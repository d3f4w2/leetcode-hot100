# 448. 找到所有数组中消失的数字

## 所属专题

- 哈希表

## 题目描述

给你一个含 `n` 个整数的数组 `nums`，其中 `nums[i]` 在区间 `[1, n]` 内。

请你找出所有在 `[1, n]` 范围内但没有出现在 `nums` 中的数字，并以数组的形式返回结果。

## 示例

### 示例 1

```text
输入：nums = [4,3,2,7,8,2,3,1]
输出：[5,6]
```

### 示例 2

```text
输入：nums = [1,1]
输出：[2]
```

## 题意理解

这道题有两个非常关键的条件：

1. 数组长度是 `n`
2. 数组中的每个数都在 `[1, n]` 范围内

这两个条件放在一起，意味着什么？

意味着：

- 数字 `1` 到 `n` 本来应该“刚好对应”这 `n` 个位置
- 但现在有些数字重复出现了
- 所以就一定会有一些数字没有出现

题目要找的不是：

- 重复了哪些数字

而是：

- 在 `1 ~ n` 里，哪些数字根本没出现过

比如：

```text
nums = [4,3,2,7,8,2,3,1]
```

长度是 `8`，所以理论上应该出现的是：

```text
[1,2,3,4,5,6,7,8]
```

但数组里：

- `2` 重复了
- `3` 重复了

所以：

- `5` 没出现
- `6` 没出现

答案就是：

```text
[5,6]
```

## 最直接的想法：额外哈希集合

最容易想到的方法是：

- 先把数组中出现过的数字都放进一个集合 `seen`
- 再从 `1` 遍历到 `n`
- 如果某个数字不在 `seen` 中，就说明它消失了

例如：

```python
seen = set(nums)
result = []

for x in range(1, len(nums) + 1):
    if x not in seen:
        result.append(x)
```

这个思路很好理解：

- 集合负责快速判断“某个数字有没有出现过”

时间复杂度是 `O(n)`，已经很不错了。

但问题是：

- 额外用了一个集合
- 空间复杂度是 `O(n)`

而这道题其实还能继续优化。

## 优化思路：用原数组本身做哈希标记

这是这道题最经典的做法。

### 核心想法

因为数组中的数字都在 `[1, n]` 范围内，
所以每个数字都可以映射到数组中的一个下标。

对应关系是：

```text
数字 x  <->  下标 x - 1
```

例如在长度为 `8` 的数组里：

- 数字 `1` 对应下标 `0`
- 数字 `2` 对应下标 `1`
- 数字 `3` 对应下标 `2`
- ...
- 数字 `8` 对应下标 `7`

这就意味着：

**我们可以不用额外开哈希表，而是直接利用数组下标来记录“某个数字是否出现过”。**

### 怎么记录“出现过”

做法是：

- 遍历数组中的每个数字 `num`
- 找到它对应的下标 `abs(num) - 1`
- 把这个位置上的数字改成负数

也就是说：

- 如果数字 `x` 出现过
- 就把 `nums[x - 1]` 标记成负数

为什么用负数？

因为：

- 原数组中的数本来都在 `[1, n]`
- 一开始全部是正数
- 所以“负号”可以用来当一个出现标记

### 为什么要用 `abs(num)`

这是这道题最容易写错的地方之一。

因为我们在遍历过程中，会不断把数组中的某些位置改成负数。

比如原本是：

```text
3
```

被标记后可能变成：

```text
-3
```

但它本质上仍然表示数字 `3`。

所以每次取值时，都必须写：

```python
abs(num)
```

表示：

- 不管它现在正还是负，我都只关心它原本代表的是哪个数字

### 为什么最后正数位置就是“消失的数字”

如果某个数字出现过，
它对应的位置一定会被我们改成负数。

反过来说：

- 如果最后某个位置仍然是正数
- 说明这个位置从来没有被标记过
- 也就说明“对应的那个数字”从来没出现过

例如：

- 下标 `4` 还是正数，说明数字 `5` 没出现
- 下标 `5` 还是正数，说明数字 `6` 没出现

所以只要最后再遍历一遍数组：

- 哪个位置是正数
- 就把 `位置 + 1` 加入答案

## 用示例手推一遍

以示例 1 为例：

```text
nums = [4,3,2,7,8,2,3,1]
```

### 初始状态

```text
[4,3,2,7,8,2,3,1]
```

### 第 1 步：读到 `4`

- 对应下标：`4 - 1 = 3`
- 把 `nums[3]` 标记成负数

数组变成：

```text
[4,3,2,-7,8,2,3,1]
```

### 第 2 步：读到 `3`

- 对应下标：`3 - 1 = 2`
- 把 `nums[2]` 标记成负数

数组变成：

```text
[4,3,-2,-7,8,2,3,1]
```

### 第 3 步：读到 `-2`

注意：

- 这里虽然当前值已经变成负数了
- 但它原本表示的数字仍然是 `2`

所以要用：

```text
abs(-2) = 2
```

- 对应下标：`2 - 1 = 1`
- 把 `nums[1]` 标记成负数

数组变成：

```text
[4,-3,-2,-7,8,2,3,1]
```

### 第 4 步：读到 `-7`

- `abs(-7) = 7`
- 对应下标：`6`
- 把 `nums[6]` 标记成负数

数组变成：

```text
[4,-3,-2,-7,8,2,-3,1]
```

### 第 5 步：读到 `8`

- 对应下标：`7`
- 把 `nums[7]` 标记成负数

数组变成：

```text
[4,-3,-2,-7,8,2,-3,-1]
```

### 第 6 步：读到 `2`

- 对应下标：`1`
- 发现 `nums[1]` 已经是负数了

说明数字 `2` 之前已经出现过。

这时不要再取反，否则会把它又变回正数。

### 第 7 步：读到 `-3`

- `abs(-3) = 3`
- 对应下标：`2`
- 这个位置已经是负数，说明数字 `3` 之前已经出现过

### 第 8 步：读到 `-1`

- `abs(-1) = 1`
- 对应下标：`0`
- 把 `nums[0]` 标记成负数

数组最终变成：

```text
[-4,-3,-2,-7,8,2,-3,-1]
```

现在观察哪些位置仍然是正数：

- 下标 `4` 的值是 `8`
- 下标 `5` 的值是 `2`

所以消失的数字就是：

- `4 + 1 = 5`
- `5 + 1 = 6`

答案为：

```text
[5,6]
```

## 为什么这样写

这道题最巧妙的地方，不在于“哈希表”这三个字，而在于：

### 1. 题目给了一个非常重要的值域条件

所有数字都在 `[1, n]` 之间。

这让我们可以直接建立：

- 数字 -> 下标

的映射关系。

也就是说，这不是普通数组，而是一个“天然带编号”的数组。

### 2. 负号只用来表示“出现过”

我们并不关心把某个位置具体改成多少，
只关心它是不是负数。

所以：

- 正数 = 还没被标记
- 负数 = 这个数字出现过

### 3. `abs(num)` 是整个解法的关键细节

因为数组在遍历过程中会被我们改坏。

如果不用绝对值，就会把：

- `-3`

错误地理解成一个非法下标来源。

而正确理解应该是：

- 它代表的原始数字还是 `3`

### 4. 已经是负数时不能再取反

如果你不判断：

```python
if nums[index] > 0:
```

而是每次都写：

```python
nums[index] = -nums[index]
```

那么重复出现的数字会把该位置来回翻转。

这样就会把“已经出现过”的位置错误地变回正数。

## 算法步骤

1. 遍历数组中的每个数字 `num`
2. 计算它对应的下标 `index = abs(num) - 1`
3. 如果 `nums[index]` 是正数，就把它改成负数，表示这个数字出现过
4. 第一轮遍历结束后，再遍历一次数组
5. 如果某个位置 `i` 上仍然是正数，说明数字 `i + 1` 没出现过
6. 把这些数字加入结果数组并返回

## 复杂度分析

### 时间复杂度

`O(n)`

原因：

- 我们只遍历了数组两遍
- 每次访问和修改都是 `O(1)`

### 空间复杂度

`O(1)`

说明：

- 这里不计算返回结果数组的空间
- 除了答案本身，只使用了常数级额外变量

不过要注意：

- 这个做法会修改原数组 `nums`

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        # 第一轮遍历：
        # 用“对应位置变成负数”的方式，标记某个数字出现过。
        for num in nums:
            # 因为数组中的值可能已经被我们改成负数了，
            # 所以这里一定要先取绝对值，还原它原本表示的数字。
            index = abs(num) - 1

            # 如果这个位置目前还是正数，
            # 说明它还没有被标记过，就把它变成负数。
            if nums[index] > 0:
                nums[index] = -nums[index]

        # 第二轮遍历：
        # 哪个位置仍然是正数，就说明对应的数字没有出现过。
        result = []
        for index, num in enumerate(nums):
            if num > 0:
                # 下标 index 对应的数字其实是 index + 1。
                result.append(index + 1)

        return result
```

## 这段代码最值得记住的地方

你在自己手写的时候，重点记住下面这条主线：

```python
for num in nums:
    index = abs(num) - 1
    if nums[index] > 0:
        nums[index] = -nums[index]

result = []
for index, num in enumerate(nums):
    if num > 0:
        result.append(index + 1)
```

本质上就是一句话：

**把“数字出现过”这件事，转化成“对应位置是否被标成负数”。**

## 常见错误

### 1. 忘记用 `abs(num)`

这是最常见的错误。

因为数组在遍历中会被改成负数，
如果不用绝对值，就会得到错误的下标。

### 2. 下标映射写错

数字 `x` 对应的是：

```python
x - 1
```

不是：

```python
x
```

因为数组下标从 `0` 开始。

### 3. 重复出现时又把负数翻回正数

所以必须先判断：

```python
if nums[index] > 0:
```

再去取反。

### 4. 最后返回的是数字，不是下标

如果位置 `i` 是正数，说明消失的是：

```python
i + 1
```

而不是 `i`。

### 5. 忘记这个方法会修改原数组

如果你后面还需要保留原数组的内容，
就不能直接在原数组上操作，或者需要先拷贝一份。

## 适合你自己再写一遍的版本

如果你准备在自己的 `.ipy` 文件里默写，建议先记住下面这个精简版本：

```python
from typing import List


class Solution:
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:
        for num in nums:
            index = abs(num) - 1
            if nums[index] > 0:
                nums[index] = -nums[index]

        result = []
        for index, num in enumerate(nums):
            if num > 0:
                result.append(index + 1)

        return result
```

## 一句话总结

这道题的关键不是额外开一个哈希表，而是：

**利用“数字范围正好是 `1 ~ n`”这一条件，把数组下标当成哈希位置，再用负号标记某个数字是否出现过。**
