# 049. 字母异位词分组

## 所属专题
- 哈希

## 题目描述

给你一个字符串数组 `strs`，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

字母异位词指的是：

- 由相同字母组成
- 只是字母排列顺序不同

例如：

- `eat`
- `tea`
- `ate`

它们都由同样的字母组成，所以属于同一组。

## 示例

### 示例 1

```text
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

### 示例 2

```text
输入：strs = [""]
输出：[[""]]
```

### 示例 3

```text
输入：strs = ["a"]
输出：[["a"]]
```

## 题意理解

这道题并不是让我们判断：

- 两个字符串是不是字母异位词

而是要我们做更进一步的事：

- 把整个数组里“互为字母异位词”的字符串分到同一组里

也就是说，
我们需要找到一种办法，能够快速判断：

- 两个字符串本质上是不是由同一批字母组成

如果能把每个字符串都转成某种“统一表示”，
那么：

- 统一表示相同的字符串，就放进同一组
- 统一表示不同的字符串，就分到不同组

这就是这道题最核心的思路。

## 最直接的想法：两两比较是否互为异位词

最容易想到的方法是：

- 取一个字符串
- 和后面所有字符串逐个比较
- 如果是字母异位词，就分到同一组

但这里很麻烦：

1. 每个字符串都要和很多字符串比较
2. 每次比较还要判断两个字符串是否由相同字母组成

这样整体效率会比较低。

所以我们自然会想到一个更好的方向：

- 能不能给每个字符串做一个“标识”
- 只要标识相同，就说明它们应该分到一组

## 优化思路：排序后作为哈希表的键

这道题最经典、最好理解的做法是：

- 把每个字符串排序
- 将排序后的结果作为哈希表的键

### 为什么排序后可以当作键

因为字母异位词虽然顺序不同，
但它们包含的字母和数量是完全一样的。

例如：

- `eat` 排序后是 `aet`
- `tea` 排序后是 `aet`
- `ate` 排序后还是 `aet`

所以它们排序后的结果相同，
自然应该放到同一组。

再看：

- `tan` 排序后是 `ant`
- `nat` 排序后是 `ant`

它们也会分到同一组。

而：

- `bat` 排序后是 `abt`

它和前面那些键都不同，
所以它自己单独成组。

### 哈希表里存什么

我们可以用一个字典 `groups`：

- 键：字符串排序后的结果
- 值：所有属于这一组的原字符串列表

例如遍历到一半时，
字典可能长这样：

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"]
}
```

最后只要返回：

```python
list(groups.values())
```

就得到答案。

## 用示例手推一遍

以：

```text
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
```

为例。

### 第 1 步：处理 `eat`

- 排序后得到 `aet`
- `aet` 这组还不存在
- 新建一组，加入 `eat`

此时：

```python
{
    "aet": ["eat"]
}
```

### 第 2 步：处理 `tea`

- 排序后还是 `aet`
- 说明它和 `eat` 属于同一组

此时：

```python
{
    "aet": ["eat", "tea"]
}
```

### 第 3 步：处理 `tan`

- 排序后得到 `ant`
- 这是新的一组

此时：

```python
{
    "aet": ["eat", "tea"],
    "ant": ["tan"]
}
```

### 第 4 步：处理 `ate`

- 排序后得到 `aet`
- 加入 `aet` 这一组

此时：

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan"]
}
```

### 第 5 步：处理 `nat`

- 排序后得到 `ant`
- 加入 `ant` 这一组

此时：

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"]
}
```

### 第 6 步：处理 `bat`

- 排序后得到 `abt`
- 新建一组

最终：

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"]
}
```

返回所有值即可。

## 为什么这样写

### 1. 把“顺序不同”转成“统一表示相同”

这道题最关键的一步就是：

- 不再直接比较原字符串
- 而是比较它们的“标准形态”

排序后的字符串，就是这里的标准形态。

只要标准形态一样，
就说明这些字符串是同一类。

### 2. 哈希表非常适合做分组

哈希表的优势是：

- 能快速判断某个键是否已经出现过
- 能快速把元素追加到对应分组里

所以“按某个特征分组”的题，
经常都可以考虑：

- `key -> list`

这样的哈希结构。

### 3. 返回顺序不重要，正好适合字典存储

题目说明：

- 结果列表的顺序可以任意
- 每组内部元素顺序通常也不影响判题

所以我们不需要额外维护复杂的顺序规则，
只需要把分组做对即可。

## 算法步骤

1. 创建一个哈希表 `groups`
2. 遍历数组中的每个字符串 `s`
3. 对 `s` 排序，得到键 `key`
4. 把原字符串 `s` 放入 `groups[key]`
5. 遍历结束后，返回 `groups` 的所有值

## 复杂度分析

### 时间复杂度

`O(n * k log k)`

其中：

- `n` 是字符串数组的长度
- `k` 是字符串的最大长度

原因是：

- 需要遍历每个字符串
- 每个字符串都要排序一次
- 排序一个长度为 `k` 的字符串需要 `O(k log k)`

### 空间复杂度

`O(n * k)`

原因是：

- 哈希表需要存储所有字符串分组
- 排序后的键也会占用额外空间

## Python 参考实现（详细注释）

```python
from typing import List
from collections import defaultdict


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)

        for s in strs:
            # 把排序后的结果作为同类字符串的统一标识
            key = ''.join(sorted(s))
            groups[key].append(s)

        return list(groups.values())
```

## 这段代码最值得记住的地方

核心其实就两句：

```python
key = ''.join(sorted(s))
groups[key].append(s)
```

它表达的含义是：

- 先把字符串转成统一的“标准形态”
- 再按这个标准形态分组

只要你能熟练想到“先构造 key，再哈希分组”，
这类题就会顺很多。

## 常见错误

### 1. 直接拿 `sorted(s)` 当字典键

`sorted(s)` 的结果是一个列表，
而列表不能作为字典键。

所以要写成：

```python
key = ''.join(sorted(s))
```

或者写成元组：

```python
key = tuple(sorted(s))
```

### 2. 把排序后的字符串放进去，而不是原字符串

题目要返回的是：

- 原来的字符串分组

不是要返回排序后的字符串。

所以应该：

```python
groups[key].append(s)
```

而不是：

```python
groups[key].append(key)
```

### 3. 误以为输出顺序必须完全固定

这题的结果顺序通常可以任意，
所以：

- 各组的顺序不一定固定
- 组内元素的顺序也不一定固定

只要分组正确即可。

### 4. 忘记使用 `defaultdict(list)` 或初始化列表

如果直接写：

```python
groups[key].append(s)
```

那就要保证 `groups[key]` 已经存在。

所以一般有两种写法：

```python
groups = defaultdict(list)
```

或者：

```python
if key not in groups:
    groups[key] = []
groups[key].append(s)
```

## 可以进一步了解的点

除了“排序后作为键”之外，
这道题还有另一种常见思路：

- 统计每个字符串 26 个字母出现的次数
- 把次数数组转成元组作为键

这样可以把单个字符串构造键的时间降到：

- `O(k)`

不过对于入门和日常刷题来说，
“排序 + 哈希分组”已经是最经典、最好记的一种写法。

from collections import defaultdict

## 一句话总结

这道题的关键是：

**把每个字符串排序后作为统一标识，再用哈希表按这个标识分组。**
