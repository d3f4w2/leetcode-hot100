# 072. 编辑距离

## 所属专题

- 动态规划

## 题目描述

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

## 示例

### 示例 1

```text
输入：word1 = horse, word2 = ros
输出：3
解释：
horse -> rorse（将 'h' 替换为 'r'）
rorse -> rose（删除 'r'）
rose -> ros（删除 'e'）
```

### 示例 2

```text
输入：word1 = intention, word2 = execution
输出：5
解释：
intention -> inention（删除 't'）
inention -> enention（将 'i' 替换为 'e'）
enention -> exention（将 'n' 替换为 'x'）
exention -> exection（将 'n' 替换为 'c'）
exection -> execution（插入 'u'）
```

## 题意理解

这道题问的不是：

- 两个字符串哪里不一样

而是问：

- 最少做多少次操作
- 才能把 `word1` 变成 `word2`

题目允许的操作只有三种：

- 插入
- 删除
- 替换

这意味着我们每走一步，
都在让两个字符串“更接近一点”。

但难点在于：

- 当前一步怎么选，会影响后面的状态
- 局部看起来最优的选择，不一定能得到全局最优解

所以这道题不适合贪心，
而非常适合动态规划。

本质上，我们其实是在思考：

- `word1` 的前一段，怎么变成 `word2` 的前一段

只要我们把所有“前缀变前缀”的最优答案都求出来，
最后整个字符串的最优答案也就出来了。

## 最直接的想法：暴力递归

最容易想到的是：

- 如果当前两个字符相同，就一起跳过
- 如果当前两个字符不同，就分别尝试删除、插入、替换

也就是说，
对于每一对位置，我们都去递归尝试：

```text
min(
    删除后的结果，
    插入后的结果，
    替换后的结果
) + 1
```

这个思路方向是对的，
因为编辑距离本来就是从这三种操作里选最优。

但它有一个很大的问题：

- 会反复计算大量重复子问题

比如：

- `word1` 前 4 个字符变成 `word2` 前 3 个字符
- 这个结果可能会被很多不同分支重复算到

所以纯递归虽然好理解，
但效率会很差。

我们要做的优化就是：

**把这些重复子问题的答案保存下来。**

## 优化思路：动态规划

### 核心想法

定义一个二维数组，
专门记录：

- `word1` 的某个前缀
- 变成 `word2` 的某个前缀
- 最少需要多少次操作

这样每个子问题只算一次，
后面直接复用。

### 状态定义

定义：

```text
dp[i][j] = word1 的前 i 个字符转换成 word2 的前 j 个字符所需的最少操作数
```

这里一定要注意：

- `i` 和 `j` 表示的是“前缀长度”
- 不是字符串下标本身

所以题目最终要求的答案就是：

```text
dp[m][n]
```

其中：

- `m = len(word1)`
- `n = len(word2)`

### 状态转移

我们只看当前这一步，
也就是比较：

```python
word1[i - 1]
word2[j - 1]
```

#### 情况 1：当前字符相同

如果：

```text
word1[i - 1] == word2[j - 1]
```

说明最后一个字符不用改，
问题就等价于：

- `word1` 前 `i - 1` 个字符
- 变成 `word2` 前 `j - 1` 个字符

所以：

```text
dp[i][j] = dp[i - 1][j - 1]
```

#### 情况 2：当前字符不同

如果：

```text
word1[i - 1] != word2[j - 1]
```

那我们就尝试三种操作。

##### 1. 删除

删除 `word1[i - 1]`，
那么问题变成：

- `word1` 前 `i - 1` 个字符
- 变成 `word2` 前 `j` 个字符

对应：

```text
dp[i - 1][j] + 1
```

##### 2. 插入

如果想让 `word1` 变成 `word2`，
可以在 `word1` 末尾插入 `word2[j - 1]`。

这样问题就变成：

- `word1` 前 `i` 个字符
- 变成 `word2` 前 `j - 1` 个字符

对应：

```text
dp[i][j - 1] + 1
```

##### 3. 替换

把 `word1[i - 1]` 替换成 `word2[j - 1]`，
那么问题变成：

- `word1` 前 `i - 1` 个字符
- 变成 `word2` 前 `j - 1` 个字符

对应：

```text
dp[i - 1][j - 1] + 1
```

所以综合起来：

```text
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
```

### 初始化

#### `dp[i][0] = i`

如果要把 `word1` 的前 `i` 个字符变成空串，
只能做一件事：

- 把这 `i` 个字符全部删除

所以：

```text
dp[i][0] = i
```

#### `dp[0][j] = j`

如果要把空串变成 `word2` 的前 `j` 个字符，
只能做一件事：

- 插入这 `j` 个字符

所以：

```text
dp[0][j] = j
```

#### `dp[0][0] = 0`

空串变成空串，
不需要任何操作。

## 用示例手推一遍

以：

```text
word1 = horse
word2 = ros
```

为例。

我们最终要求的是：

```text
dp[5][3]
```

也就是：

- `horse` 变成 `ros`

### 第 1 步：初始化表格

先把第一行和第一列填出来：

```text
      ''  r  o  s
''     0  1  2  3
h      1
o      2
r      3
s      4
e      5
```

这里表示：

- 第一行：空串变成 `r`、`ro`、`ros` 需要几步
- 第一列：`h`、`ho`、`hor`... 变成空串需要几步

### 第 2 步：填写关键位置

#### `dp[1][1]`

比较：

- `h`
- `r`

它们不同，所以：

```text
dp[1][1] = min(dp[0][1], dp[1][0], dp[0][0]) + 1
         = min(1, 1, 0) + 1
         = 1
```

#### `dp[2][2]`

比较：

- `o`
- `o`

它们相同，所以：

```text
dp[2][2] = dp[1][1] = 1
```

#### `dp[3][1]`

比较：

- `r`
- `r`

它们相同，所以：

```text
dp[3][1] = dp[2][0] = 2
```

### 第 3 步：得到最终答案

整张表填完后，
最后会得到：

```text
dp[5][3] = 3
```

这就说明：

- `horse` 变成 `ros`
- 最少需要 `3` 步

## 为什么这样写

### 1. 把原问题拆成“前缀对前缀”

字符串类动态规划里最常见的做法就是：

- 不直接想整个字符串
- 而是想前缀和前缀之间的关系

这样状态就更容易定义，
也更容易递推。

### 2. 只讨论“最后一步”就够了

对于 `dp[i][j]`，
前面的部分怎么变已经由更小状态算好了。

我们当前只需要关心：

- 最后一个字符相不相同
- 如果不同，是删除、插入还是替换

这就是这道题状态转移特别自然的原因。

### 3. 题目问“最少操作数”，所以自然是取最小值

每次都有多个候选方案：

- 删除
- 插入
- 替换

而我们要的是最少操作次数，
所以转移时自然就是：

```text
min(...)
```

## 算法步骤

1. 设 `m = len(word1)`，`n = len(word2)`
2. 创建大小为 `(m + 1) × (n + 1)` 的二维数组 `dp`
3. 初始化第一列 `dp[i][0] = i`
4. 初始化第一行 `dp[0][j] = j`
5. 从 `i = 1` 遍历到 `m`
6. 从 `j = 1` 遍历到 `n`
7. 如果 `word1[i - 1] == word2[j - 1]`，则 `dp[i][j] = dp[i - 1][j - 1]`
8. 否则 `dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1`
9. 返回 `dp[m][n]`

## 复杂度分析

### 时间复杂度

`O(m × n)`

原因是：

- 一共有 `m * n` 个状态
- 每个状态只做常数次比较和更新

### 空间复杂度

`O(m × n)`

原因是：

- 使用了一个二维 `dp` 数组

如果继续优化，
也可以把空间压缩到：

```text
O(min(m, n))
```

不过入门阶段先把二维写法彻底掌握更重要。

## Python 参考实现（详细注释）

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)

        # dp[i][j] 表示：
        # word1 的前 i 个字符，变成 word2 的前 j 个字符，
        # 最少需要多少次操作。
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 初始化第一列：
        # 把 word1 的前 i 个字符变成空串，
        # 只能一直删除，所以需要 i 步。
        for i in range(m + 1):
            dp[i][0] = i

        # 初始化第一行：
        # 把空串变成 word2 的前 j 个字符，
        # 只能一直插入，所以需要 j 步。
        for j in range(n + 1):
            dp[0][j] = j

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 如果当前两个字符相同，
                # 那么最后一个字符不需要额外操作。
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    # 三种操作分别对应：
                    # 1. 删除 word1[i - 1]
                    # 2. 插入 word2[j - 1]
                    # 3. 把 word1[i - 1] 替换成 word2[j - 1]
                    dp[i][j] = min(
                        dp[i - 1][j],
                        dp[i][j - 1],
                        dp[i - 1][j - 1]
                    ) + 1

        return dp[m][n]
```

## 这段代码最值得记住的地方

整道题最核心的是这两部分：

```text
dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数
```

以及：

```python
if word1[i - 1] == word2[j - 1]:
    dp[i][j] = dp[i - 1][j - 1]
else:
    dp[i][j] = min(
        dp[i - 1][j],
        dp[i][j - 1],
        dp[i - 1][j - 1]
    ) + 1
```

你可以这样记：

- 字符相同，就沿左上角继承
- 字符不同，就在删除、插入、替换里选最优

## 常见错误

### 1. 把 `i`、`j` 当成字符下标直接用

`dp[i][j]` 表示的是前缀长度，
所以真正比较的字符应该是：

```python
word1[i - 1]
word2[j - 1]
```

不是直接写 `word1[i]`、`word2[j]`。

### 2. 第一行和第一列忘记初始化

这两个边界特别重要：

- `dp[i][0] = i`
- `dp[0][j] = j`

如果不初始化，
后面的状态就没有正确起点。

### 3. 分不清三种操作对应哪个状态

建议固定这样记：

- `dp[i - 1][j]`：删除
- `dp[i][j - 1]`：插入
- `dp[i - 1][j - 1]`：替换

### 4. 误以为字符不同就一定选替换

字符不同的时候，
最优操作不一定是替换。

有时候：

- 删除更优
- 插入更优

所以一定要三种情况一起比较。

## 适合自己默写的精简版本

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = min(
                        dp[i - 1][j],
                        dp[i][j - 1],
                        dp[i - 1][j - 1]
                    ) + 1

        return dp[m][n]
```

## 一句话总结

这道题的关键是：

**把问题定义成两个字符串前缀之间的最小编辑距离，再根据最后一个字符是否相同，分类讨论删除、插入、替换三种转移。**
