# 72. 编辑距离

## 所属专题
- 动态规划

## 题目描述

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

## 示例

### 示例 1

```text
输入：word1 = horse, word2 = ros
输出：3
解释：
horse -> rorse（将 'h' 替换为 'r'）
rorse -> rose（删除 'r'）
rose -> ros（删除 'e'）
```

### 示例 2

```text
输入：word1 = intention, word2 = execution
输出：5
解释：
intention -> inention（删除 't'）
inention -> enention（将 'i' 替换为 'e'）
enention -> exention（将 'n' 替换为 'x'）
exention -> exection（将 'n' 替换为 'c'）
exection -> execution（插入 'u'）
```

## 题意理解

这道题要求的是：

- 把字符串 `word1`
- 变成字符串 `word2`
- 所需要的最少操作次数

操作只有三种：

- 插入
- 删除
- 替换

这道题的难点在于：

- 每一步操作都会影响后面的字符串状态
- 局部看起来最优的选择，不一定能得到全局最优解

所以它不太适合贪心，
而非常适合用动态规划去做。

本质上，我们要解决的是：

- `word1` 的前一部分怎么变成 `word2` 的前一部分

只要把“前缀到前缀”的最优解都算出来，
最后就能得到整个字符串的最优解。

## 为什么想到动态规划

假设我们已经知道：

- `word1` 前 `i - 1` 个字符变成 `word2` 前 `j` 个字符的最少操作数
- `word1` 前 `i` 个字符变成 `word2` 前 `j - 1` 个字符的最少操作数
- `word1` 前 `i - 1` 个字符变成 `word2` 前 `j - 1` 个字符的最少操作数

那么就有机会推出：

- `word1` 前 `i` 个字符变成 `word2` 前 `j` 个字符的最少操作数

也就是说：

- 大问题可以由更小的子问题推出来

这正是动态规划的典型特征。

## 状态定义

定义：

```text
dp[i][j] = 将 word1 的前 i 个字符转换成 word2 的前 j 个字符所需的最少操作数
```

这里的“前 `i` 个字符”非常重要。

例如：

- `dp[3][2]`

表示的是：

- `word1` 的前 3 个字符
- 变成 `word2` 的前 2 个字符
- 最少需要多少步

题目最终要求的答案就是：

```text
dp[m][n]
```

其中：

- `m = len(word1)`
- `n = len(word2)`

## 状态转移方程

### 情况 1：最后一个字符相同

如果：

```text
word1[i - 1] == word2[j - 1]
```

说明最后一个字符不用做任何操作，
那么问题就直接变成：

- 前 `i - 1` 个字符怎么变成前 `j - 1` 个字符

所以：

```text
dp[i][j] = dp[i - 1][j - 1]
```

### 情况 2：最后一个字符不同

如果：

```text
word1[i - 1] != word2[j - 1]
```

那么我们就有三种选择：

#### 1. 删除

删除 `word1[i - 1]`，
那么问题变成：

- `word1` 前 `i - 1` 个字符变成 `word2` 前 `j` 个字符

对应：

```text
dp[i - 1][j] + 1
```

#### 2. 插入

如果要让 `word1` 变成 `word2`，
可以在 `word1` 末尾插入 `word2[j - 1]`。

这样问题变成：

- `word1` 前 `i` 个字符变成 `word2` 前 `j - 1` 个字符

对应：

```text
dp[i][j - 1] + 1
```

#### 3. 替换

把 `word1[i - 1]` 替换成 `word2[j - 1]`，
那么问题变成：

- `word1` 前 `i - 1` 个字符变成 `word2` 前 `j - 1` 个字符

对应：

```text
dp[i - 1][j - 1] + 1
```

所以综合起来：

```text
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
```

## 初始化为什么这样写

### `dp[i][0] = i`

如果要把 `word1` 的前 `i` 个字符变成空字符串，
只能做一件事：

- 把这 `i` 个字符全部删除

所以：

```text
dp[i][0] = i
```

### `dp[0][j] = j`

如果要把空字符串变成 `word2` 的前 `j` 个字符，
只能做一件事：

- 插入这 `j` 个字符

所以：

```text
dp[0][j] = j
```

### `dp[0][0] = 0`

空字符串变成空字符串，
不需要任何操作。

## 用示例手推一遍

以：

```text
word1 = horse
word2 = ros
```

为例。

我们关注最后答案：

```text
dp[5][3]
```

也就是：

- `horse` 变成 `ros`

### 第一步：建表

我们创建一个 `(m + 1) × (n + 1)` 的二维数组。

横轴表示 `word2` 的前缀长度，
纵轴表示 `word1` 的前缀长度。

先初始化第一行和第一列：

```text
      ''  r  o  s
''    0  1  2  3
h     1
o     2
r     3
s     4
e     5
```

### 第二步：逐格填写

#### `dp[1][1]`

- 比较 `h` 和 `r`
- 不相同

所以：

```text
dp[1][1] = min(dp[0][1], dp[1][0], dp[0][0]) + 1
         = min(1, 1, 0) + 1
         = 1
```

#### `dp[2][2]`

- 比较 `o` 和 `o`
- 相同

所以：

```text
dp[2][2] = dp[1][1]
```

#### `dp[3][1]`

- 比较 `r` 和 `r`
- 相同

所以：

```text
dp[3][1] = dp[2][0] = 2
```

最终整个表填完后，
会得到：

```text
dp[5][3] = 3
```

这就说明最少需要 `3` 步。

## 为什么这样写

### 1. 每一步都只关心最后一个字符怎么处理

动态规划里很常见的技巧就是：

- 先把问题缩小到前缀
- 再思考最后一步怎么走

在这题里，
最后一步无非就是：

- 删除
- 插入
- 替换
- 或者什么都不做（最后字符相同）

这样就把复杂问题拆成了有限几种情况。

### 2. 二维 `dp` 正好表示两个字符串前缀之间的关系

因为题目里有两个字符串，
所以通常会想到：

- 用一维表示 `word1` 的位置
- 用另一维表示 `word2` 的位置

于是二维动态规划就是很自然的建模方式。

### 3. 题目问“最少操作数”，天然对应取最小值

每次我们都会面对多个可选操作，
而题目要求最少操作数，
所以自然就是：

```text
min(...)
```

## 算法步骤

1. 设 `m = len(word1)`，`n = len(word2)`
2. 创建大小为 `(m + 1) × (n + 1)` 的二维数组 `dp`
3. 初始化第一列 `dp[i][0] = i`
4. 初始化第一行 `dp[0][j] = j`
5. 从 `i = 1` 遍历到 `m`
6. 从 `j = 1` 遍历到 `n`
7. 如果 `word1[i - 1] == word2[j - 1]`，则 `dp[i][j] = dp[i - 1][j - 1]`
8. 否则 `dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1`
9. 返回 `dp[m][n]`

## 复杂度分析

### 时间复杂度

`O(m × n)`

其中：

- `m` 是 `word1` 的长度
- `n` 是 `word2` 的长度

因为二维表中的每个状态只计算一次。

### 空间复杂度

`O(m × n)`

原因是：

- 使用了一个二维 `dp` 数组

如果继续优化，
也可以把空间压缩到：

```text
O(min(m, n))
```

不过入门阶段先掌握二维写法最重要。

## Python 参考实现（详细注释）

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 初始化：把 word1 的前 i 个字符变成空串
        for i in range(m + 1):
            dp[i][0] = i

        # 初始化：把空串变成 word2 的前 j 个字符
        for j in range(n + 1):
            dp[0][j] = j

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = min(
                        dp[i - 1][j],
                        dp[i][j - 1],
                        dp[i - 1][j - 1]
                    ) + 1

        return dp[m][n]
```

## 这段代码最值得记住的地方

这题最关键的是先记住状态定义：

```text
dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数
```

然后记住两种转移：

### 字符相同

```text
dp[i][j] = dp[i - 1][j - 1]
```

### 字符不同

```text
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
```

只要这两句真正理解了，
这题就能自己写出来。

## 常见错误

### 1. 下标和字符位置对应错

`dp[i][j]` 表示前 `i` 个字符，
所以当前比较的字符应该是：

```python
word1[i - 1]
word2[j - 1]
```

不是直接写 `word1[i]`、`word2[j]`。

### 2. 初始化没写全

第一行和第一列都非常重要：

- `dp[i][0] = i`
- `dp[0][j] = j`

如果漏掉初始化，
后面的状态都会错。

### 3. 分不清插入、删除、替换分别对应哪个状态

建议这样记：

- `dp[i - 1][j]`：删除
- `dp[i][j - 1]`：插入
- `dp[i - 1][j - 1]`：替换

### 4. 误以为字符不同就一定要替换

字符不同的时候，
不一定替换最优。

有时候：

- 删除更优
- 插入更优

所以必须三种操作都比较后再取最小值。

这道题的关键是：

**定义 `dp[i][j]` 表示两个字符串前缀之间的最小编辑距离，再根据最后一个字符是否相同，分类讨论删除、插入、替换三种转移。**
