# 279. 完全平方数

## 所属专题
- 动态规划

## 题目描述

给你一个整数 `n`，返回 **和为 `n` 的完全平方数的最少数量**。

完全平方数指的是：

- 一个整数可以写成另一个整数的平方

例如：

- `1 = 1 × 1`
- `4 = 2 × 2`
- `9 = 3 × 3`
- `16 = 4 × 4`

而：

- `3`
- `11`

都不是完全平方数。

## 示例

### 示例 1

```text
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4
```

### 示例 2

```text
输入：n = 13
输出：2
解释：13 = 4 + 9
```

## 题意理解

这道题不是问：

- 有多少种表示方法

而是问：

- 在所有表示方法里，最少需要几个完全平方数

比如 `12`：

- 可以写成 `4 + 4 + 4`
- 也可以写成 `9 + 1 + 1 + 1`

但题目要的是：

- 哪一种拆分用的完全平方数最少

所以答案是：

```text
3
```

这类“最少个数”“最优解”的题目，
很适合往动态规划方向去想。

## 最直接的想法：暴力尝试所有拆分

最容易想到的是：

- 对于 `n`
- 尝试减去每一个不超过它的完全平方数
- 再递归去求剩下部分的最优解

比如：

```text
n = 12
```

可以尝试：

- `12 - 1 = 11`
- `12 - 4 = 8`
- `12 - 9 = 3`

然后再继续求：

- 组成 `11` 的最少数量
- 组成 `8` 的最少数量
- 组成 `3` 的最少数量

最后取最小值。

这个思路本身没错，
但会遇到一个问题：

- 很多子问题会被重复计算

例如：

- 求 `12` 时可能会求到 `8`
- 求 `9` 时也可能会求到 `8`

所以如果直接暴力递归，效率会比较低。

## 优化思路：动态规划

### 状态定义

定义：

```text
dp[i] = 组成整数 i 所需要的完全平方数的最少数量
```

那么题目要求的就是：

```text
dp[n]
```

### 状态转移方程

如果我们当前要求 `dp[i]`，
那么最后一个使用的完全平方数可能是：

- `1`
- `4`
- `9`
- `16`
- ...

只要满足：

```text
j * j <= i
```

假设最后用了一个完全平方数 `j * j`，
那么前面剩下的是：

```text
i - j * j
```

于是就有：

```text
dp[i] = min(dp[i], dp[i - j * j] + 1)
```

这里的 `+ 1` 表示：

- 当前又多用了一个完全平方数 `j * j`

### 初始条件

```text
dp[0] = 0
```

因为：

- 组成 `0` 不需要任何完全平方数

这就是整个动态规划的起点。

## 用示例手推一遍

以：

```text
n = 12
```

为例。

### 第 1 步：初始化

创建数组：

```text
dp[0...12]
```

初始时：

- `dp[0] = 0`
- 其他位置先设为正无穷，表示还没算出来

### 第 2 步：依次计算

#### `dp[1]`

只可以用：

- `1`

所以：

```text
dp[1] = dp[0] + 1 = 1
```

#### `dp[2]`

只可以减去：

- `1`

所以：

```text
dp[2] = dp[1] + 1 = 2
```

即：

```text
2 = 1 + 1
```

#### `dp[3]`

同理：

```text
dp[3] = dp[2] + 1 = 3
```

即：

```text
3 = 1 + 1 + 1
```

#### `dp[4]`

可以尝试：

- `4 - 1 = 3`
- `4 - 4 = 0`

所以：

```text
dp[4] = min(dp[3] + 1, dp[0] + 1)
      = min(4, 1)
      = 1
```

即：

```text
4 = 4
```

#### `dp[5]`

可以尝试：

- 用 `1`，则 `dp[5] = dp[4] + 1 = 2`
- 用 `4`，则 `dp[5] = dp[1] + 1 = 2`

所以：

```text
dp[5] = 2
```

即：

```text
5 = 4 + 1
```

......

#### `dp[12]`

可以尝试：

- `12 - 1 = 11`
- `12 - 4 = 8`
- `12 - 9 = 3`

于是：

```text
dp[12] = min(dp[11] + 1, dp[8] + 1, dp[3] + 1)
```

最终会得到：

```text
dp[12] = 3
```

对应的一种拆法是：

```text
12 = 4 + 4 + 4
```

## 为什么这样写

### 1. 每个数字都可以看成“更小数字 + 一个完全平方数”

比如 `12`，
它可以来自：

- `11 + 1`
- `8 + 4`
- `3 + 9`

也就是说：

- 当前问题可以由更小规模的问题转移而来

这正是动态规划最重要的特征。

### 2. 我们只需要选最优的那个前驱状态

虽然 `i` 可以由很多种完全平方数转移过来，
但题目要的是最少数量，
所以我们只需要在这些可能中取最小值。

这就是：

```text
min(...)
```

出现的原因。

### 3. 顺序不重要，所以可以按大小递推

题目并不关心：

- `4 + 9`
- `9 + 4`

有什么顺序差别。

它只关心最少用了几个数。

所以我们完全可以从小到大计算：

- 先求出 `dp[1]`
- 再求出 `dp[2]`
- ...
- 最后求出 `dp[n]`

## 算法步骤

1. 创建长度为 `n + 1` 的数组 `dp`
2. 将所有位置初始化为正无穷
3. 设 `dp[0] = 0`
4. 从 `1` 遍历到 `n`
5. 对每个 `i`，枚举所有满足 `j * j <= i` 的 `j`
6. 用 `dp[i - j * j] + 1` 更新 `dp[i]`
7. 最后返回 `dp[n]`

## 复杂度分析

### 时间复杂度

`O(n√n)`

原因是：

- 外层循环遍历 `1` 到 `n`
- 内层循环枚举不超过 `i` 的完全平方数
- 完全平方数的个数大约是 `√i`

综合起来就是：

```text
O(n√n)
```

### 空间复杂度

`O(n)`

原因是：

- 使用了一个长度为 `n + 1` 的 `dp` 数组

## Python 参考实现（详细注释）

```python
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [float('inf')] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1

        return dp[n]
```

## 这段代码最值得记住的地方

最核心的是这句：

```python
dp[i] = min(dp[i], dp[i - j * j] + 1)
```

它表示：

- 如果最后使用了一个完全平方数 `j * j`
- 那么组成 `i` 的最优解
- 可以由 `i - j * j` 的最优解再加一个数得到

只要你能记住：

- `dp[i]` 表示组成 `i` 的最少数量
- 枚举最后一个完全平方数是多少

这道题就很容易默写出来。

## 常见错误

### 1. 把题目理解成“有多少种组成方式”

这道题问的是：

- 最少数量

不是问：

- 方案总数

所以状态定义不要写偏。

### 2. 忘记初始化 `dp[0] = 0`

`dp[0]` 是整个递推的起点。

如果这里不设好，
后面的状态都会受影响。

### 3. 内层循环没有限制 `j * j <= i`

枚举完全平方数时，
只能枚举到不超过当前 `i` 的范围。

否则会越界或者逻辑错误。

### 4. 没有把 `dp[i]` 初始化成一个很大的值

因为我们要取最小值，
所以一开始通常写成：

```python
float('inf')
```

这样更新最方便。

```python
class Solution:
    def numSquares(self, n: int) -> int:

        dp[0] = 0

        for i in range(1, n + 1):
            j = 1

                dp[i] = min(dp[i], dp[i - j * j] + 1)

```

## 一句话总结

这道题的关键是：

**定义 `dp[i]` 为组成 `i` 的最少完全平方数个数，再枚举最后一个使用的完全平方数进行转移。**
