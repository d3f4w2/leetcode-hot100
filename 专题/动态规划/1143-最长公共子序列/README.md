# 1143. 最长公共子序列

## 所属专题
- 动态规划

## 题目描述

给定两个字符串 `text1` 和 `text2`，
返回这两个字符串的最长公共子序列的长度。

如果不存在公共子序列，返回 `0`。

这里的“子序列”指的是：

- 不要求字符连续
- 但必须保持原来的相对顺序

也就是说，
你可以从原字符串中删除一些字符，
但不能打乱剩余字符的前后顺序。

## 示例

### 示例 1

```text
输入：text1 = abcde, text2 = ace
输出：3
解释：最长公共子序列是 ace，长度为 3。
```

### 示例 2

```text
输入：text1 = abc, text2 = abc
输出：3
解释：最长公共子序列是 abc。
```

### 示例 3

```text
输入：text1 = abc, text2 = def
输出：0
解释：两个字符串没有公共子序列。
```

## 题意理解

这道题问的不是：

- 两个字符串里有没有相同字符

而是问：

- 能不能从两个字符串中各自删掉一些字符
- 让它们剩下来的部分完全一样
- 并且这个一样的部分尽可能长

例如：

```text
text1 = abcde
text2 = ace
```

虽然 `ace` 在 `text1` 中不是连续的，
但顺序是对的：

- `a`
- `c`
- `e`

所以它是一个合法的公共子序列。

## 为什么适合用动态规划

当我们比较两个字符串时，
经常会遇到这样的子问题：

- `text1` 前 3 个字符和 `text2` 前 2 个字符的答案是多少
- `text1` 前 4 个字符和 `text2` 前 5 个字符的答案是多少

这些更小的前缀问题会被反复使用。

这正是动态规划的典型特征：

- 大问题依赖小问题
- 小问题会重复出现

所以我们可以把这些前缀问题的答案保存起来。

## 动态规划定义

定义：

```text
dp[i][j] = text1 的前 i 个字符 和 text2 的前 j 个字符 的最长公共子序列长度
```

这里要特别注意：

- `dp[i][j]` 比较的是“前 `i` 个字符”和“前 `j` 个字符”
- 不是下标 `i` 和下标 `j` 的字符本身

例如：

- `dp[0][j]` 表示第一个字符串为空时的答案
- `dp[i][0]` 表示第二个字符串为空时的答案
- `dp[m][n]` 表示整个问题的答案

## 为什么要开 `m + 1` 行、`n + 1` 列

假设：

```python
m = len(text1)
n = len(text2)
```

我们需要表示：

- 前 `0` 个字符
- 前 `1` 个字符
- ...
- 前 `m` 个字符

所以行数要开到 `m + 1`。

列也是同样的道理，
需要从 `0` 到 `n`，
所以列数要开到 `n + 1`。

这也是为什么代码里通常写成：

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]
```

## 为什么初始值都是 0

当其中一个字符串为空时，
最长公共子序列长度一定是 `0`。

例如：

- 空串和任何字符串的最长公共子序列都是 `0`

所以：

```text
dp[0][j] = 0
dp[i][0] = 0
```

这也就是整个动态规划的边界条件。

## 状态转移方程

对于 `dp[i][j]`，
我们看的是：

- `text1` 的第 `i` 个字符
- `text2` 的第 `j` 个字符

因为 Python 下标从 `0` 开始，
所以实际对应的是：

```python
text1[i - 1]
text2[j - 1]
```

### 情况 1：当前两个字符相等

如果：

```python
text1[i - 1] == text2[j - 1]
```

说明这两个字符可以作为公共子序列的最后一个字符。

那么答案就是：

```text
dp[i - 1][j - 1] + 1
```

也就是：

- 前面的前缀先求出最长公共子序列
- 再把当前这个相同字符接上去

所以：

```text
dp[i][j] = dp[i - 1][j - 1] + 1
```

### 情况 2：当前两个字符不相等

如果：

```python
text1[i - 1] != text2[j - 1]
```

那这两个字符不可能同时作为公共子序列的最后一个字符。

这时只能二选一：

- 不看 `text1[i - 1]`，去看 `dp[i - 1][j]`
- 不看 `text2[j - 1]`，去看 `dp[i][j - 1]`

取更大的那个：

```text
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

## 为什么“不相等”时不用看 `dp[i - 1][j - 1]`

很多人会疑惑：

既然当前两个字符不相等，
是不是也该比较：

```text
dp[i - 1][j - 1]
```

其实不需要单独比较。

因为：

- `dp[i - 1][j]` 一定不小于 `dp[i - 1][j - 1]`
- `dp[i][j - 1]` 也一定不小于 `dp[i - 1][j - 1]`

原因是：

- 比较的字符串更长了，可选择的字符更多
- 最优解不会比更短前缀更差

所以只比较：

```text
max(dp[i - 1][j], dp[i][j - 1])
```

就够了。

## 用示例手推一遍

以：

```text
text1 = abcde
text2 = ace
```

为例。

设：

- `m = 5`
- `n = 3`

所以 `dp` 是一个 `6 x 4` 的表。

### 1. 比较 `a` 和 `a`

它们相等，
所以：

```text
dp[1][1] = dp[0][0] + 1 = 1
```

### 2. 继续比较 `ab` 和 `a`

当前字符 `b` 和 `a` 不相等，
所以：

```text
dp[2][1] = max(dp[1][1], dp[2][0]) = max(1, 0) = 1
```

### 3. 比较 `abc` 和 `ac`

当前字符 `c` 和 `c` 相等，
所以：

```text
dp[3][2] = dp[2][1] + 1 = 2
```

这表示当前最长公共子序列可以是：

```text
ac
```

### 4. 最后比较整个 `abcde` 和 `ace`

最后会在 `e` 和 `e` 相等时得到：

```text
dp[5][3] = dp[4][2] + 1 = 3
```

所以最终答案是：

```text
3
```

## 为什么要用两层循环

外层循环：

```python
for i in range(1, m + 1):
```

表示：

- 依次计算 `text1` 前 `i` 个字符的情况

内层循环：

```python
for j in range(1, n + 1):
```

表示：

- 依次计算 `text2` 前 `j` 个字符的情况

所以两层循环本质上是在：

- 枚举所有前缀组合
- 把整张 `dp` 表一格一格填出来

## 算法步骤

1. 令 `m = len(text1)`，`n = len(text2)`
2. 定义二维数组 `dp`
3. 初始化第一行和第一列为 `0`
4. 从 `i = 1` 到 `m` 遍历
5. 从 `j = 1` 到 `n` 遍历
6. 如果 `text1[i - 1] == text2[j - 1]`，则 `dp[i][j] = dp[i - 1][j - 1] + 1`
7. 否则 `dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`
8. 返回 `dp[m][n]`

## 复杂度分析

### 时间复杂度

`O(m × n)`

因为：

- 一共有 `m * n` 个状态
- 每个状态只做常数次计算

### 空间复杂度

`O(m × n)`

因为：

- 使用了一个 `m + 1` 行、`n + 1` 列的二维数组

如果进一步优化，
可以把空间压缩到：

```text
O(min(m, n))
```

## Python 参考实现（详细注释）

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)

        # dp[i][j] 表示 text1 前 i 个字符 和 text2 前 j 个字符 的最长公共子序列长度
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[m][n]
```

## 这段代码最值得记住的地方

核心就是两句：

```python
if text1[i - 1] == text2[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + 1
else:
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

你可以这样记：

- 相等：一起接到前面对角线后面，所以 `+1`
- 不等：删掉其中一个字符试试，所以取“上面”和“左边”的最大值

## 常见错误

### 1. 把“子序列”看成“子串”

子序列：

- 不要求连续

子串：

- 必须连续

这道题求的是子序列，不是子串。

### 2. 忘了 `i - 1` 和 `j - 1`

因为：

- `dp[i][j]` 表示前 `i` 个字符
- 真正访问字符串字符时，下标要减一

所以要写成：

```python
text1[i - 1]
text2[j - 1]
```

### 3. 二维数组初始化写错

不要写成：

```python
dp = [[0] * (n + 1)] * (m + 1)
```

因为这样会让多行引用同一个列表，
修改一行会影响其他行。

正确写法是：

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]
```

### 4. 把不相等时的转移写错

不相等时不是：

```python
dp[i][j] = dp[i - 1][j - 1]
```

而是：

```python
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

因为你可以选择跳过其中一个字符。

## 适合自己默写的精简版

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[m][n]
```

## 一句话总结

这道题的关键是：

**用 `dp[i][j]` 记录两个字符串前缀的最长公共子序列长度，相等时接对角线 `+1`，不相等时取上方和左方的较大值。**
