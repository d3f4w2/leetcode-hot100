# 053. 最大子数组和

## 所属专题
- 动态规划

## 题目描述

给你一个整数数组 `nums`，请你找出一个具有最大和的 **连续子数组**（子数组最少包含一个元素），返回其最大和。

这里的“子数组”有两个关键词：

- 连续
- 至少包含一个元素

也就是说：

- 不能跳着选
- 不能选空数组

## 示例

### 示例 1

```text
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6。
```

### 示例 2

```text
输入：nums = [1]
输出：1
```

### 示例 3

```text
输入：nums = [5,4,-1,7,8]
输出：23
```

## 题意理解

这道题不是让我们从数组里随便挑几个数让和最大，
而是要求：

- 选出来的这一段必须是连续的
- 并且这段连续区间的和要尽可能大

比如：

```text
[4, -1, 2, 1]
```

这是一个合法子数组，因为它在原数组中是连续的一段。

但如果你想选：

```text
[4, 2, 1]
```

虽然和更大，
但它不是连续的一段，
所以不符合题意。

因此这道题的本质是：

- 以每个位置为结尾时
- 最优的连续子数组和是多少

这正是动态规划非常经典的切入点。

## 最直接的想法：枚举所有子数组

最容易想到的方法是：

- 枚举每个起点
- 再枚举每个终点
- 计算这段子数组的和
- 不断更新最大值

这样当然能做出来，
但问题在于：

- 子数组的数量很多
- 如果每次还重新求和，效率会更低

即使通过前缀和把求区间和优化掉，
整体仍然要枚举很多区间。

所以我们应该思考：

**能不能在遍历数组的过程中，顺手维护“以当前位置结尾的最优答案”？**

## 优化思路：动态规划（Kadane 算法）

### 核心想法

定义：

```text
dp[i] = 以 nums[i] 结尾的最大子数组和
```

这个定义非常关键。

注意它不是：

- 前 `i` 个元素里的最大子数组和

而是：

- **必须以 `nums[i]` 作为结尾** 的最大子数组和

为什么这样定义好？

因为当我们走到 `nums[i]` 时，
以它结尾的连续子数组只有两种选择：

### 情况 1：从 `nums[i]` 自己重新开始

也就是前面的部分不要了，
当前子数组只有一个元素：

```text
nums[i]
```

### 情况 2：接在前面的最优连续子数组后面

如果前一个位置结尾的最大子数组和是 `dp[i - 1]`，
那当前就可以把 `nums[i]` 接在后面：

```text
dp[i - 1] + nums[i]
```

那么两种情况取最大值即可：

```text
dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

这就是这道题最核心的状态转移方程。

## 为什么这个转移是对的

关键在于“连续”这个条件。

如果一个最大子数组必须以 `i` 结尾，
那么它前面的那一部分：

- 要么根本不要，直接从 `nums[i]` 开始
- 要么就一定是“以 `i - 1` 结尾的某个连续子数组”

而既然我们要求最优，
那前面的那一段自然应该选：

- 以 `i - 1` 结尾的最大子数组和

所以转移只能是：

```text
max(nums[i], dp[i - 1] + nums[i])
```

没有第三种情况。

## 用示例手推一遍

以：

```text
nums = [-2,1,-3,4,-1,2,1,-5,4]
```

为例。

我们用：

- `current_sum` 表示当前“以当前位置结尾”的最大子数组和
- `max_sum` 表示全局最大值

### 初始状态

第一个元素只能自己单独成数组：

- `current_sum = -2`
- `max_sum = -2`

### 处理 `1`

比较：

- 只取自己：`1`
- 接在前面后面：`-2 + 1 = -1`

取更大值：

- `current_sum = 1`
- `max_sum = 1`

### 处理 `-3`

比较：

- 只取自己：`-3`
- 接在前面后面：`1 + (-3) = -2`

取更大值：

- `current_sum = -2`
- `max_sum = 1`

### 处理 `4`

比较：

- 只取自己：`4`
- 接在前面后面：`-2 + 4 = 2`

取更大值：

- `current_sum = 4`
- `max_sum = 4`

### 处理 `-1`

比较：

- 只取自己：`-1`
- 接在前面后面：`4 + (-1) = 3`

取更大值：

- `current_sum = 3`
- `max_sum = 4`

### 处理 `2`

比较：

- 只取自己：`2`
- 接在前面后面：`3 + 2 = 5`

取更大值：

- `current_sum = 5`
- `max_sum = 5`

### 处理 `1`

比较：

- 只取自己：`1`
- 接在前面后面：`5 + 1 = 6`

取更大值：

- `current_sum = 6`
- `max_sum = 6`

这时对应的连续子数组就是：

```text
[4, -1, 2, 1]
```

后面继续更新，
全局最大值也不会再超过 `6`。

所以最终答案是：

```text
6
```

## 为什么这样写

### 1. 负贡献前缀应该果断丢掉

如果前面那一段和是负数，
再把当前数字接上去，
只会让结果更差。

例如当前数字是 `4`：

- 单独开始：`4`
- 接在 `-2` 后面：`2`

显然不如直接从 `4` 开始。

这也是这道题的直觉核心：

- 前面的累计和如果已经拖后腿
- 就不如从当前位置重新开一段

### 2. `dp[i]` 只依赖 `dp[i - 1]`

状态转移公式是：

```text
dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

可以看出：

- 当前状态只和前一个状态有关

所以没有必要真的开一个完整数组，
我们只需要一个变量保存上一个状态即可。

### 3. 全局最优和局部最优要分开看

这道题里有两个层次：

- 局部最优：以当前位置结尾的最大子数组和
- 全局最优：整个数组中的最大子数组和

所以写代码时通常会维护两个变量：

- `current_sum`
- `max_sum`

其中：

- `current_sum` 用来做状态转移
- `max_sum` 用来记录最终答案

## 算法步骤

1. 用第一个元素初始化 `current_sum` 和 `max_sum`
2. 从第二个元素开始遍历数组
3. 对于当前元素 `nums[i]`，计算：
   - 直接从自己开始
   - 或者接在前一个连续子数组后面
4. 更新当前的最大连续子数组和 `current_sum`
5. 用 `current_sum` 更新全局最大值 `max_sum`
6. 遍历结束后返回 `max_sum`

## 复杂度分析

### 时间复杂度

`O(n)`

原因是：

- 只遍历了一次数组
- 每个位置只进行常数次计算

### 空间复杂度

`O(1)`

原因是：

- 只使用了两个额外变量
- 没有使用与数组长度成比例的额外空间

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        current_sum = nums[0]
        max_sum = nums[0]

        for i in range(1, len(nums)):
            # 要么从当前元素重新开始，
            # 要么接在前面的最大连续子数组后面
            current_sum = max(nums[i], current_sum + nums[i])

            # 更新全局最大值
            max_sum = max(max_sum, current_sum)

        return max_sum
```

## 这段代码最值得记住的地方

核心就是这两句：

```python
current_sum = max(nums[i], current_sum + nums[i])
max_sum = max(max_sum, current_sum)
```

第一句表示：

- 当前这段连续子数组要不要接着前面走
- 还是从当前位置重新开始

第二句表示：

- 每走到一个位置
- 都顺手更新一次全局答案

只要理解了这两句，
这道题基本就掌握了。

## 常见错误

### 1. 把题目理解成“挑若干个数让和最大”

这题必须满足：

- **子数组连续**

不能跳着挑元素。

### 2. 忘记处理全是负数的情况

例如：

```text
nums = [-3, -2, -5]
```

答案应该是：

```text
-2
```

也就是取单个元素 `-2`。

如果你把初始值写成 `0`，
就会错误地得到 `0`。

所以初始化一定要用：

- `nums[0]`

而不是 `0`。

### 3. 只维护了局部最优，没有维护全局最优

有些写法只更新：

- `current_sum`

但没有同步更新：

- `max_sum`

这样最后拿到的不一定是整段数组中的最大值。

### 4. 误以为必须开 `dp` 数组

虽然这题确实是动态规划，
但由于状态只依赖前一个位置，
完全可以压缩成两个变量。

## 适合自己默写的精简版本

```python
from typing import List


class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        current_sum = nums[0]
        max_sum = nums[0]

        for i in range(1, len(nums)):
            current_sum = max(nums[i], current_sum + nums[i])
            max_sum = max(max_sum, current_sum)

        return max_sum
```

## 一句话总结

这道题的关键是：

**用 `current_sum` 表示“以当前位置结尾的最大子数组和”，如果前面的和已经是负贡献，就从当前位置重新开始。**
