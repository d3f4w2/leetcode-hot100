# 198. 打家劫舍

## 所属专题
- 动态规划

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。

每间房内都藏有一定的现金，
影响你偷窃的唯一制约因素就是：

- 相邻的房屋装有相互连通的防盗系统
- 如果两间相邻的房屋在同一晚上被偷，系统会自动报警

给定一个代表每个房屋存放金额的非负整数数组 `nums`，
请你计算：

- 在不触动警报装置的情况下
- 一夜之内能够偷窃到的最高金额

## 示例

### 示例 1

```text
输入：nums = [1,2,3,1]
输出：4
解释：偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4。
```

### 示例 2

```text
输入：nums = [2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋（金额 = 2），偷窃 3 号房屋（金额 = 9），接着偷窃 5 号房屋（金额 = 1）。
     偷窃到的最高金额 = 2 + 9 + 1 = 12。
```

## 题意理解

这道题不是简单地“挑几个最大的数相加”。

因为题目有一个关键限制：

- **相邻的房屋不能同时偷**

所以当你决定偷某一间房时，
它左右紧挨着的那一间就不能再偷。

这意味着：

- 当前房屋偷不偷
- 会影响前一个房屋能不能选

这正是动态规划最常见的信号：

- 当前选择依赖前面的最优结果

换句话说，
这道题的本质是：

- 走到第 `i` 间房时
- 在“偷它”和“不偷它”之间做选择
- 看哪种方案得到的钱更多

## 最直接的想法：枚举所有偷法

最容易想到的方法是：

- 每间房都考虑“偷”或“不偷”
- 把所有可能方案都试一遍
- 最后找最大值

但这样会有很多重复计算。

例如：

- 前 3 间房的最优结果
- 在后续很多选择里都会反复被用到

所以暴力递归虽然可以想到，
但效率会比较差。

我们更应该考虑：

- 能不能把“前面若干间房的最优结果”保存下来
- 后面直接复用

这就是动态规划的核心思路。

## 优化思路：动态规划

### 核心想法

定义：

```text
dp[i] = 偷前 i 间房屋时，能够获得的最大金额
```

这里要注意：

- `dp[i]` 表示的是“前 `i` 间房”的最优答案
- 不是“第 `i` 间房一定要偷”的答案

那么对于第 `i` 间房（如果按下标理解是 `nums[i]`），
我们只有两种选择：

### 情况 1：不偷当前这间房

如果不偷当前房屋，
那么答案就和前一间房时一样：

```text
dp[i - 1]
```

### 情况 2：偷当前这间房

如果偷当前房屋，
那前一间房就一定不能偷。

所以能得到的钱是：

```text
dp[i - 2] + nums[i]
```

### 状态转移方程

两种情况取最大值：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

这就是这道题最核心的状态转移。

## 为什么这个转移是对的

因为对每一间房来说，
最终方案只可能分成两类：

- 当前房不偷
- 当前房偷

而且这两类已经把所有合法情况都覆盖了。

如果不偷当前房：

- 那最优结果就等于前一间房时的最优结果

如果偷当前房：

- 前一间一定不能偷
- 所以只能接在前两间房的最优结果后面

因此：

```text
max(不偷当前房, 偷当前房)
```

也就是：

```text
max(dp[i - 1], dp[i - 2] + nums[i])
```

## 用示例手推一遍

以：

```text
nums = [2,7,9,3,1]
```

为例。

### 第 1 间房

只有一间房时，
最优就是偷它：

```text
dp[0] = 2
```

### 第 2 间房

前两间房只能二选一：

- 偷第 1 间：`2`
- 偷第 2 间：`7`

所以：

```text
dp[1] = max(2, 7) = 7
```

### 第 3 间房

现在考虑金额 `9`：

- 不偷第 3 间：答案是 `dp[1] = 7`
- 偷第 3 间：答案是 `dp[0] + 9 = 2 + 9 = 11`

所以：

```text
dp[2] = max(7, 11) = 11
```

### 第 4 间房

金额是 `3`：

- 不偷第 4 间：`dp[2] = 11`
- 偷第 4 间：`dp[1] + 3 = 7 + 3 = 10`

所以：

```text
dp[3] = max(11, 10) = 11
```

### 第 5 间房

金额是 `1`：

- 不偷第 5 间：`dp[3] = 11`
- 偷第 5 间：`dp[2] + 1 = 11 + 1 = 12`

所以：

```text
dp[4] = max(11, 12) = 12
```

最终答案是：

```text
12
```

## 为什么这样写

### 1. 每间房都只有“偷”或“不偷”两种状态

这道题虽然是选择题，
但并不复杂，
因为每一步的决策非常明确：

- 偷当前房
- 不偷当前房

这使得状态转移非常自然。

### 2. 偷当前房时，只能接 `i - 2`

这是这题最关键的限制。

因为相邻房屋不能同时偷，
所以：

- 如果偷第 `i` 间
- 那么第 `i - 1` 间一定不能偷

所以只能把当前金额接到：

- `dp[i - 2]`

后面。

### 3. 本质上是在维护“到当前位置为止的最优解”

`dp[i]` 并不是局部贪心，
而是：

- 前 `i` 间房的全局最优结果

这样后面的决策就能直接复用前面的最佳答案。

### 4. 状态只依赖前两个位置，可以压缩空间

从转移方程：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

可以看出：

- 当前状态只依赖 `dp[i - 1]`
- 和 `dp[i - 2]`

所以没必要开整个数组，
只要两个变量滚动维护即可。

## 算法步骤

1. 如果数组为空，返回 `0`
2. 如果只有一间房，返回 `nums[0]`
3. 定义两个变量：
   - `prev2` 表示前前一个状态
   - `prev1` 表示前一个状态
4. 从第 `3` 间房开始遍历
5. 当前状态为：`max(prev1, prev2 + nums[i])`
6. 滚动更新两个变量
7. 最后返回 `prev1`

## 复杂度分析

### 时间复杂度

`O(n)`

原因是：

- 只遍历了一次数组
- 每个位置只进行常数次计算

### 空间复杂度

`O(1)`

原因是：

- 只使用了几个额外变量
- 没有开与数组长度成比例的额外空间

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums:
            return 0
        if len(nums) == 1:
            return nums[0]

        prev2 = nums[0]
        prev1 = max(nums[0], nums[1])

        for i in range(2, len(nums)):
            current = max(prev1, prev2 + nums[i])
            prev2 = prev1
            prev1 = current

        return prev1
```

## 这段代码最值得记住的地方

最核心的是这句：

```python
current = max(prev1, prev2 + nums[i])
```

它刚好对应两种选择：

- `prev1`：不偷当前房
- `prev2 + nums[i]`：偷当前房

只要理解这句，
整道题的思路就清楚了。

## 常见错误

### 1. 把这题理解成“选几个最大的数”

这题最大的限制是：

- 相邻元素不能同时选

所以不能简单排序或贪心地挑最大值。

### 2. 没有处理边界情况

这题最常见的边界有两个：

- 空数组
- 只有一个元素

如果不先处理，
后面的初始化容易越界。

### 3. 状态定义混乱

有些人会把：

- `dp[i]` 定义成“偷第 `i` 间房时的最大金额”

这样也不是不能做，
但更容易把“不偷当前房”的情况绕晕。

这题最清晰的定义通常是：

- 前 `i` 间房的最优结果

### 4. 更新顺序写错

做空间优化时，
一定要先算出 `current`，
再更新：

- `prev2 = prev1`
- `prev1 = current`

如果顺序写乱，
会把旧状态覆盖掉。

## 适合自己默写的精简版本

```python
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums:
            return 0
        if len(nums) == 1:
            return nums[0]

        prev2 = nums[0]
        prev1 = max(nums[0], nums[1])

        for i in range(2, len(nums)):
            prev2, prev1 = prev1, max(prev1, prev2 + nums[i])

        return prev1
```

## 一句话总结

这道题的关键是：

**对每间房只做“偷”或“不偷”两种选择，并用动态规划维护到当前位置为止的最大收益。**
