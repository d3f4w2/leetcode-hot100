# 056. 合并区间

## 所属专题

- 贪心

## 题目描述

以数组 `intervals` 表示若干个区间的集合，
其中单个区间为：

```text
intervals[i] = [starti, endi]
```

请你合并所有重叠的区间，
并返回一个 **不重叠的区间数组**。

返回结果需要：

- 恰好覆盖输入中的所有区间
- 所有能合并的区间都已经合并完成

## 示例

### 示例 1

```text
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠，将它们合并为 [1,6]。
```

### 示例 2

```text
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：[1,4] 和 [4,5] 也算重叠，因为它们首尾相接。
```

## 题意理解

这道题不是让我们：

- 统计有多少个区间
- 也不是判断某两个区间是否重叠

而是要求我们：

- 把整个区间集合整理一下
- 让所有有重叠的部分合并成更大的区间
- 最后得到一组互不重叠的结果

比如：

```text
[[1,3],[2,6],[8,10],[15,18]]
```

其中：

- `[1,3]` 和 `[2,6]` 有重叠
- `[8,10]` 和前面不重叠
- `[15,18]` 和前面也不重叠

所以结果就是：

```text
[[1,6],[8,10],[15,18]]
```

你可以把这道题理解成：

- 先把区间按顺序排好
- 再从左到右扫一遍
- 遇到能接起来的就合并
- 接不起来的就单独开一个新区间

## 最直接的想法：不停比较区间是否重叠

最容易想到的办法是：

- 拿一个区间去和后面的区间逐个比较
- 如果重叠，就合并
- 合并后再继续和其他区间比较

这个思路虽然能做，
但如果区间很多，
比较过程会比较乱，
而且效率也不够高。

问题的关键在于：

- 如果区间顺序是乱的
- 你很难只通过当前局部信息，判断后面还会不会出现可合并的区间

所以我们需要先做一件非常重要的事：

- 排序

## 优化思路：排序 + 贪心

### 核心想法

先按区间的起点从小到大排序：

```python
intervals.sort(key=lambda x: x[0])
```

排序之后，
区间就会按“从左到右”的顺序排好。

这样我们在遍历时，
只需要关心：

- 当前区间能不能和结果里的最后一个区间合并

如果能合并，就更新右边界。

如果不能合并，就把当前区间作为一个新的独立区间加入结果。

### 为什么排序后只看结果最后一个区间就够了

因为排序后，
后面的区间起点只会越来越大。

这意味着：

- 如果当前区间和结果最后一个区间都不能重叠
- 那它更不可能和结果中更前面的区间重叠

所以每次只判断：

- `当前区间`
- `result[-1]`

就足够了。

这就是这道题的贪心本质：

- 每一步都尽量把当前能合并的区间合并掉
- 不需要回头重算前面的结果

### 两个区间什么时候算重叠

设：

- 上一个合并结果是 `[a, b]`
- 当前区间是 `[c, d]`

如果：

```text
c <= b
```

就说明它们有重叠，或者首尾相接，
此时应该合并。

合并后的新区间是：

```text
[a, max(b, d)]
```

如果：

```text
c > b
```

就说明它们完全分开，
当前区间应该单独加入结果。

## 用示例手推一遍

以示例 1 为例：

```text
intervals = [[1,3],[2,6],[8,10],[15,18]]
```

### 第 1 步：先排序

这组数据本身已经按起点排好序：

```text
[[1,3],[2,6],[8,10],[15,18]]
```

### 第 2 步：先把第一个区间放进结果

初始时：

```text
result = [[1,3]]
```

### 第 3 步：看 `[2,6]`

比较：

- 当前区间起点是 `2`
- 结果最后一个区间终点是 `3`

因为：

```text
2 <= 3
```

说明有重叠，
所以合并。

合并后：

```text
result = [[1,6]]
```

因为新的右边界是：

```text
max(3, 6) = 6
```

### 第 4 步：看 `[8,10]`

比较：

- 当前起点 `8`
- 结果最后一个区间终点 `6`

因为：

```text
8 > 6
```

说明不重叠，
所以直接加入结果：

```text
result = [[1,6],[8,10]]
```

### 第 5 步：看 `[15,18]`

比较：

- 当前起点 `15`
- 结果最后一个区间终点 `10`

因为：

```text
15 > 10
```

仍然不重叠，
所以加入结果：

```text
result = [[1,6],[8,10],[15,18]]
```

最终答案就是：

```text
[[1,6],[8,10],[15,18]]
```

## 为什么这样写

### 1. 排序是这道题的前提

如果不排序，
区间顺序可能是乱的，
你就无法稳定地从左到右合并。

排序之后，
每个新区间只需要跟当前合并结果的最后一个区间比较，
逻辑会非常清楚。

### 2. 贪心地维护“当前合并区间”就够了

在扫描过程中，
`result[-1]` 就表示：

- 到目前为止，最后一个已经整理好的区间

如果当前区间能和它合并，
那就尽量扩展右边界。

如果不能合并，
那就说明它应该成为新的独立区间。

### 3. 只更新右边界，不更新左边界

因为排序后：

- 当前区间的起点一定不会比前一个结果区间更小

所以一旦发生合并，
左边界肯定还是原来的左边界，
只需要更新右边界即可。

### 4. 首尾相接也要算重叠

比如：

```text
[1,4] 和 [4,5]
```

题目默认这种情况也要合并。

所以判断条件要写成：

```python
if interval[0] <= result[-1][1]:
```

而不是严格小于。

## 算法步骤

1. 如果 `intervals` 为空，直接返回 `[]`
2. 按每个区间的起点从小到大排序
3. 先把排序后的第一个区间放入结果 `result`
4. 从第二个区间开始遍历
5. 如果当前区间起点 `<=` 结果最后一个区间的终点，说明重叠，进行合并
6. 合并时只需要更新结果最后一个区间的终点为两者终点的较大值
7. 如果当前区间起点 `>` 结果最后一个区间的终点，说明不重叠，直接加入结果
8. 遍历结束后返回 `result`

## 复杂度分析

设区间个数为 `n`。

### 时间复杂度

`O(n log n)`

原因：

- 排序需要 `O(n log n)`
- 排序后只遍历一遍区间，代价是 `O(n)`

所以总复杂度由排序主导。

### 空间复杂度

如果不考虑返回结果本身占用的空间，
通常可以写作：

`O(1)`

因为我们只是在结果列表末尾进行合并或追加。

如果把排序过程的内部额外开销也严格算上，
则会和具体排序实现有关。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        # 边界情况：如果没有区间，直接返回空列表。
        if not intervals:
            return []

        # 先按区间起点排序。
        intervals.sort(key=lambda interval: interval[0])

        # 先把第一个区间放进结果里，
        # 后面依次和它比较、合并。
        result = [intervals[0]]

        for interval in intervals[1:]:
            # 取出当前结果中的最后一个区间。
            last_interval = result[-1]

            # 如果当前区间的起点 <= 最后一个区间的终点，
            # 说明它们重叠，或者首尾相接，可以合并。
            if interval[0] <= last_interval[1]:
                # 合并时左边界不用变，
                # 只需要把右边界更新为更大的那个。
                last_interval[1] = max(last_interval[1], interval[1])
            else:
                # 如果不重叠，就把当前区间直接加入结果。
                result.append(interval)

        return result
```

## 这段代码最值得记住的地方

这题最核心的其实就是这几句：

```python
intervals.sort(key=lambda interval: interval[0])

if interval[0] <= result[-1][1]:
    result[-1][1] = max(result[-1][1], interval[1])
else:
    result.append(interval)
```

它表达的意思是：

- 先按起点排序
- 如果和最后一个结果区间能接上，就合并
- 接不上，就单独开新区间

## 常见错误

### 1. 忘记先排序

如果不排序，
合并过程就没有稳定的从左到右顺序，
很容易漏掉本该合并的区间。

### 2. 空数组没有单独处理

如果直接写：

```python
result = [intervals[0]]
```

那当 `intervals = []` 时就会报错。

所以最好先写：

```python
if not intervals:
    return []
```

### 3. 把判断条件写成 `<`

如果写成：

```python
if interval[0] < result[-1][1]:
```

那像 `[1,4]` 和 `[4,5]` 这种首尾相接的情况就不会被合并。

正确写法是：

```python
<=
```

### 4. 合并时错误更新了左边界

排序后，
当前结果区间的左边界一定更靠左，
所以发生合并时只更新右边界就够了。

### 5. 不小心修改了不该修改的对象

这份代码里：

```python
result = [intervals[0]]
```

会让 `result` 中的区间和 `intervals` 中的部分对象共享引用。

在 LeetCode 这类题里通常没问题，
但如果你想写得更稳妥，
也可以在加入结果时使用拷贝：

```python
result = [intervals[0][:]]
```

## 适合你自己再写一遍的版本

```python
from typing import List


class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if not intervals:
            return []

        intervals.sort(key=lambda interval: interval[0])
        result = [intervals[0]]

        for interval in intervals[1:]:
            if interval[0] <= result[-1][1]:
                result[-1][1] = max(result[-1][1], interval[1])
            else:
                result.append(interval)

        return result
```

## 一句话总结

这道题的关键是：

**先按区间起点排序，再从左到右扫描；能和结果最后一个区间重叠就合并，不能重叠就直接加入结果。**
