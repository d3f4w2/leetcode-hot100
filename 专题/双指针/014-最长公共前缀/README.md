# 014. 最长公共前缀

## 所属专题

- 双指针

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

## 示例

### 示例 1

```text
输入：strs = ["flower","flow","flight"]
输出："fl"
```

### 示例 2

```text
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入中不存在公共前缀。
```

## 题意理解

这道题要求我们在一个字符串数组里，
找到所有字符串开头那一段“完全相同”的部分。

注意这里找的是：

- 公共前缀
- 必须从字符串的第一个字符开始

不是：

- 公共子串
- 也不是公共子序列

例如：

```text
["flower","flow","flight"]
```

它们的公共前缀是：

```text
"fl"
```

因为：

- 第 1 个字符都是 `f`
- 第 2 个字符都是 `l`
- 到第 3 个字符时已经不同了

所以答案就是 `"fl"`。

## 最直接的想法：横向扫描

最自然的思路是：

1. 先把第一个字符串当成当前公共前缀 `prefix`
2. 用它去和后面的每个字符串比较
3. 如果当前字符串不是以 `prefix` 开头，就不断缩短 `prefix`
4. 直到当前字符串以它开头为止
5. 最后剩下的 `prefix`，就是所有字符串的最长公共前缀

例如：

```text
strs = ["flower","flow","flight"]
```

一开始：

```text
prefix = "flower"
```

拿它和 `"flow"` 比较：

- `"flow"` 不是以 `"flower"` 开头
- 把 `prefix` 缩短成 `"flowe"`
- 还不行，再缩成 `"flow"`
- 这时可以匹配

然后再拿 `"flow"` 和 `"flight"` 比较：

- `"flight"` 不是以 `"flow"` 开头
- 缩成 `"flo"`
- 还不行，缩成 `"fl"`
- 这时可以匹配

最终答案就是：

```text
"fl"
```

## 为什么这样做是对的

这道题最关键的一点是：

**所有字符串的最长公共前缀，一定是第一个字符串的某个前缀。**

所以我们完全可以从第一个字符串出发，
逐步把候选答案缩短。

每次遇到一个新字符串时：

- 如果它不能匹配当前 `prefix`
- 说明当前 `prefix` 太长了
- 必须缩短

而且缩短的时候只需要“从后往前删字符”，
因为：

- 如果一个字符串不是公共前缀
- 那它的更长版本也不可能是公共前缀

所以这个过程一定会朝着正确答案不断逼近。

## 用示例手推一遍

以：

```text
strs = ["flower","flow","flight"]
```

为例。

### 初始状态

先把第一个字符串当作候选前缀：

```text
prefix = "flower"
```

### 和 `"flow"` 比较

检查：

```text
"flow".startswith("flower")
```

不成立，于是不断缩短：

```text
"flowe"
"flow"
```

当 `prefix = "flow"` 时，匹配成功。

此时：

```text
prefix = "flow"
```

### 和 `"flight"` 比较

检查：

```text
"flight".startswith("flow")
```

不成立，继续缩短：

```text
"flo"
"fl"
```

当 `prefix = "fl"` 时，匹配成功。

此时：

```text
prefix = "fl"
```

所有字符串都比较完成后，
最终答案就是：

```text
"fl"
```

## 算法步骤

1. 如果字符串数组为空，直接返回 `""`
2. 把第一个字符串设为当前公共前缀 `prefix`
3. 从第二个字符串开始，依次和 `prefix` 比较
4. 只要当前字符串不是以 `prefix` 开头，就不断删掉 `prefix` 的最后一个字符
5. 如果 `prefix` 被删成空字符串，直接返回 `""`
6. 所有字符串比较结束后，返回 `prefix`

## 为什么时间复杂度是 `O(S)`

设所有字符串的总字符数是 `S`。

虽然代码里有：

- 一个 `for`
- 里面还有一个 `while`

但 `prefix` 只会不断变短，
不会反复变长。

也就是说：

- 每删掉一个字符，就真的少一个字符
- 整个过程中被删掉的字符总数是有限的

因此整体时间复杂度通常记为：

```text
O(S)
```

## 复杂度分析

### 时间复杂度

`O(S)`

其中 `S` 是所有字符串字符总数。

### 空间复杂度

`O(1)`

只使用了若干额外变量。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""

        # 先把第一个字符串当作当前公共前缀。
        prefix = strs[0]

        for i in range(1, len(strs)):
            # 如果当前字符串不以 prefix 开头，
            # 就不断缩短 prefix，直到匹配为止。
            while not strs[i].startswith(prefix):
                prefix = prefix[:-1]

                # 已经缩短到空串，说明不存在公共前缀。
                if not prefix:
                    return ""

        return prefix
```

## 这段代码最值得记住的地方

你真正需要记住的主线是：

```python
prefix = strs[0]

for i in range(1, len(strs)):
    while not strs[i].startswith(prefix):
        prefix = prefix[:-1]
        if not prefix:
            return ""
```

它背后的核心思想就是：

**把第一个字符串当成候选答案，只要发现它对当前字符串来说太长了，就不断缩短，直到重新成为公共前缀。**

## 另一种思路：纵向扫描

除了横向扫描之外，
这道题还有一种常见写法叫“纵向扫描”。

它的思路是：

- 先看所有字符串的第 `0` 个字符是否相同
- 再看第 `1` 个字符是否相同
- 再看第 `2` 个字符是否相同
- 一旦某一列字符不同，就停止

例如：

```text
["flower","flow","flight"]
```

按列来看：

- 第 0 列：`f, f, f`，相同
- 第 1 列：`l, l, l`，相同
- 第 2 列：`o, o, i`，不同

所以答案是前两列组成的：

```text
"fl"
```

这种方法的时间复杂度同样是 `O(S)`，
本质上也是逐字符比较。

## 常见错误

### 1. 忘记处理空数组

如果输入是：

```text
[]
```

就应该直接返回：

```text
""
```

### 2. 把“公共前缀”理解成“公共子串”

公共前缀必须从开头开始，
不能跳过前面的字符。

例如：

```text
["abc","zab"]
```

虽然它们都包含 `"ab"`，
但 `"ab"` 不是公共前缀，
答案应该是：

```text
""
```

### 3. 只比较前两个字符串

公共前缀必须对数组里的所有字符串都成立，
不是只对前两个成立就可以。

### 4. `prefix` 缩短后忘记继续检查

有些人会只删一次字符就继续往后走，
这样不够。

必须一直缩短到：

- 当前字符串能匹配 `prefix`

或者：

- `prefix` 变成空串

为止。

## 一句话总结

这道题的关键是：

**先把第一个字符串当作候选公共前缀，再依次和后面的字符串比较；只要不匹配，就不断缩短候选前缀，直到得到所有字符串都共享的最长前缀。**
