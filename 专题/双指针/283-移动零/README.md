# 283. 移动零

## 所属专题
- 双指针

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

注意：

- 必须在不复制数组的情况下原地对数组进行操作
- 也就是说，不能额外新建一个同样大小的数组来存答案

## 示例

### 示例 1

```text
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]
```

### 示例 2

```text
输入：nums = [0]
输出：[0]
```

## 题意理解

这道题的要求其实有两个：

- 把所有的 `0` 都挪到数组末尾
- 保持所有非零元素原来的相对顺序不变

比如：

- 原数组是 `[0,1,0,3,12]`
- 非零元素按顺序是 `1、3、12`
- 所以处理后必须是 `[1,3,12,0,0]`

这里最容易忽略的一点是：

**非零元素的相对顺序不能乱。**

也就是说，这道题不是简单地把 `0` 和非零数分开就行，
而是要在“原地修改”的前提下，完成一次稳定移动。

## 最直接的想法：新开一个数组

最容易想到的方法是：

- 先遍历一遍数组
- 把所有非零元素按顺序放进新数组
- 再把剩下的位置补成 `0`

这样做当然能得到正确答案，
而且逻辑也很直观。

但问题在于：

- 额外开了一个新数组
- 不符合题目“原地操作”的要求

所以我们要继续想：

**能不能直接在原数组上完成这件事？**

## 优化思路：双指针

### 核心想法

我们可以把数组分成两个区域来理解：

- 左边：已经处理好的非零元素区域
- 右边：还没有处理的区域

于是定义两个指针：

- `left`：指向“下一个非零元素应该放的位置”
- `right`：从左到右遍历整个数组，负责寻找非零元素

### `left` 和 `right` 分别做什么

#### `right`：负责扫描数组

`right` 会从头到尾遍历：

- 如果遇到 `0`，先跳过
- 如果遇到非零元素，说明它应该被放到前面去

#### `left`：负责维护非零区间

`left` 表示：

- 到目前为止，前面已经放好了多少个非零元素
- 当前这个非零元素应该放到哪里

每当我们找到一个非零元素并处理完后：

- `left += 1`

这意味着“下一个非零元素应该放到更靠后一位”。

### 为什么交换就可以

当 `nums[right] != 0` 时：

- 说明 `nums[right]` 是一个应该被保留顺序的非零元素
- 它应该被放到 `left` 所在的位置

于是可以直接交换：

```python
nums[left], nums[right] = nums[right], nums[left]
```

这样有两种情况：

#### 情况 1：`left == right`

说明当前这个非零元素本来就在它该在的位置上。

交换虽然执行了，但实际上没有影响。

#### 情况 2：`left < right`

说明前面出现过 `0`，
现在这个非零元素需要被提到前面来。

交换后：

- 非零元素到了正确位置
- `0` 被换到后面去

随着遍历继续进行，所有 `0` 会自然被“挤”到数组末尾。

## 用示例手推一遍

以 `nums = [0,1,0,3,12]` 为例：

初始时：

- `left = 0`
- `right` 从 `0` 开始向右遍历

### 第 1 步：`right = 0`

- `nums[right] = 0`
- 跳过，不处理
- `left` 仍然是 `0`

数组不变：

```text
[0,1,0,3,12]
```

### 第 2 步：`right = 1`

- `nums[right] = 1`
- 这是非零元素，要放到 `left = 0` 的位置
- 交换 `nums[0]` 和 `nums[1]`

交换后：

```text
[1,0,0,3,12]
```

然后：

- `left += 1`
- `left = 1`

### 第 3 步：`right = 2`

- `nums[right] = 0`
- 跳过
- `left` 还是 `1`

数组不变：

```text
[1,0,0,3,12]
```

### 第 4 步：`right = 3`

- `nums[right] = 3`
- 这是非零元素，要放到 `left = 1`
- 交换 `nums[1]` 和 `nums[3]`

交换后：

```text
[1,3,0,0,12]
```

然后：

- `left = 2`

### 第 5 步：`right = 4`

- `nums[right] = 12`
- 这是非零元素，要放到 `left = 2`
- 交换 `nums[2]` 和 `nums[4]`

交换后：

```text
[1,3,12,0,0]
```

然后：

- `left = 3`

遍历结束，答案就是：

```text
[1,3,12,0,0]
```

## 为什么这样写

### 1. `left` 永远指向“下一个非零元素该去的位置”

这让整个过程非常清晰：

- 找到非零数
- 放到前面
- `left` 后移

### 2. `right` 只负责扫描，不负责决定最终位置

`right` 的任务很简单：

- 从左到右找非零元素

真正决定“放哪里”的，是 `left`。

### 3. 这种写法天然保持了非零元素的相对顺序

因为我们是按照 `right` 从左到右遇到非零元素的顺序，
把它们依次放到前面去。

也就是说：

- 先遇到的非零元素，先被放入前面的空位
- 后遇到的非零元素，只会放到更后的位置

所以顺序不会乱。

### 4. 这是原地操作，不需要额外数组

我们只用了两个指针变量：

- `left`
- `right`

所以空间复杂度是 `O(1)`。

## 算法步骤

1. 定义指针 `left = 0`
2. 用 `right` 从左到右遍历数组
3. 如果 `nums[right] != 0`，就交换 `nums[left]` 和 `nums[right]`
4. 然后让 `left += 1`
5. 遍历结束后，数组就已经完成调整

## 复杂度分析

### 时间复杂度

`O(n)`

原因是：

- `right` 只从左到右遍历一遍数组
- 每个元素最多参与一次判断和有限次交换

### 空间复杂度

`O(1)`

原因是：

- 只用了常数个额外变量
- 没有申请新的数组

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        left = 0

        for right in range(len(nums)):
            if nums[right] != 0:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
```

## 这段代码最值得记住的地方

最核心的是这几行：

```python
left = 0

for right in range(len(nums)):
    if nums[right] != 0:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
```

它表达的是一个很经典的双指针模型：

- `right` 负责遍历
- `left` 负责维护答案区域

遇到合法元素，就交换到前面去。

## 常见错误

### 1. 额外创建新数组

这样虽然容易写，
但不符合题目“原地操作”的要求。

### 2. 没有保持非零元素的相对顺序

比如有的人会想着直接把所有 `0` 跟后面元素乱换，
这样可能把 `1、3、12` 的顺序打乱。

这道题要求的是：

- `1` 还要在 `3` 前面
- `3` 还要在 `12` 前面

### 3. 把 `left` 的含义理解错

`left` 不是“当前的左指针”这么简单，
它更准确的含义是：

- 下一个非零元素应该被放置的位置

理解这一点，代码就不容易写乱。

### 4. 遇到 `0` 时也错误地移动 `left`

只有在遇到非零元素并处理完成后，
才应该让 `left += 1`。

如果遇到 `0` 也移动 `left`，逻辑就会出错。

## 一句话总结

这道题的关键不是单纯把 `0` 挪到后面，而是：

**用双指针让 `right` 负责找非零元素，`left` 负责维护非零区间，从而在原地、稳定地把所有 `0` 移到数组末尾。**
