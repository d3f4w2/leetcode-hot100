# 075. 颜色分类

## 所属专题
- 双指针

## 题目描述

给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums`，
原地对它们进行排序，使得相同颜色的元素相邻，
并按照红色、白色、蓝色顺序排列。

我们使用整数 `0`、`1` 和 `2` 分别表示红色、白色和蓝色。

题目还特别要求：

- 必须原地修改数组
- 不能使用库内置的 `sort()` 函数

## 示例

### 示例 1

```text
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

### 示例 2

```text
输入：nums = [2,0,1]
输出：[0,1,2]
```

## 题意理解

这道题表面上是在“排序”，
但它其实不是让我们写一个通用排序算法，
而是让我们利用数组里只有三种数：

- `0`
- `1`
- `2`

把它们调整成：

- 前面全是 `0`
- 中间全是 `1`
- 后面全是 `2`

并且有两个重要限制：

- 要 **原地修改**
- 不能直接调用排序函数

所以这道题的关键不是“怎么排序任意数组”，
而是：

**怎么利用值只有三种这一特点，用一次遍历把数组分成三段。**

## 最直接的想法：先统计个数，再回填数组

最容易想到的方法是：

- 先遍历一遍数组，数出 `0`、`1`、`2` 各有多少个
- 再遍历一遍数组
- 前面填若干个 `0`
- 中间填若干个 `1`
- 后面填若干个 `2`

这种方法当然能做出来，
而且时间复杂度也是 `O(n)`。

如果只从结果来看，它已经够好了。

但这道题更经典的解法是：

- 不单独计数
- 不分两次回填
- 而是在一次扫描过程中直接把数组整理好

这就是著名的：

**荷兰国旗问题。**

## 优化思路：三指针（荷兰国旗问题）

### 核心想法

我们希望在遍历过程中，把数组逐步维护成三块区域：

- 左边全是 `0`
- 中间是已经处理好的 `1`
- 右边全是 `2`

为此，定义三个指针：

- `left`：指向下一个应该放 `0` 的位置
- `curr`：当前正在检查的位置
- `right`：指向下一个应该放 `2` 的位置

### 三个区域分别表示什么

在遍历过程中，我们始终维护这样的区间含义：

- `[0, left - 1]`：全是 `0`
- `[left, curr - 1]`：全是 `1`
- `[curr, right]`：还没有处理
- `[right + 1, n - 1]`：全是 `2`

也就是说：

- `curr` 左边的内容已经整理好了
- `curr` 到 `right` 之间还要继续检查
- `right` 右边已经全部是 `2`

### 遇到 `0` 怎么办

如果：

```python
nums[curr] == 0
```

说明这个 `0` 应该被放到最左边的 `0` 区域里。

于是：

- 交换 `nums[left]` 和 `nums[curr]`
- `left += 1`
- `curr += 1`

为什么这时 `curr` 也可以前进？

因为交换之后：

- 放到 `left` 位置的已经是正确的 `0`
- 而 `curr` 当前位置换回来的元素，要么本来就是 `1`，要么是在当前已处理区域内的合法值

所以可以继续往后看。

### 遇到 `1` 怎么办

如果：

```python
nums[curr] == 1
```

那它本来就应该处在中间区域，
什么都不用做，直接：

- `curr += 1`

### 遇到 `2` 怎么办

如果：

```python
nums[curr] == 2
```

说明这个 `2` 应该被放到最右边去。

于是：

- 交换 `nums[curr]` 和 `nums[right]`
- `right -= 1`

但是这里要特别注意：

- **不能让 `curr` 立即加一**

因为从 `right` 交换过来的新元素，
我们还没有检查过。

它可能是：

- `0`
- `1`
- `2`

所以必须留在当前位置继续判断一次。

这正是这道题最容易写错的细节。

## 用示例手推一遍

以：

```text
nums = [2,0,2,1,1,0]
```

为例。

初始时：

- `left = 0`
- `curr = 0`
- `right = 5`

### 第 1 步：`curr = 0`

- `nums[curr] = 2`
- 应该放到右边去
- 交换 `nums[0]` 和 `nums[5]`

数组变成：

```text
[0,0,2,1,1,2]
```

然后：

- `right = 4`
- `curr` 不动，仍然检查当前位置

### 第 2 步：仍然 `curr = 0`

- `nums[curr] = 0`
- 应该放到左边去
- 交换 `nums[left]` 和 `nums[curr]`

其实这里是和自己交换，数组不变：

```text
[0,0,2,1,1,2]
```

然后：

- `left = 1`
- `curr = 1`

### 第 3 步：`curr = 1`

- `nums[curr] = 0`
- 继续放到左边

交换后数组仍然不变：

```text
[0,0,2,1,1,2]
```

然后：

- `left = 2`
- `curr = 2`

### 第 4 步：`curr = 2`

- `nums[curr] = 2`
- 应该放到右边
- 交换 `nums[2]` 和 `nums[4]`

数组变成：

```text
[0,0,1,1,2,2]
```

然后：

- `right = 3`
- `curr` 不动，继续检查 `nums[2]`

### 第 5 步：仍然 `curr = 2`

- `nums[curr] = 1`
- 它就在应该在的中间区域
- 所以 `curr = 3`

### 第 6 步：`curr = 3`

- `nums[curr] = 1`
- 继续前进
- `curr = 4`

这时：

- `curr > right`

遍历结束，数组就是：

```text
[0,0,1,1,2,2]
```

## 为什么这样写

### 1. 这道题本质上不是“通用排序”，而是“分区”

因为只有三种值，
所以不必真的做比较排序。

我们只需要把它们放进各自对应的区域：

- `0` 去左边
- `1` 留中间
- `2` 去右边

### 2. `curr` 是唯一负责“扫描未知区域”的指针

`left` 和 `right` 负责维护边界，
真正逐个检查元素的是 `curr`。

### 3. 遇到 `2` 时不能立刻 `curr += 1`

这是最关键的细节。

因为交换过来的元素还没检查，
如果直接跳过去，就可能漏掉一个 `0` 或另一个 `2`。

### 4. 整个过程只遍历一遍数组

每个元素最多被处理常数次，
所以整体复杂度是线性的。

## 算法步骤

1. 定义三个指针：`left = 0`、`curr = 0`、`right = len(nums) - 1`
2. 当 `curr <= right` 时，持续处理当前元素
3. 如果 `nums[curr] == 0`，交换到左边，并同时移动 `left` 和 `curr`
4. 如果 `nums[curr] == 1`，说明位置正确，只移动 `curr`
5. 如果 `nums[curr] == 2`，交换到右边，只移动 `right`
6. 当 `curr > right` 时，说明未知区域已经处理完毕

## 复杂度分析

### 时间复杂度

`O(n)`

原因是：

- `curr` 从左到右扫描数组
- 每个元素最多只会被交换和检查若干次
- 总体仍然是线性时间

### 空间复杂度

`O(1)`

原因是：

- 只使用了 `left`、`curr`、`right` 三个额外变量
- 所有操作都在原数组上完成

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def sortColors(self, nums: List[int]) -> None:
        left = 0
        curr = 0
        right = len(nums) - 1

        while curr <= right:
            if nums[curr] == 0:
                nums[left], nums[curr] = nums[curr], nums[left]
                left += 1
                curr += 1
            elif nums[curr] == 1:
                curr += 1
            else:
                nums[curr], nums[right] = nums[right], nums[curr]
                right -= 1
```

## 这段代码最值得记住的地方

最核心的是这段分支：

```python
if nums[curr] == 0:
    nums[left], nums[curr] = nums[curr], nums[left]
    left += 1
    curr += 1
elif nums[curr] == 1:
    curr += 1
else:
    nums[curr], nums[right] = nums[right], nums[curr]
    right -= 1
```

它非常清楚地体现了三种数字的处理方式：

- `0` 扔到左边
- `1` 留在中间
- `2` 扔到右边

尤其要记住最后一种情况：

- 交换完 `2` 之后，**不要移动 `curr`**

## 常见错误

### 1. 直接调用 `sort()`

题目已经明确要求：

- 不能使用库内置排序函数

### 2. 遇到 `2` 时交换后也让 `curr += 1`

这是最常见的错误。

交换过来的元素还没检查，
直接跳过会漏处理。

### 3. 没有搞清楚三个指针各自维护的区域含义

如果不知道：

- `left` 左边是什么
- `curr` 到 `right` 是什么
- `right` 右边是什么

代码就会很容易写乱。

### 4. 把这题写成计数回填版本，但忽略了更经典的一趟扫描做法

计数法不算错，
但这道题更经典、更值得掌握的是荷兰国旗三指针写法。

### 5. 误以为这是普通快排分区模板

这题和分区思想有点像，
但这里的目标更明确：

- 只处理 `0`、`1`、`2` 三种值
- 并维护三个稳定的区域语义

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        left = curr = 0
        right = len(nums) - 1

        while curr <= right:
            if nums[curr] == 0:
                nums[left], nums[curr] = nums[curr], nums[left]
                left += 1
                curr += 1
            elif nums[curr] == 1:
                curr += 1
            else:
                nums[curr], nums[right] = nums[right], nums[curr]
                right -= 1
```

## 一句话总结

这道题的关键不是记住三种分支本身，而是：

**用 `left`、`curr`、`right` 三个指针把数组维护成“左边全是 0、中间全是 1、右边全是 2”的三段区域。**
