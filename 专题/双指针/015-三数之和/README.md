# 015. 三数之和

## 所属专题

- 双指针

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足：

- `i != j`
- `i != k`
- `j != k`
- `nums[i] + nums[j] + nums[k] == 0`

请你返回所有 **和为 `0` 且不重复** 的三元组。

注意：

- 答案中不可以包含重复的三元组
- 返回答案的顺序和三元组内部的顺序都不重要

## 示例

### 示例 1

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0
不同的三元组是 [-1,0,1] 和 [-1,-1,2]
输出的顺序和三元组内部的顺序都不重要
```

### 示例 2

```text
输入：nums = []
输出：[]
```

### 示例 3

```text
输入：nums = [0]
输出：[]
```

## 题意理解

这道题和“两数之和”最大的不同有两个：

1. 这次不是找两个数，而是找三个数
2. 这次不是返回一个答案，而是返回所有不重复的答案

也就是说，我们最终要得到的是：

- 所有满足和为 `0` 的三元组
- 每个三元组里的三个位置必须不同
- 值相同、只是顺序不同的三元组，算重复，不能重复加入答案

比如：

- `[-1,0,1]`
- `[0,-1,1]`

本质上是同一个三元组，不能算两个答案。

所以这道题真正的难点，不只是“找到三个数”，而是：

- 怎么更快地找到它们
- 怎么避免把重复答案收进去

## 最直接的想法：暴力枚举

最容易想到的方法，就是三层循环。

具体做法：

- 第一层循环枚举第一个数
- 第二层循环枚举第二个数
- 第三层循环枚举第三个数
- 如果三数之和等于 `0`，就把这个三元组加入答案

这个方法当然能做出来，但有两个明显问题。

### 问题 1：太慢

三层循环的时间复杂度是 `O(n^3)`。

当数组长度变大时，枚举次数会非常多，效率不够好。

### 问题 2：去重很麻烦

即使你找到了很多和为 `0` 的组合，也可能出现：

- 值一样
- 顺序不同

比如：

- `[-1,0,1]`
- `[-1,1,0]`
- `[0,-1,1]`

这些实际上都应该只保留一个。

所以我们要思考：

**能不能一边高效查找，一边顺手把重复答案处理掉？**

## 优化思路：排序 + 固定一个数 + 双指针

这是这道题最经典、也最推荐掌握的做法。

### 第一步：先排序

假设原数组是：

```text
[-1,0,1,2,-1,-4]
```

排序后变成：

```text
[-4,-1,-1,0,1,2]
```

排序有两个核心作用：

1. 方便去重
2. 方便使用双指针

为什么排序后就方便双指针？

因为数组有序之后：

- 如果当前和太小，就让左指针右移，去找更大的数
- 如果当前和太大，就让右指针左移，去找更小的数

这样就能利用“有序”这个性质来减少无效枚举。

### 第二步：固定第一个数

我们可以先固定一个数 `nums[i]`。

那么问题就变成：

> 在 `i` 后面的区间里，找两个数，使它们的和等于 `-nums[i]`

这就把“三数之和”转换成了一个“有序数组里的两数之和”问题。

### 第三步：剩下两个数用双指针找

固定 `nums[i]` 后：

- 左指针 `left = i + 1`
- 右指针 `right = n - 1`

然后计算：

```text
total = nums[i] + nums[left] + nums[right]
```

分三种情况：

1. 如果 `total < 0`，说明总和太小，需要更大的数，所以 `left += 1`
2. 如果 `total > 0`，说明总和太大，需要更小的数，所以 `right -= 1`
3. 如果 `total == 0`，说明找到一个答案，把它加入结果

### 第四步：认真处理重复

这道题最关键的细节，其实不是双指针本身，而是“去重”。

去重主要有三处：

#### 1. 固定第一个数时去重

如果：

```python
nums[i] == nums[i - 1]
```

说明这个数作为“三元组第一个数”已经处理过了，直接跳过。

#### 2. 找到一个答案后，左指针去重

如果当前 `left` 指向的值和下一个值相同，就继续右移。

这样可以避免把相同的第二个数重复加入答案。

#### 3. 找到一个答案后，右指针去重

如果当前 `right` 指向的值和前一个值相同，就继续左移。

这样可以避免把相同的第三个数重复加入答案。

## 用示例手推一遍

以示例 1 为例：

```text
nums = [-1,0,1,2,-1,-4]
```

先排序：

```text
[-4,-1,-1,0,1,2]
```

### 第 1 轮：固定 `nums[i] = -4`

- `left = 1`，值是 `-1`
- `right = 5`，值是 `2`
- 当前和：`-4 + (-1) + 2 = -3`

和太小，所以左指针右移。

继续尝试：

- `-4 + (-1) + 2 = -3`
- `-4 + 0 + 2 = -2`
- `-4 + 1 + 2 = -1`

始终小于 `0`，所以这一轮找不到答案。

### 第 2 轮：固定 `nums[i] = -1`（下标 1）

- `left = 2`，值是 `-1`
- `right = 5`，值是 `2`
- 当前和：`-1 + (-1) + 2 = 0`

找到第一个答案：

```text
[-1,-1,2]
```

记录后，继续移动指针。

现在：

- `left = 3`，值是 `0`
- `right = 4`，值是 `1`
- 当前和：`-1 + 0 + 1 = 0`

又找到一个答案：

```text
[-1,0,1]
```

### 第 3 轮：固定 `nums[i] = -1`（下标 2）

因为它和前一个固定数相同，所以直接跳过。

这一步就是“第一个数去重”。

### 第 4 轮：固定 `nums[i] = 0`

此时剩余区间太短，而且也找不到新的满足条件的组合。

最终答案就是：

```text
[[-1,-1,2],[-1,0,1]]
```

## 为什么这样写

这道题的写法看起来比“两数之和”复杂，但核心逻辑其实很清楚：

### 1. 排序是整个方法的前提

只有排完序，我们才能：

- 用双指针判断该往左还是往右移动
- 轻松跳过重复元素

### 2. 固定一个数，可以把问题降成“两数之和”

一旦固定了 `nums[i]`，剩下要做的事情就是：

- 在后面的有序区间里
- 找两个数
- 让三者之和等于 `0`

这就把问题拆小了。

### 3. 找到答案后不能只简单地 `left += 1`、`right -= 1`

因为如果不先跳过重复值，就可能收集到重复三元组。

所以正确顺序是：

- 先记录答案
- 再跳过重复的 `left`
- 再跳过重复的 `right`
- 最后同时移动两边指针

### 4. 当固定数已经大于 `0` 时，可以直接结束

因为数组已经有序。

如果 `nums[i] > 0`，那么它右边的数只会更大，三个数之和不可能再等于 `0`。

这可以少做一些无意义的遍历。

## 算法步骤

1. 先对数组 `nums` 排序
2. 从左到右枚举第一个数 `nums[i]`
3. 如果 `nums[i] > 0`，直接结束遍历
4. 如果 `nums[i]` 和前一个数相同，跳过，避免重复
5. 令 `left = i + 1`，`right = n - 1`
6. 当 `left < right` 时：
   - 计算 `total = nums[i] + nums[left] + nums[right]`
   - 如果 `total < 0`，左指针右移
   - 如果 `total > 0`，右指针左移
   - 如果 `total == 0`，记录答案，并跳过左右两边的重复值
7. 所有位置处理完成后，返回结果

## 复杂度分析

### 时间复杂度

`O(n^2)`

原因：

- 排序需要 `O(n log n)`
- 外层固定一个数，内层双指针整体扫描一遍
- 总体复杂度由 `O(n^2)` 主导

### 空间复杂度

如果只看双指针过程本身，额外空间是 `O(1)`。

通常这道题在题解里也写作：

`O(1)`（不计答案空间）

不过如果严格把 Python 排序过程内部可能使用的辅助空间也算上，那么实际额外空间并不一定严格是常数。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        # 先排序。
        # 排序后有两个好处：
        # 1. 可以使用双指针
        # 2. 更容易跳过重复答案
        nums.sort()

        # 用来保存所有满足条件且不重复的三元组。
        result = []

        n = len(nums)

        # 枚举三元组中的第一个数。
        # 由于至少需要三个数，所以 i 最多到 n - 3。
        for i in range(n - 2):
            # 如果当前固定数已经大于 0，后面的数只会更大，
            # 三数之和不可能再等于 0，可以直接结束。
            if nums[i] > 0:
                break

            # 第一个数去重。
            # 如果当前数和前一个数相同，
            # 那么以它为起点得到的三元组会和上一轮重复。
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            # 在 i 后面的区间里，用双指针找另外两个数。
            left = i + 1
            right = n - 1

            while left < right:
                # 计算当前三个数的和。
                total = nums[i] + nums[left] + nums[right]

                if total < 0:
                    # 和太小，说明需要更大的数。
                    # 因为数组有序，所以让 left 右移。
                    left += 1
                elif total > 0:
                    # 和太大，说明需要更小的数。
                    # 因为数组有序，所以让 right 左移。
                    right -= 1
                else:
                    # 找到一个满足条件的三元组。
                    result.append([nums[i], nums[left], nums[right]])

                    # 第二个数去重。
                    # 如果 left 后面还是相同的值，就一直跳过。
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1

                    # 第三个数去重。
                    # 如果 right 前面还是相同的值，也一直跳过。
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1

                    # 当前答案处理完后，左右指针都继续收缩。
                    left += 1
                    right -= 1

        return result
```

## 这段代码最值得记住的地方

你在自己手写的时候，重点记住的是这条主线：

```python
nums.sort()

for i in range(len(nums) - 2):
    if nums[i] > 0:
        break
    if i > 0 and nums[i] == nums[i - 1]:
        continue

    left, right = i + 1, len(nums) - 1

    while left < right:
        total = nums[i] + nums[left] + nums[right]
        if total < 0:
            left += 1
        elif total > 0:
            right -= 1
        else:
            result.append([nums[i], nums[left], nums[right]])
            while left < right and nums[left] == nums[left + 1]:
                left += 1
            while left < right and nums[right] == nums[right - 1]:
                right -= 1
            left += 1
            right -= 1
```

本质上就是一句话：

**先排序，再固定一个数，把剩下两个数交给双指针，同时一路去重。**

## 常见错误

### 1. 忘记先排序

如果不排序：

- 双指针就没有办法根据“和太大还是太小”来移动
- 去重也会变得很麻烦

所以排序不是附属操作，而是核心前提。

### 2. 只找到了答案，但没有跳过重复值

这是最常见的问题之一。

如果你找到一个三元组后，直接：

```python
left += 1
right -= 1
```

而不先跳过重复值，就很容易把重复三元组加入结果。

### 3. 忘记对第一个数去重

即使 `left` 和 `right` 的去重都写对了，
如果外层的 `i` 不去重，答案仍然会重复。

所以这道题的去重不是一处，而是三处都要注意。

### 4. 找到答案后只移动一边指针

当 `total == 0` 时，正常做法是：

- 跳过重复值
- 然后 `left += 1`
- 再 `right -= 1`

如果只动一边，逻辑容易乱，还可能漏解或者重复。

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:

        result = []
        n = len(nums)

                    right -= 1
                else:
                    result.append([nums[i], nums[left], nums[right]])
                    while left < right and nums[left] == nums[left + 1]:

                        right -= 1
                    left += 1
                    right -= 1

        return result
```

## 一句话总结

这道题的关键不是单纯“找三个数”，而是：

**把数组排好序，固定第一个数，再用双指针去找另外两个数，并且在三个层次上做好去重。**
