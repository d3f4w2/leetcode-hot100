# 005. 最长回文子串

## 所属专题
- 双指针

## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

如果一个字符串正着读和反着读都一样，那么它就是回文串。

## 示例

### 示例 1

```text
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案
```

### 示例 2

```text
输入：s = "cbbd"
输出："bb"
```

### 示例 3

```text
输入：s = "a"
输出："a"
```

## 题意理解

这道题不是让我们判断整个字符串是不是回文，
而是让我们在字符串里找到一段 **连续的子串**，并且这段子串要满足：

- 正着读和反着读一样
- 长度尽可能长
- 返回的是这段子串本身

比如：

- 在 `"babad"` 里，`"bab"` 是回文串
- `"aba"` 也是回文串
- 它们长度都是 `3`
- 所以返回其中任意一个都可以

关键点有两个：

- 这是 **子串**，必须连续
- 不是求长度，而是要返回真正的那段字符串

## 最直接的想法：暴力枚举

最容易想到的方法是：

- 枚举所有子串的起点
- 枚举所有子串的终点
- 取出每一个子串
- 判断它是不是回文
- 如果是，就更新当前最长答案

比如字符串长度是 `n`：

- 子串的数量大约是 `O(n^2)`
- 每次判断一个子串是否回文，又可能要 `O(n)`

所以总时间复杂度会到 `O(n^3)`，太慢了。

## 优化思路：中心扩展法

### 核心想法

回文串有一个非常重要的性质：

> 它一定是从中间向两边对称的。

所以我们不一定要枚举“每一段子串”，
而可以反过来思考：

**如果我知道回文串的中心，能不能从中心往两边扩展，直接找到这个回文串的范围？**

答案是可以。

### 为什么要分奇数和偶数两种情况

回文串的中心有两种形式：

#### 1. 奇数长度回文串

例如：

- `"aba"`
- `"racecar"`

它们都有一个明确的中心字符。

比如 `"aba"` 的中心是 `b`，
可以从 `b` 开始，向左右同时扩展。

#### 2. 偶数长度回文串

例如：

- `"abba"`
- `"bb"`

它们的中心不是某个字符，
而是 **两个字符之间的空隙**。

比如 `"abba"` 的中心在两个 `b` 之间。

所以对于每个位置 `i`，都要检查两种中心：

- 以 `i` 为中心：`(i, i)`
- 以 `i` 和 `i + 1` 之间为中心：`(i, i + 1)`

### 扩展过程在做什么

定义一个函数 `expandAroundCenter(left, right)`：

- 如果 `s[left] == s[right]`，说明还能继续保持回文
- 就让 `left -= 1`，`right += 1`
- 一直扩展到不能扩展为止

当循环结束时：

- `left` 和 `right` 已经走到了“回文边界的外面”
- 真正的回文长度就是 `right - left - 1`

### 整体流程

- 枚举每一个位置 `i`
- 计算以 `i` 为中心的最长奇数回文串长度
- 计算以 `i, i + 1` 为中心的最长偶数回文串长度
- 取两者较大值
- 如果比当前记录的最长回文串还长，就更新起止位置

## 用示例手推一遍

以 `s = "babad"` 为例：

### 当 `i = 0`

- 奇数中心：`(0, 0)`，回文串是 `"b"`
- 偶数中心：`(0, 1)`，`b != a`，不能扩展
- 当前最长是 `"b"`

### 当 `i = 1`

- 奇数中心：`(1, 1)`
- 先比较 `a == a`
- 再向两边扩展，比较 `b == b`
- 得到回文串 `"bab"`
- 偶数中心：`(1, 2)`，`a != b`
- 当前最长更新为 `"bab"`

### 当 `i = 2`

- 奇数中心：`(2, 2)`
- 向两边扩展后得到 `"aba"`
- 偶数中心：`(2, 3)`，`b != a`
- `"aba"` 长度和当前最长一样，所以返回 `"bab"` 或 `"aba"` 都可以

### 后面的中心

继续枚举后，不会再找到更长的回文串。

## 为什么这样写

### 1. 回文串天然适合“从中间往两边看”

- 左右字符相等，才能继续扩展
- 一旦不相等，当前中心能形成的最长回文就结束了

### 2. 每个位置都必须同时考虑奇数和偶数两种中心

如果只考虑 `(i, i)`：

- 能找到 `"aba"`
- 但找不到 `"abba"`

如果只考虑 `(i, i + 1)`：

- 能找到偶数回文
- 但会漏掉奇数回文

所以两种情况都不能少。

### 3. 记录起点和终点，比每次直接切片更稳妥

在遍历过程中：

- 只更新 `start` 和 `end`
- 最后统一返回 `s[start:end + 1]`

这样逻辑更清楚，也避免反复生成字符串。

### 4. 这道题虽然是 `O(n^2)`，但已经是很经典也很常用的写法

它不是最极致的做法，
但非常容易理解、面试里也很常见。

## 算法步骤

1. 定义扩展函数 `expandAroundCenter(left, right)`
2. 用两个指针从中心向两边扩展
3. 返回当前中心能得到的最长回文长度
4. 枚举字符串中每一个位置 `i`
5. 分别计算奇数中心和偶数中心的最长长度
6. 取较大值，必要时更新答案的起止位置
7. 最后返回最长回文子串

## 复杂度分析

### 时间复杂度

`O(n^2)`

原因是：

- 一共有 `n` 个位置作为中心
- 每个中心最坏情况下要向两边扩展 `O(n)` 次

### 空间复杂度

`O(1)`

原因是：

- 只使用了若干个额外变量
- 没有使用与输入规模相关的额外存储空间

## Python 参考实现（详细注释）

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expandAroundCenter(left: int, right: int) -> int:
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            return right - left - 1

        start = 0
        end = 0

        for i in range(len(s)):
            len1 = expandAroundCenter(i, i)
            len2 = expandAroundCenter(i, i + 1)
            max_len = max(len1, len2)

            if max_len > end - start:
                start = i - (max_len - 1) // 2
                end = i + max_len // 2

        return s[start:end + 1]
```

## 这段代码最值得记住的地方

```python
def expandAroundCenter(left, right):
    while left >= 0 and right < len(s) and s[left] == s[right]:
        left -= 1
        right += 1
    return right - left - 1
```

它体现了这道题最核心的思想：

- 不去枚举每一个子串
- 而是固定中心，然后向两边扩展

再加上这两行：

```python
len1 = expandAroundCenter(i, i)
len2 = expandAroundCenter(i, i + 1)
```

就把奇数回文和偶数回文都覆盖到了。

## 常见错误

### 1. 只考虑奇数长度回文串

这样会漏掉：

- `"bb"`
- `"abba"`

所以必须同时检查 `(i, i)` 和 `(i, i + 1)`。

### 2. 扩展结束后回文长度计算错了

循环结束时：

- `left` 和 `right` 已经越过了真正的回文边界

所以长度不是：

- `right - left`

而是：

- `right - left - 1`

### 3. 更新 `start` 和 `end` 的公式写错

这一步很容易记混。

如果最长长度是 `max_len`，中心在 `i` 附近，那么：

- `start = i - (max_len - 1) // 2`
- `end = i + max_len // 2`

这样才能同时兼容奇数和偶数长度。

### 4. 把“子串”写成“子序列”思路

这道题要求的是：

- 连续的一段字符串

不是：

- 可以跳着选字符

## 适合你自己再写一遍的版本

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(left: int, right: int) -> int:
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            return right - left - 1

        start = 0
        end = 0

        for i in range(len(s)):
            current_len = max(expand(i, i), expand(i, i + 1))
            if current_len > end - start:
                start = i - (current_len - 1) // 2
                end = i + current_len // 2

        return s[start:end + 1]
```

## 一句话总结

这道题的关键不是去枚举所有子串，而是：

**把每个位置都当成回文中心，分别向两边扩展，找出奇数回文和偶数回文里的最长者。**
