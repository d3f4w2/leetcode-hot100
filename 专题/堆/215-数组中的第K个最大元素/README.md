# 215. 数组中的第K个最大元素

## 所属专题
- 堆

## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，这里找的是：

- 排序后第 `k` 个最大的元素

而不是：

- 第 `k` 个不同的元素

也就是说，如果数组里有重复数字，重复数字也要参与排名。

## 原题示例

### 示例 1

```text
输入：nums = [3,2,1,5,6,4], k = 2
输出：5
```

### 示例 2

```text
输入：nums = [3,2,3,1,2,4,5,5,6], k = 4
输出：4
```

## 题意理解

这道题本质上是在问：

- 把数组按从大到小排好以后
- 第 `k` 个位置上的数字是多少

比如：

```text
nums = [3,2,1,5,6,4], k = 2
```

如果从大到小排序，得到：

```text
[6,5,4,3,2,1]
```

那么第 `2` 个最大的元素就是：

```text
5
```

还要特别注意一个细节：

**题目要找的是第 `k` 个最大元素，不是第 `k` 个不同的元素。**

例如：

```text
nums = [5,5,4], k = 2
```

排序后是：

```text
[5,5,4]
```

第 `2` 个最大的元素仍然是 `5`，不是 `4`。

## 最直接的想法：排序

最直观的方法就是：

1. 先对数组排序
2. 再取出第 `k` 个最大的元素

如果按从小到大排序：

```python
nums.sort()
return nums[-k]
```

如果按从大到小排序：

```python
nums.sort(reverse=True)
return nums[k - 1]
```

这个方法很好理解，也很好写。

但问题在于：

- 我们只是想知道第 `k` 个最大元素
- 却把整个数组都排了一遍

所以这个方法的时间复杂度是：

```text
O(n log n)
```

还能继续优化。

## 优化思路：维护大小为 k 的最小堆

这道题最常见、也最值得掌握的做法，就是：

- 用一个大小始终不超过 `k` 的最小堆

### 核心想法

我们在遍历数组时，不需要记住所有数字，只需要记住：

- 当前扫描过的数字里，最大的 `k` 个

那怎么维护这件事？

- 用最小堆

最小堆有一个非常重要的性质：

- 堆顶永远是堆里最小的元素

如果这个堆里装的正好是“当前最大的 `k` 个元素”，那么：

- 堆顶这个最小值
- 恰好就是当前第 `k` 大的元素

遍历完整个数组后：

- 堆里剩下的就是整个数组里最大的 `k` 个元素
- 堆顶自然就是整个数组里第 `k` 个最大元素

### 为什么是最小堆，不是最大堆

因为我们要保留的是：

- 最大的 `k` 个数

当堆大小超过 `k` 时，我们应该删掉谁？

- 删掉这批数里最小的那个

这样堆里剩下的，才能继续保持为“最大的 `k` 个数”。

而最小堆正好最擅长这件事：

- 可以快速找到并删除当前最小值

### 具体过程在做什么

遍历数组中的每个 `num`：

1. 先把 `num` 放进最小堆
2. 如果堆的大小超过了 `k`
3. 就把堆顶最小元素弹出去

这样一来，任意时刻堆里的元素个数都不会超过 `k`。

最后堆中留下来的，一定就是：

- 整个遍历过程中见过的最大的 `k` 个元素

而堆顶就是这 `k` 个元素里最小的那个，也就是答案。

```text

```

为例。

为了方便理解，下面把堆中的元素按“从小到大”的样子写出来。

### 初始状态

```text
heap = []
```

```text
heap = [3]
```

堆大小没有超过 `2`，不用弹出。

```text
heap = [2,3]
```

堆大小正好等于 `2`，不用弹出。

### 处理 1

先加入堆：

```text

```

堆大小超过了 `2`，弹出最小值 `1`：

```text
heap = [2,3]
```

现在堆里保存的是当前最大的 `2` 个数。

```text
heap = [2,3,5]

```

```text

```

### 处理 4

先加入堆：

```text

```

弹出最小值 `4`：

```text
heap = [5,6]
```

遍历结束后：

```text
heap = [5,6]
```

堆顶是：

```text

```

所以答案就是：

```text
5
```

## 为什么这样写是对的

关键在于：堆里始终只保留“当前最大的 `k` 个元素”。

假设某一时刻我们已经处理完前面若干个数，并且堆里保存的正好就是：

- 当前最大的 `k` 个元素

这时新来一个数字 `num`：

- 如果它很小，那么即使先放进堆里，之后也会因为太小被弹出去
- 如果它够大，那么它会把原来那 `k` 个数中更小的那个挤出去

所以每处理完一个数字后，这个性质都仍然成立：

- 堆里保存的是当前最大的 `k` 个元素

遍历完成后，这个结论自然就推广到了整个数组。

因此：

- 堆顶就是这 `k` 个元素里最小的那个
- 也就是整个数组的第 `k` 大元素

## 算法步骤

1. 创建一个空的最小堆 `heap`
2. 遍历数组中的每个数字 `num`
3. 把 `num` 放入堆中
4. 如果堆大小超过 `k`，弹出堆顶最小元素
5. 遍历结束后，返回 `heap[0]`

## 复杂度分析

### 排序做法

时间复杂度：

```text
O(n log n)
```

空间复杂度：

```text
视排序实现而定，通常写作 O(1) 或 O(log n)
```

### 最小堆做法

时间复杂度：

```text
O(n log k)
```

原因是：

- 一共遍历 `n` 个元素
- 每次入堆或出堆的代价是 `O(log k)`

空间复杂度：

```text
O(k)
```

因为堆中最多只保留 `k` 个元素。

### 快速选择

这道题还可以用快速选择来做。

平均时间复杂度：

```text
O(n)
```

最坏时间复杂度：

```text
O(n^2)
```

空间复杂度：

```text
O(1)
```

如果写成原地划分，额外空间可以看作常数级。

## Python 参考实现（带详细注释）

```python
from typing import List
import heapq


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # Python 的 heapq 默认实现的是最小堆。
        # 也就是说，heap[0] 永远是当前堆中最小的元素。
        heap = []

        # 依次扫描数组中的每个数字。
        for num in nums:
            # 先把当前数字放进堆里。
            heapq.heappush(heap, num)

            # 如果堆大小超过了 k，
            # 说明现在堆里有 k + 1 个数字。
            # 我们只想保留最大的 k 个数字，
            # 所以要把其中最小的那个弹出去。
            if len(heap) > k:
                heapq.heappop(heap)

        # 遍历结束后，堆中正好保存着整个数组里最大的 k 个元素。
        # 堆顶是这 k 个元素里最小的那个，也就是第 k 大元素。
        return heap[0]
```

## 常见错误

### 1. 误以为要找“第 k 个不同的元素”

题目要求的是：

- 第 `k` 个最大元素

不是：

- 第 `k` 个不同的元素

重复数字也要参与排名。

### 2. 不理解为什么堆大小必须控制在 `k`

如果不控制堆大小，堆里会保存所有元素，那就失去了“只保留最大的 `k` 个”的意义。

每次让堆大小不超过 `k`，本质上就是在不断淘汰较小的元素。

### 3. 误以为堆里的元素必须整体有序

堆和排序数组不是一回事。

堆只保证：

- 堆顶最小

并不保证其余元素从小到大完全排好。

但这已经足够解决这道题。

### 4. 把时间复杂度写成 `O(n log n)`

这里维护的是一个大小最多为 `k` 的堆，所以每次调整堆的代价是：

```text
O(log k)
```

不是 `O(log n)`。

因此总时间复杂度是：

```text
O(n log k)
```

## 适合自己默写的精简版本

```python
from typing import List
import heapq


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        heap = []
        for num in nums:
            heapq.heappush(heap, num)
            if len(heap) > k:
                heapq.heappop(heap)
        return heap[0]
```

## 一句话总结

这道题的关键就是：

**始终用一个大小为 `k` 的最小堆，保留当前最大的 `k` 个元素，最后堆顶就是第 `k` 个最大元素。**
