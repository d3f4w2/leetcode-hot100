# 260. 只出现一次的数字 III

## 所属专题

- 位运算

## 题目描述

给定一个整数数组 `nums`，其中恰好有两个元素只出现一次，其余所有元素均出现两次。请你找出这两个只出现一次的元素。

你可以按任意顺序返回答案。

进阶要求：

- 时间复杂度为 `O(n)`
- 额外空间复杂度为 `O(1)`

## 示例

### 示例 1

```text
输入：nums = [1,2,1,3,2,5]
输出：[3,5]
解释：[5,3] 也是有效答案。
```

### 示例 2

```text
输入：nums = [-1,0]
输出：[-1,0]
```

### 示例 3

```text
输入：nums = [0,1]
输出：[1,0]
```

## 题意理解

这道题和 `136. 只出现一次的数字` 很像，但又不完全一样。

在 `136` 里：

- 只有一个数字出现一次
- 其余数字都出现两次
- 所以把所有数字异或一遍，最后就能直接得到答案

但这道题里：

- 有两个数字各出现一次
- 其余数字都出现两次

如果我们直接把所有数字异或起来，最后得到的不是其中某一个答案，而是：

```text
a ^ b
```

其中：

- `a` 和 `b` 就是那两个只出现一次的数字

所以这道题真正的关键不是“怎么消掉重复数字”，而是：

**在已经得到 `a ^ b` 之后，怎么把 `a` 和 `b` 再拆开。**

## 最直接的想法：哈希统计

最容易想到的做法是用哈希表统计每个数字出现的次数。

具体做法：

- 遍历数组，用字典记录每个数字出现了几次
- 再遍历一次字典，找出出现次数为 `1` 的两个数字

这个方法当然能做出来，而且思路很直观。

但是它的缺点也很明显：

- 时间复杂度是 `O(n)`
- 空间复杂度是 `O(n)`

而题目的进阶要求是额外空间复杂度 `O(1)`，所以我们还得继续优化。

## 优化思路：位运算 + 分组异或

这道题的标准解法就是位运算。

### 第一步：先把所有数字异或起来

我们先把数组中所有数字都异或一遍：

```text
xor_all = nums[0] ^ nums[1] ^ nums[2] ^ ...
```

因为异或有两个很重要的性质：

- `x ^ x = 0`
- `x ^ 0 = x`

所以所有出现两次的数字都会被抵消掉，最后只会剩下：

```text
xor_all = a ^ b
```

这里的 `a` 和 `b` 就是两个只出现一次的数字。

### 第二步：找到 `a` 和 `b` 的某一位不同

既然 `a != b`，那么 `a ^ b` 至少有一位是 `1`。

这一位是 `1` 说明什么？

说明：

- `a` 在这一位上是 `0`
- `b` 在这一位上是 `1`

或者反过来：

- `a` 在这一位上是 `1`
- `b` 在这一位上是 `0`

也就是说，只要我们找到 `xor_all` 中任意一个为 `1` 的二进制位，就说明 `a` 和 `b` 在这一位上不同。

最常用的写法是：

```python
diff_bit = xor_all & -xor_all
```

它的作用是：

- 取出 `xor_all` 二进制表示中最低位的那个 `1`

比如：

```text
xor_all = 6 = 110
diff_bit = 2 = 010
```

### 第三步：按照这一位把所有数字分成两组

有了 `diff_bit` 之后，我们就可以把数组分成两组：

- 一组是这一位为 `1` 的数字
- 一组是这一位为 `0` 的数字

为什么这样分就有用？

因为：

- `a` 和 `b` 在这一位上不同
- 所以它们一定会被分到不同组里

同时，任意一个出现两次的数字，两次的二进制完全一样：

- 它们一定会进同一组
- 在组内继续异或时会互相抵消

### 第四步：两组分别异或

把两组各自异或一遍之后：

- 第一组最后会剩下 `a` 或 `b`
- 第二组最后会剩下另一个

这样就把两个答案都找出来了。

## 用示例手推一遍

以示例 1 为例：

```text
nums = [1,2,1,3,2,5]
```

### 第一步：整体异或

```text
1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5
= (1 ^ 1) ^ (2 ^ 2) ^ (3 ^ 5)
= 0 ^ 0 ^ 6
= 6
```

所以：

```text
xor_all = 6
```

它的二进制是：

```text
6 = 110
```

### 第二步：取出最低位的 1

```text
diff_bit = xor_all & -xor_all
         = 6 & -6
         = 2
```

二进制表示为：

```text
2 = 010
```

这说明最终答案 `a` 和 `b` 在倒数第二位上不同。

### 第三步：按 `diff_bit` 分组

把所有数字按 `num & 2` 是否为 `0` 分组：

第一组：

```text
2, 3, 2
```

因为它们在这一位上是 `1`。

第二组：

```text
1, 1, 5
```

因为它们在这一位上是 `0`。

### 第四步：组内分别异或

第一组异或：

```text
2 ^ 3 ^ 2 = 3
```

第二组异或：

```text
1 ^ 1 ^ 5 = 5
```

所以答案就是：

```text
[3, 5]
```

## 为什么这样写

### 1. 为什么整体异或之后只剩 `a ^ b`

因为所有成对出现的数字都会互相抵消：

```text
x ^ x = 0
```

最后自然只剩下那两个单独出现的数字的异或结果。

### 2. 为什么只取一个为 `1` 的位就够了

我们不需要知道 `a` 和 `b` 在所有位上哪里不同，只需要找到它们“至少有一个地方不同”。

只要找到了这样一位：

- `a` 和 `b` 就一定能被分开
- 分到两组之后，各自组内的重复数字照样还能抵消

所以任意一个为 `1` 的位都可以，取最低位只是写法最常见、最方便。

### 3. 为什么重复元素不会被拆到两组里

因为相同的两个数字二进制完全一致。

既然某一位上数值一样，那么：

- 第一份进哪一组
- 第二份就一定也进哪一组

这样它们就会在同一组里异或掉，不会影响最终结果。

### 4. 为什么这题不能直接返回 `xor_all`

因为：

```text
xor_all = a ^ b
```

这只是两个答案混在一起的结果，不是其中任何一个真实数字。

所以必须再做一次“按不同位分组”，才能把这两个数拆开。

## 算法步骤

1. 初始化 `xor_all = 0`
2. 遍历数组，把所有数字异或到 `xor_all` 中
3. 计算 `diff_bit = xor_all & -xor_all`，取出最低位的 `1`
4. 初始化两个结果变量 `first = 0`、`second = 0`
5. 再遍历一次数组
6. 如果 `num & diff_bit != 0`，就把它异或到 `first`
7. 否则把它异或到 `second`
8. 遍历结束后返回 `[first, second]`

## 复杂度分析

### 时间复杂度

`O(n)`

原因：

- 第一次遍历用于整体异或
- 第二次遍历用于分组异或
- 每次遍历都是线性的

所以总时间复杂度仍然是 `O(n)`。

### 空间复杂度

`O(1)`

原因：

- 只使用了有限个额外变量
- 没有使用哈希表、集合或额外数组

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        # 第一步：把所有数字异或起来。
        # 所有出现两次的数字都会互相抵消，
        # 最后只剩下那两个只出现一次数字的异或结果 a ^ b。
        xor_all = 0
        for num in nums:
            xor_all ^= num

        # 第二步：从 xor_all 中取出任意一个为 1 的二进制位。
        # 这里用的是最常见的写法：取最低位的 1。
        # 这一位为 1，说明两个答案在这一位上不同。
        diff_bit = xor_all & -xor_all

        # 第三步：把数组分成两组，分别异或。
        # 由于两个答案在 diff_bit 这一位上不同，
        # 它们一定会落到不同的组里。
        # 而成对出现的相同数字一定落到同一组里，并在组内被抵消。
        first = 0
        second = 0

        for num in nums:
            if num & diff_bit:
                # 这一组最后只会剩下其中一个只出现一次的数字。
                first ^= num
            else:
                # 另一组最后会剩下另一个只出现一次的数字。
                second ^= num

        return [first, second]
```

## 这段代码最值得记住的地方

你真正要记住的不是整段代码，而是这条主线：

```python
xor_all = 0
for num in nums:
    xor_all ^= num

diff_bit = xor_all & -xor_all

first = 0
second = 0
for num in nums:
    if num & diff_bit:
        first ^= num
    else:
        second ^= num
```

本质上就是一句话：

**先用整体异或把重复数字全部消掉，再用一个“不同位”把两个目标数字分开，最后各组分别异或得到答案。**

## 常见错误

### 1. 以为整体异或后的 `xor_all` 就是答案

这一步得到的只是：

```text
a ^ b
```

并不是最终那两个数字本身，所以还必须继续分组。

### 2. 不会正确提取区分位

正确写法是：

```python
diff_bit = xor_all & -xor_all
```

很多人会误写成别的形式，导致拿到的不是“单独一个区分位”，分组逻辑也就容易出错。

### 3. 分组之后没有继续做异或，而是去额外存列表

这会让空间复杂度变大。

其实分组之后根本不需要把元素真的存下来，只要边遍历边异或就够了。

### 4. 用哈希表统计次数

这个方法可以做对，但额外空间复杂度是 `O(n)`，不满足题目的进阶要求。

## 适合自己默写的精简版本

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        xor_all = 0
        for num in nums:
            xor_all ^= num

        diff_bit = xor_all & -xor_all

        a = 0
        b = 0
        for num in nums:
            if num & diff_bit:
                a ^= num
            else:
                b ^= num

        return [a, b]
```

## 一句话总结

这道题的关键是：

**先把两个只出现一次的数字“异或到一起”，再利用它们某一位不同这一点把数组拆成两组，各组分别异或，两个答案就都会留下来。**
