# 137. 只出现一次的数字 II

## 所属专题
- 位运算

## 题目描述

给你一个整数数组 `nums`，除某个元素仅出现 **一次** 外，其余每个元素都恰好出现 **三次**。

请你找出并返回那个只出现了一次的元素。

你需要尽量设计时间复杂度为 `O(n)`、额外空间复杂度为 `O(1)` 的解法。

## 示例

### 示例 1

```text
输入：nums = [2,2,3,2]
输出：3
```

### 示例 2

```text
输入：nums = [0,1,0,1,0,1,99]
输出：99
```

## 题意理解

这道题最关键的信息有两条：

- 除了一个数只出现一次，其他所有数都出现三次
- 希望我们尽量做到 `O(n)` 时间、`O(1)` 额外空间

如果只是“找出谁出现一次”，其实并不难。
难点在于：

- 不能为了方便直接开一个哈希表把所有数字的出现次数都记下来
- 因为那样虽然时间复杂度是 `O(n)`，但额外空间会变成 `O(n)`

所以这道题真正想考察的是：

**能不能利用“其余元素都出现三次”这个特殊条件，把重复元素自动消掉。**

## 最直接的想法：哈希表计数

最容易想到的办法是：

- 用字典统计每个数字出现了多少次
- 再遍历字典，找到出现次数为 `1` 的那个数

例如：

```python
count[num] += 1
```

最后返回：

```python
出现次数 == 1 的数字
```

这个方法的优点是：

- 很直观
- 很容易写对

但问题也很明显：

- 时间复杂度是 `O(n)`
- 空间复杂度是 `O(n)`

它不满足这道题想要的“额外空间为常数”的要求。

所以我们还得继续想：

**既然重复元素都出现三次，那有没有办法让“出现三次”的贡献自动归零？**

## 优化思路：按位统计 + 对 3 取模

这道题最经典的做法就是位运算。

### 核心想法

不要把每个数字当成一个整体去看，
而是把每个数字拆成二进制的每一位分别统计。

对于第 `i` 位：

- 统计数组里所有数字在这一位上有多少个 `1`
- 如果这个数量是 `3` 的倍数，说明这一位上“出现三次的那些数”已经完全抵消了
- 如果不是 `3` 的倍数，说明那个只出现一次的数字在这一位上是 `1`

也就是说：

```text
当前位答案 = 这一位上 1 的总个数 % 3
```

### 为什么这样一定成立

因为除了目标数字以外，其余数字都出现了三次。

假设某一位上：

- 某个重复数字这一位是 `0`，它贡献 `0 + 0 + 0 = 0`
- 某个重复数字这一位是 `1`，它贡献 `1 + 1 + 1 = 3`

不管怎样，所有“出现三次”的数字在这一位上的贡献，一定都是 `3` 的倍数。

所以最后剩下的不是：

- `0`，说明答案这一位是 `0`

就是：

- `1`，说明答案这一位是 `1`

### 为什么要遍历 32 位

题目中的整数通常按 **32 位有符号整数** 来处理。

所以我们直接遍历：

```python
for i in range(32):
```

这样可以统一处理：

- 正数
- 负数
- 符号位

## 用示例手推一遍

我们用示例 1：

```text
nums = [2,2,3,2]
```

先把它们写成二进制（这里只看低 4 位就够了）：

```text
2 = 0010
2 = 0010
3 = 0011
2 = 0010
```

### 第 0 位

看最右边这一位：

```text
0 + 0 + 1 + 0 = 1
```

`1 % 3 = 1`

说明答案的第 0 位是 `1`。

### 第 1 位

看倒数第二位：

```text
1 + 1 + 1 + 1 = 4
```

`4 % 3 = 1`

说明答案的第 1 位也是 `1`。

### 第 2 位及更高位

这些位上的 `1` 的数量对 `3` 取模后都为 `0`，
所以答案这些位都是 `0`。

最后得到：

```text
0011
```

也就是：

```text
3
```

## 为什么这样写

### 1. 每一位都可以单独处理

一个整数的每一位彼此独立。

我们完全可以：

- 先求第 `0` 位答案
- 再求第 `1` 位答案
- 再求第 `2` 位答案
- ...

最后再把这些位拼回去。

这就是为什么可以写成：

```python
for i in range(32):
```

### 2. 对 3 取模就是在“消掉重复三次的贡献”

这道题的特殊条件不是“重复两次”，也不是“重复四次”，
而是恰好“重复三次”。

所以我们统计某一位上 `1` 的总数后，
最自然的处理方式就是：

```python
count % 3
```

余数只可能是：

- `0`：答案这一位是 `0`
- `1`：答案这一位是 `1`

### 3. Python 要手动处理负数结果

这道题里有一个很容易忽略的点：

- Python 的整数不是固定 32 位
- 但题目是按 32 位有符号整数来理解的

所以如果最终拼出来的结果最高位（第 31 位）是 `1`，
那它其实应该表示一个负数。

因此最后要做一次转换：

```python
if result >= 1 << 31:
    result -= 1 << 32
```

这样才能把 Python 里的大正数还原成题目意义下的负数。

## 算法步骤

1. 初始化答案 `result = 0`
2. 遍历 32 个二进制位
3. 对于当前位 `i`，统计所有数字在这一位上有多少个 `1`
4. 计算 `count % 3`
5. 如果余数为 `1`，说明答案在这一位上是 `1`，把它加入 `result`
6. 32 位全部处理完后，判断结果是否需要转换成负数
7. 返回最终答案

## 复杂度分析

### 时间复杂度

`O(n)`

更准确地说是：

```text
O(32 × n)
```

因为我们一共统计 32 个二进制位，而 32 是常数，
所以整体仍然可以写成 `O(n)`。

### 空间复杂度

`O(1)`

因为我们只用了：

- 若干计数变量
- 一个结果变量

没有使用随输入规模增长的额外存储空间。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        # 用 result 来逐位拼出最终答案
        result = 0

        # 题目按 32 位有符号整数来处理
        # 所以我们固定统计 0 到 31 这 32 个二进制位
        for i in range(32):
            # 统计当前第 i 位上总共有多少个 1
            bit_count = 0

            for num in nums:
                # (num >> i) & 1 的含义是：
                # 1. 先把第 i 位移动到最低位
                # 2. 再和 1 做按位与，只保留最低位
                # 这样就能得到 num 的第 i 位到底是 0 还是 1
                bit_count += (num >> i) & 1

            # 如果这一位上 1 的总数不是 3 的倍数，
            # 说明只出现一次的那个数在这一位上是 1
            if bit_count % 3 != 0:
                result |= 1 << i

        # Python 的整数没有固定 32 位，
        # 如果第 31 位是 1，这里得到的会是一个很大的正数，
        # 需要把它还原成 32 位有符号整数意义下的负数
        if result >= 1 << 31:
            result -= 1 << 32

        return result
```

## 这段代码最值得记住的地方

这题最值得记住的不是整段代码，
而是下面这条主线：

```python
for i in range(32):
    bit_count = 0
    for num in nums:
        bit_count += (num >> i) & 1

    if bit_count % 3:
        result |= 1 << i
```

本质上就是一句话：

**把所有数字拆成二进制位分别统计，让“出现三次”的贡献通过 `% 3` 自动消失。**

## 常见错误

### 1. 直接用哈希表计数

这种写法虽然能做出来，
但额外空间复杂度是 `O(n)`，
不符合这道题想训练的位运算思路。

### 2. 忘记处理负数

很多人把 32 位都统计完以后直接返回 `result`，
这样在答案是负数时会出错。

因为 Python 不会自动把它当成 32 位有符号整数。

### 3. 没有固定统计 32 位

如果只根据某些数字当前的长度去决定遍历多少位，
遇到负数时就容易出问题。

最稳妥的写法就是固定：

```python
range(32)
```

### 4. 写错“把第 i 位放回答案里”的方式

有些人统计完余数后，知道当前位应该是 `1`，
却忘了把它放回正确的位置。

标准写法是：

```python
result |= 1 << i
```

## 适合自己默写的精简版本

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        result = 0
        for i in range(32):
            count = 0
            for num in nums:
                count += (num >> i) & 1
            if count % 3:
                result |= 1 << i

        if result >= 1 << 31:
            result -= 1 << 32
        return result
```

## 一句话总结

这道题的关键就是：

**逐位统计所有数字中 `1` 出现的次数，对 `3` 取模后重建答案，再补上 32 位有符号整数的负数处理。**
