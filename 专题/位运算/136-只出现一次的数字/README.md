# 136. 只出现一次的数字

## 所属专题

- 位运算

## 题目描述

给你一个 **非空整数数组** `nums`，
除了某个元素只出现 **一次** 以外，
其余每个元素都恰好出现 **两次**。

请你找出那个只出现一次的元素。

题目还要求：

- 时间复杂度为 `O(n)`
- 尽量不使用额外空间

## 示例

### 示例 1

```text
输入：nums = [2,2,1]
输出：1
```

### 示例 2

```text
输入：nums = [4,1,2,1,2]
输出：4
```

### 示例 3

```text
输入：nums = [1]
输出：1
```

## 题意理解

这道题的信息非常关键：

- 只有一个数字出现了 `1` 次
- 其他所有数字都出现了 `2` 次

我们要做的不是统计所有数字的出现次数再慢慢找，
而是利用这个“成对出现，只有一个落单”的特征，
把问题尽量简化。

题目还额外要求：

- 线性时间 `O(n)`
- 最好不用额外空间

这意味着很多常规思路虽然能做出来，
但不一定满足题目的进阶要求。

## 最直接的想法：哈希表计数

最容易想到的方法是：

- 用一个哈希表统计每个数字出现了几次
- 再遍历哈希表，找到那个出现次数为 `1` 的数字

例如：

```text
nums = [4,1,2,1,2]
```

统计结果可能是：

```python
{
    4: 1,
    1: 2,
    2: 2
}
```

于是答案就是 `4`。

这个方法的优点是：

- 很直观
- 很容易写对

但问题也很明显：

- 时间复杂度是 `O(n)`
- 空间复杂度也是 `O(n)`

它能通过题目，
但不满足“尽量不使用额外空间”的进阶要求。

所以我们还要继续想：

**有没有一种方式，不用额外开哈希表，也能把成对出现的数字自动消掉？**

## 优化思路：异或运算

这道题最经典的解法就是：

- 把数组中所有数字依次做异或运算

最后剩下的结果，
就是那个只出现一次的数字。

### 异或的三个核心性质

我们只需要记住下面三条：

1. 任何数和 `0` 异或，结果还是它本身

```text
a ^ 0 = a
```

2. 任何数和自己异或，结果是 `0`

```text
a ^ a = 0
```

3. 异或满足交换律和结合律

```text
a ^ b ^ a = (a ^ a) ^ b = 0 ^ b = b
```

这三条一组合，
就特别适合处理“别的数字都成对出现”的题目。

## 为什么异或正好适合这道题

因为除了一个数字以外，
其他数字都出现两次。

如果把所有数字全部异或起来：

- 成对的数字会两两抵消成 `0`
- 最后只剩下那个没有配对的数字

例如：

```text
[4,1,2,1,2]
```

全部异或就是：

```text
4 ^ 1 ^ 2 ^ 1 ^ 2
```

利用交换律和结合律，
可以重排成：

```text
4 ^ (1 ^ 1) ^ (2 ^ 2)
```

再利用 `a ^ a = 0`：

```text
4 ^ 0 ^ 0 = 4
```

所以答案就是：

```text
4
```

## 为什么结果变量可以从 `0` 开始

代码里通常会这样写：

```python
result = 0
for num in nums:
    result ^= num
```

为什么可以从 `0` 开始？

因为：

```text
0 ^ a = a
```

也就是说：

- 第一次异或时，相当于直接把第一个数放进去
- 后面不断把新的数字异或进来

所以 `0` 是最自然的初始值。

## 用示例手推一遍

以示例 2 为例：

```text
nums = [4,1,2,1,2]
```

初始化：

```text
result = 0
```

### 第 1 步：异或 `4`

```text
result = 0 ^ 4 = 4
```

### 第 2 步：异或 `1`

```text
result = 4 ^ 1
```

先不用算十进制具体值，
知道“结果中同时保留了 4 和 1 的信息”就行。

### 第 3 步：异或 `2`

```text
result = 4 ^ 1 ^ 2
```

### 第 4 步：再异或一个 `1`

```text
result = 4 ^ 1 ^ 2 ^ 1
      = 4 ^ (1 ^ 1) ^ 2
      = 4 ^ 0 ^ 2
      = 4 ^ 2
```

可以看到，
两个 `1` 已经抵消掉了。

### 第 5 步：再异或一个 `2`

```text
result = 4 ^ 2 ^ 2
      = 4 ^ 0
      = 4
```

最终答案就是：

```text
4
```

## 为什么这种写法一定成立

这道题能用异或，
本质原因不是“异或很神奇”，
而是因为题目满足下面这个结构：

- 一个数字只出现一次
- 其余数字全部刚好出现两次

只要是“出现两次”的数字，
在整体异或里一定会被消掉。

而且异或满足交换律，
所以这些配对数字即使在数组中不挨着出现，
也完全不影响最后结果。

例如：

```text
[2,1,4,1,2]
```

虽然两个 `2`、两个 `1` 不在一起，
但整体异或仍然可以看成：

```text
(2 ^ 2) ^ (1 ^ 1) ^ 4 = 4
```

这就是这道题最核心的地方。

## 算法步骤

1. 初始化结果变量 `result = 0`
2. 遍历数组中的每个数字 `num`
3. 让 `result` 与当前数字做异或：`result ^= num`
4. 遍历结束后，返回 `result`

## 复杂度分析

### 时间复杂度

`O(n)`

因为：

- 只遍历数组一遍
- 每次异或操作都是常数时间

### 空间复杂度

`O(1)`

因为：

- 只使用了一个结果变量
- 没有额外使用哈希表、集合或其他线性空间

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        # result 用来保存“当前所有元素异或之后的结果”。
        # 一开始设为 0，是因为 0 ^ a = a，
        # 这样第一个数异或进来后，结果就是它本身。
        result = 0

        # 依次把数组中的每个数字都异或到 result 里。
        for num in nums:
            # 如果某个数字出现两次，那么它们会互相抵消：
            # a ^ a = 0
            # 所以遍历结束后，只会剩下那个只出现一次的数字。
            result ^= num

        return result
```

## 这段代码最值得记住的地方

真正值得记住的就一行：

```python
result ^= num
```

它背后的含义是：

**把所有成对出现的数字全部抵消掉，最后留下唯一那个没有配对的数字。**

所以这题不是“硬记模板”，
而是要记住：

- 成对出现
- 想到抵消
- 抵消想到异或

## 常见错误

### 1. 用哈希表统计，但忘了进阶要求

哈希表当然能做，
而且也不难。

但它的空间复杂度是：

`O(n)`

不满足题目希望的 `O(1)` 额外空间。

### 2. 把异或写成别的运算

这题必须是：

```python
^
```

不是：

- `|`
- `&`
- `+`

只有异或才具备“相同数字互相抵消”的性质。

### 3. 误以为要先排序

排序后确实也能通过相邻元素找落单数字，
但时间复杂度会变成：

`O(n log n)`

不符合题目要求的线性时间。

### 4. 没有理解“为什么可以整体异或”

有些人会记住代码，
但不明白为什么顺序无所谓。

关键就在于异或满足：

- 交换律
- 结合律

所以我们可以放心地把相同数字看成最终会配对消掉。

## 适合自己默写的精简版本

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        result = 0
        for num in nums:
            result ^= num
        return result
```

## 一句话总结

这道题的关键是：

**利用异或中 `a ^ a = 0`、`a ^ 0 = a` 的性质，把所有成对数字抵消掉，最后剩下的就是只出现一次的那个数。**
