# 124. 二叉树中的最大路径和

## 所属专题

- 二叉树

## 题目描述

路径被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。

需要注意：

- 同一个节点在一条路径中 **至多出现一次**
- 路径 **至少包含一个节点**
- 路径 **不一定经过根节点**

路径和，就是这条路径上所有节点值的总和。

给你一个二叉树的根节点 `root`，返回其 **最大路径和**。

## 示例

### 示例 1

```text
输入：root = [1,2,3]
输出：6
解释：
最优路径是 2 -> 1 -> 3
路径和为 2 + 1 + 3 = 6
```

### 示例 2

```text
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：
最优路径是 15 -> 20 -> 7
路径和为 15 + 20 + 7 = 42
```

## 题意理解

这道题最容易误解的地方在于“路径”的定义。

它不是说：

- 必须从根节点出发
- 必须走到叶子节点
- 必须自上而下只走一条边到底

它真正允许的是：

- 路径可以从任意节点开始
- 路径可以在任意节点结束
- 只要路径上的节点彼此通过父子关系连通即可

例如：

```text
    20
   /  \
 15    7
```

路径可以是：

- `20`
- `15 -> 20`
- `20 -> 7`
- `15 -> 20 -> 7`

其中：

- `15 -> 20 -> 7`

虽然“拐了一个弯”，
但它仍然是一条合法路径，
因为它始终沿着父子连接移动，
而且没有重复节点。

所以这道题的核心不是“某一条固定方向的路径”，
而是：

- 在整棵树里，找出任意一条合法路径，使路径和最大

## 最直接的想法：枚举所有路径

最容易想到的思路是：

- 枚举每个节点作为起点
- 再去尝试所有可能延伸出来的路径
- 最后比较所有路径和的最大值

这个想法理论上可行，
但实现起来会非常复杂。

因为对于每个节点：

- 你要考虑往左走
- 往右走
- 还要考虑路径可能在某个节点“左边一段 + 当前节点 + 右边一段”拼起来

也就是说，路径并不是简单的一条“从上到下”的线，
而可能在某个节点形成一个“拱形结构”。

如果硬枚举，重复计算会很多，
效率也会比较差。

所以我们需要一个更适合树结构的递归思路。

## 优化思路：递归计算“最大增益”

这是这道题最经典的做法。

### 第一步：先想清楚递归函数该返回什么

很多人一开始会直接想：

- 递归函数是不是返回“当前子树里的最大路径和”？

这样想不太好写。

更自然的想法是定义：

```text
maxGain(node)
```

表示：

- **从当前节点 `node` 出发，向下走，最多只能选一条分支时，能够提供给父节点的最大路径和**

这里有两个关键词必须抓住：

- 从当前节点出发
- 只能选一边往上交给父节点

为什么只能选一边？

因为如果当前节点已经把：

- 左边一条路径
- 右边一条路径

同时都接上了，
那这条路径就在当前节点这里“封口”了，
不能再继续往父节点延伸。

一条合法路径不可能在父节点那里又继续分叉一次。

所以：

- 返回给父节点的值，只能是 `node.val + max(左增益, 右增益)`

### 第二步：经过当前节点的最大路径和怎么求

虽然返回给父节点时只能选一边，
但在“更新全局答案”时，
当前节点是可以把左右两边都接上的。

也就是说，
经过当前节点的最大路径和可以写成：

```text
node.val + left_gain + right_gain
```

其中：

- `left_gain` 是左子树能提供的最大正增益
- `right_gain` 是右子树能提供的最大正增益

注意这里是：

- 最大正增益

如果某一边的贡献是负数，
那还不如不选。

所以要写成：

```text
left_gain = max(maxGain(node.left), 0)
right_gain = max(maxGain(node.right), 0)
```

这表示：

- 左边如果拖后腿，就当它不存在
- 右边如果拖后腿，也当它不存在

### 第三步：同时维护一个全局最大值

递归函数返回的是：

- 当前节点能向父节点提供的最大单边增益

但题目要的是：

- 整棵树里任意路径的最大路径和

所以我们还需要一个全局变量 `max_sum`，
在遍历每个节点时，用：

```text
current_path = node.val + left_gain + right_gain
```

不断更新它。

## 用示例手推一遍

以示例 2 为例：

```text
root = [-10,9,20,null,null,15,7]
```

树结构是：

```text
       -10
       /  \
      9    20
          /  \
         15   7
```

我们从下往上看。

### 第 1 步：看叶子节点 15

节点 `15` 没有左右孩子。

所以：

- `left_gain = 0`
- `right_gain = 0`
- 经过 `15` 的路径和 = `15`

更新全局最大值：

- `max_sum = 15`

返回给父节点的增益是：

- `15 + max(0, 0) = 15`

### 第 2 步：看叶子节点 7

同理：

- 经过 `7` 的路径和 = `7`
- 当前全局最大值仍然是 `15`
- 返回给父节点的增益是 `7`

### 第 3 步：看节点 20

现在左边返回 `15`，右边返回 `7`。

所以：

- `left_gain = 15`
- `right_gain = 7`

经过节点 `20` 的最大路径和是：

```text
20 + 15 + 7 = 42
```

这说明路径：

```text
15 -> 20 -> 7
```

是一条合法路径。

更新全局最大值：

- `max_sum = 42`

但是，节点 `20` 返回给它父节点 `-10` 的时候，
不能左右两边都带上，
只能选较大的一边。

所以返回值是：

```text
20 + max(15, 7) = 35
```

### 第 4 步：看叶子节点 9

节点 `9` 返回给父节点的增益是：

- `9`

### 第 5 步：看根节点 -10

现在：

- 左边增益是 `9`
- 右边增益是 `35`

经过 `-10` 的路径和是：

```text
-10 + 9 + 35 = 34
```

这比当前的 `42` 小，
所以全局最大值不变。

最终答案仍然是：

```text
42
```

## 为什么这样写

### 1. “返回给父节点的值”和“当前节点处的最优路径”不是一回事

这是这道题最关键的点。

对于某个节点，
我们实际上在算两个不同的东西：

#### 返回值

返回给父节点的是：

- 从当前节点出发，向下延伸时，最多能提供多大的单边增益

所以只能选：

- 当前节点 + 左边

或者：

- 当前节点 + 右边

不能左右都选。

#### 当前节点处的完整路径值

而用于更新全局答案时，
可以同时把左右两边都接上：

- 左边路径 + 当前节点 + 右边路径

这两个量非常像，
但含义完全不同。

### 2. 为什么负数增益要直接舍弃

如果左子树给你的增益是 `-3`，
那把它接到路径里只会让总和更小。

所以与其带上它，
不如直接不要。

这就是为什么要写：

```python
left_gain = max(maxGain(node.left), 0)
```

意思就是：

- 这边如果有帮助就接上
- 如果没帮助，就当作贡献是 `0`

### 3. 为什么全局最大值要初始化为负无穷

因为节点值可能全是负数。

例如：

```text
[-3]
```

答案应该是：

```text
-3
```

如果你把 `max_sum` 初始化成 `0`，
那就会错误地得到 `0`。

但路径至少要包含一个节点，
所以不能把“空路径”当答案。

因此应该初始化为：

```python
float('-inf')
```

### 4. 为什么这题适合后序遍历思想

因为当前节点要先知道：

- 左子树能提供多少增益
- 右子树能提供多少增益

然后才能计算：

- 当前节点的返回值
- 当前节点能形成的完整路径和

所以一定要先算子树，
再算当前节点。

这本质上就是：

- 后序遍历思想

## 算法步骤

1. 定义全局变量 `max_sum`，初始值为负无穷
2. 定义递归函数 `maxGain(node)`
3. 如果当前节点为空，返回 `0`
4. 递归计算左子树最大增益，并和 `0` 取较大值
5. 递归计算右子树最大增益，并和 `0` 取较大值
6. 计算经过当前节点的完整路径和 `node.val + left_gain + right_gain`
7. 用这个值更新全局最大路径和 `max_sum`
8. 返回给父节点的值为 `node.val + max(left_gain, right_gain)`
9. 从根节点开始递归
10. 最终返回 `max_sum`

## 复杂度分析

### 时间复杂度

`O(n)`

其中：

- `n` 是二叉树的节点总数

原因是：

- 每个节点都只会被访问一次

### 空间复杂度

`O(h)`

其中：

- `h` 是二叉树的高度

原因是：

- 递归调用栈的深度最多等于树高

如果树退化成链表，
最坏情况下空间复杂度会变成：

```text
O(n)
```

## Python 参考实现（详细注释）

```python
from typing import Optional


class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        # 记录整棵树中目前找到的最大路径和。
        # 这里必须初始化为负无穷，
        # 因为节点值可能全部是负数。
        max_sum = float('-inf')

        def maxGain(node: Optional[TreeNode]) -> int:
            nonlocal max_sum

            # 空节点不能提供任何增益。
            if not node:
                return 0

            # 递归计算左子树和右子树能提供的最大增益。
            # 如果某一边是负收益，就直接舍弃，按 0 处理。
            left_gain = max(maxGain(node.left), 0)
            right_gain = max(maxGain(node.right), 0)

            # 经过当前节点的完整路径和：
            # 左边最大贡献 + 当前节点 + 右边最大贡献。
            current_path = node.val + left_gain + right_gain

            # 用当前路径和更新全局最大答案。
            max_sum = max(max_sum, current_path)

            # 返回给父节点的只能是一条单边路径：
            # 当前节点 + 左右子树中贡献更大的那一边。
            return node.val + max(left_gain, right_gain)

        maxGain(root)
        return max_sum
```

## 这段代码最值得记住的地方

最关键的是区分这两个公式：

### 用来更新答案的公式

```python
current_path = node.val + left_gain + right_gain
```

这表示：

- 路径在当前节点这里拐弯
- 左右两边都可以接上

### 用来返回给父节点的公式

```python
return node.val + max(left_gain, right_gain)
```

这表示：

- 路径如果还要继续向上走
- 就只能带一边

你只要真正理解这两个公式的区别，
这道题就掌握了大半。

## 常见错误

### 1. 把返回值误写成 `node.val + left_gain + right_gain`

这是最典型的错误。

返回给父节点时，
路径不能同时带左右两边一起向上，
否则就不是一条合法路径了。

正确返回值应该是：

```python
node.val + max(left_gain, right_gain)
```

### 2. 忘记把负贡献裁掉

如果不写：

```python
max(maxGain(node.left), 0)
```

那么负数子树会把路径和拖小，
结果就可能错误。

### 3. 把 `max_sum` 初始化成 `0`

当整棵树全是负数时，
这会导致答案错误。

例如：

```text
root = [-3]
```

正确答案是 `-3`，
不是 `0`。

### 4. 误以为路径必须经过根节点

这道题最优路径可能完全在某一棵子树内部。

例如示例 2 的最优路径：

```text
15 -> 20 -> 7
```

就根本没有经过根节点 `-10`。

## 适合你自己再写一遍的版本

```python
from typing import Optional


class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        max_sum = float('-inf')

        def maxGain(node: Optional[TreeNode]) -> int:
            nonlocal max_sum
            if not node:
                return 0

            left_gain = max(maxGain(node.left), 0)
            right_gain = max(maxGain(node.right), 0)

            max_sum = max(max_sum, node.val + left_gain + right_gain)
            return node.val + max(left_gain, right_gain)

        maxGain(root)
        return max_sum
```

## 一句话总结

这道题的关键不是“从根往下找最大和”，而是：

**递归计算每个节点能向父节点提供的最大单边增益，同时把“左增益 + 当前节点 + 右增益”作为经过该节点的完整路径去更新全局答案。**
