# 236. 二叉树的最近公共祖先

## 所属专题

- 二叉树

## 题目描述

给定一个二叉树，找到该树中两个指定节点 `p` 和 `q` 的最近公共祖先。

最近公共祖先 的定义为：

> 对于有根树 `T` 的两个节点 `p`、`q`，最近公共祖先表示为一个节点 `x`，满足 `x` 是 `p`、`q` 的祖先，且 `x` 的深度尽可能大。

题目还特别提醒我们：

- 一个节点也可以是它自己的祖先

这句话非常重要，因为它决定了：

- 如果 `p` 本身就是 `q` 的祖先，那么答案就是 `p`
- 如果 `q` 本身就是 `p` 的祖先，那么答案就是 `q`

## 示例

### 示例 1

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3。
```

对应的二叉树如下：

```text
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```

### 示例 2

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5。
```

注意这里体现了题目的关键条件：

- 节点可以是它自己的祖先

因为 `5` 本身就在从根到 `4` 的路径上，所以答案不是更上面的 `3`，而是更近的 `5`。

### 示例 3

```text
输入：root = [1,2], p = 1, q = 2
输出：1
```

## 题意理解

这道题要找的不是：

- 两个节点共同的某个祖先

而是：

- **离这两个节点最近的那个公共祖先**

“最近”可以理解为：

- 这个祖先要尽可能靠下
- 也就是深度尽可能大

比如示例 1 里：

- `3` 是 `5` 和 `1` 的公共祖先
- 更下面已经没有别的节点能同时做 `5` 和 `1` 的祖先

所以答案是 `3`。

而示例 2 里：

- `5` 是 `4` 的祖先
- 同时 `5` 也是它自己本身

所以最近公共祖先就是 `5`。

这道题最核心的一点是：

- 你不需要从某个节点一直往上找父节点
- 因为题目只给了根节点 `root`
- 所以更自然的做法是：**从上往下递归搜索，再从下往上汇总信息**

## 最直接的想法：先找两条路径

最容易想到的办法是：

1. 先找到从根节点到 `p` 的路径
2. 再找到从根节点到 `q` 的路径
3. 比较这两条路径最后一个相同的节点

比如：

- 根到 `5` 的路径：`3 -> 5`
- 根到 `4` 的路径：`3 -> 5 -> 2 -> 4`

那么它们最后一个相同的节点就是：

- `5`

这个思路是能做出来的。

### 这个思路为什么不算最优雅

因为它通常需要：

- 写一个 DFS / 回溯去记录路径
- 分别找两次路径
- 再做一次路径比较

虽然时间复杂度仍然可以做到 `O(n)`，
但实现上会更绕一些。

对于二叉树来说，
这道题其实有一个非常自然的递归写法，
几乎就是“树形递归模板题”。

## 正解思路：后序递归

这道题最经典的做法是：

- 递归去左子树找 `p` 和 `q`
- 递归去右子树找 `p` 和 `q`
- 再根据左右子树返回的结果，判断当前节点是不是最近公共祖先

### 先想一个问题

假设我们现在站在某个节点 `root` 上，
那我们真正想知道的是：

- `p` 和 `q` 是否分别出现在它的左右子树中
- 或者当前节点本身是不是 `p` / `q`

如果：

- 左边找到了一个目标节点
- 右边也找到了一个目标节点

那么说明当前节点 `root` 正好把 `p` 和 `q` 分隔在两边，
它自然就是最近公共祖先。

如果：

- 只有左边找到了

那就说明答案一定在左子树里，或者左边找到的就是目标节点本身，
我们直接把左边结果往上返回即可。

如果：

- 只有右边找到了

同理，直接返回右边结果。

## 递归函数到底返回什么

理解这道题，最关键的是搞清楚递归函数的返回值。

这里我们定义：

```text
lowestCommonAncestor(root, p, q)
```

它的含义不是单纯“返回最近公共祖先”这么简单，
而是：

- 如果当前子树里没有 `p` 和 `q`，返回 `None`
- 如果当前子树里只找到了 `p`，返回 `p`
- 如果当前子树里只找到了 `q`，返回 `q`
- 如果当前子树里已经确定了最近公共祖先，返回这个最近公共祖先节点

也就是说，
这个函数返回的是：

- **当前子树向上层汇报的重要结果**

这样设计以后，整道题就会非常顺。

## 递归终止条件

### 1. 当前节点为空

如果当前节点为空：

```python
if not root:
    return None
```

说明这棵子树什么都没找到，直接返回 `None`。

### 2. 当前节点就是 `p` 或 `q`

如果：

- `root == p`
- 或者 `root == q`

那么直接返回当前节点。

为什么可以直接返回？

因为：

- 当前节点本身就是目标节点
- 它有可能最终成为最近公共祖先
- 尤其是在“一个节点可以是它自己的祖先”这个条件下，这一步不能漏

所以：

```python
if not root or root == p or root == q:
    return root
```

## 递归关系

对于当前节点 `root`：

1. 去左子树查找，得到 `left`
2. 去右子树查找，得到 `right`

然后分情况讨论。

### 情况 1：`left` 和 `right` 都不为空

这说明：

- 左子树找到了一个目标节点
- 右子树也找到了一个目标节点

因此当前节点 `root` 一定就是最近公共祖先：

```python
if left and right:
    return root
```

### 情况 2：只有 `left` 不为空

这说明：

- `p` 和 `q` 都在左子树里
- 或者左子树只找到了其中一个目标节点

这时应该把左边结果继续向上返回：

```python
return left
```

### 情况 3：只有 `right` 不为空

同理，返回右边结果：

```python
return right
```

所以最后可以简写成：

```python
return left if left else right
```

## 用示例手推一遍

我们用示例 1 来看：

```text
root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
```

对应二叉树：

```text
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```

### 第 1 步：看根节点 `3`

我们要先递归去看：

- `3` 的左子树能返回什么
- `3` 的右子树能返回什么

### 第 2 步：进入左子树，看到节点 `5`

此时发现：

- 当前节点 `5` 就是目标节点 `p`

所以根据递归终止条件：

```text
返回节点 5
```

注意这里不会继续往下找，
因为一旦当前节点就是 `p` 或 `q`，
它已经足够成为“向上汇报的信息”了。

### 第 3 步：进入右子树，看到节点 `1`

同理：

- 当前节点 `1` 就是目标节点 `q`

所以：

```text
返回节点 1
```

### 第 4 步：回到根节点 `3`

这时：

- `left = 5`
- `right = 1`

左右两边都不为空，说明：

- 一个目标节点在左边
- 一个目标节点在右边

因此当前节点 `3` 就是最近公共祖先。

最终返回：

```text
3
```

## 再看示例 2 为什么答案是 `5`

示例 2：

```text
p = 5, q = 4
```

当递归走到节点 `5` 时，
由于：

- `root == p`

所以会立刻返回 `5`。

而 `4` 是 `5` 的后代，
在更高层往上收结果时，
最终保留下来的仍然是 `5`。

这正体现了题目的关键条件：

- 一个节点可以是它自己的祖先

所以最近公共祖先不一定是“严格在两个节点上方”的那个点，
也可能就是其中一个节点本身。

## 为什么这样写

这道题的递归之所以漂亮，
是因为它把“找节点”和“判断祖先”合并到了一次后序遍历里。

你可以把每个递归调用理解成：

- 我去这棵子树里帮你找 `p` 和 `q`
- 如果我什么都没找到，我返回 `None`
- 如果我只找到一个，我把那个节点带回来
- 如果我左右两边各找到一个，那我就直接告诉你：当前节点就是答案

于是整棵树只需要遍历一次，
答案就自然在回溯过程中出现了。

## 算法步骤

1. 如果当前节点为空，返回 `None`
2. 如果当前节点等于 `p` 或 `q`，返回当前节点
3. 递归查找左子树，记录结果为 `left`
4. 递归查找右子树，记录结果为 `right`
5. 如果 `left` 和 `right` 都不为空，返回当前节点 `root`
6. 如果只有一边不为空，返回那一边的结果
7. 如果两边都为空，返回 `None`

## 复杂度分析

### 时间复杂度

`O(n)`

原因：

- 每个节点最多被访问一次

其中 `n` 是二叉树中的节点总数。

### 空间复杂度

`O(h)`

原因：

- 递归调用会占用系统栈空间
- 栈深度取决于树的高度 `h`

如果树比较平衡，`h` 大约是 `log n`；
如果树极端退化成链表，最坏情况下空间复杂度会变成：

```text
O(n)
```

## Python 参考实现（详细注释）

```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        # 如果当前节点为空，说明这棵子树里什么都没找到，直接返回 None。
        # 如果当前节点就是 p 或 q，直接返回当前节点。
        # 这里非常关键，因为“一个节点也可以是它自己的祖先”。
        if not root or root == p or root == q:
            return root

        # 去左子树中查找 p 和 q。
        left = self.lowestCommonAncestor(root.left, p, q)

        # 去右子树中查找 p 和 q。
        right = self.lowestCommonAncestor(root.right, p, q)

        # 如果左右子树都找到了结果，说明 p 和 q 分别位于当前节点的两侧。
        # 那么当前节点就是它们的最近公共祖先。
        if left and right:
            return root

        # 如果只有一边找到了，说明：
        # 1. 两个节点都在这一边；或者
        # 2. 这一边只找到了其中一个节点。
        # 无论哪种情况，都把这边的结果继续向上返回。
        return left if left else right
```

## 这段代码最值得记住的地方

自己手写时，最应该记住的是这三层逻辑：

```python
if not root or root == p or root == q:
    return root

left = self.lowestCommonAncestor(root.left, p, q)
right = self.lowestCommonAncestor(root.right, p, q)

if left and right:
    return root
return left if left else right
```

本质上就是一句话：

- **让左右子树先把“有没有找到目标节点”的结果交上来，当前节点再决定自己是不是最近公共祖先。**

## 常见错误

### 1. 忘记处理“节点可以是它自己的祖先”

如果漏掉这句：

```python
if root == p or root == q:
    return root
```

那么像示例 2 这种情况就会出错。

### 2. 只要一边找到了就返回当前节点

这是不对的。

只有在：

- 左边找到了
- 右边也找到了

这两件事同时成立时，当前节点才是最近公共祖先。

如果只有一边找到了，说明答案还在那一边，不应该提前把当前节点当成答案。

### 3. 把题目理解成“比较节点值”而不是“比较节点本身”

在题目语义里，`p` 和 `q` 是节点对象，
我们判断的是：

- 当前节点是不是 `p`
- 当前节点是不是 `q`

而不只是单纯比较某个数值。

### 4. 递归返回值含义不清楚

很多人会写着写着就乱，
根本原因通常是没有想清楚：

- `left` 到底可能是什么
- `right` 到底可能是什么

记住它们只可能是三类结果：

- `None`
- `p` / `q` 中的某一个节点
- 已经求出的最近公共祖先节点

一旦把这个返回值含义想清楚，代码就顺了。

## 适合你自己再写一遍的版本

如果你准备在 `.ipy` 文件里自己默写，
可以先记住这个精简版本：

```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if not root or root == p or root == q:
            return root

        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if left and right:
            return root
        return left if left else right
```

## 一句话总结

这道题的核心就是：

**后序递归，让左右子树先汇报结果；第一个同时从左右两边收到目标节点信息的节点，就是最近公共祖先。**
