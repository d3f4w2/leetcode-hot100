# 103. 二叉树的锯齿形层序遍历

## 所属专题

- 二叉树

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的 **锯齿形层序遍历**。

这里的“锯齿形”指的是：

- 第一层从左到右
- 第二层从右到左
- 第三层再从左到右
- 第四层再从右到左

也就是说：

- 层与层之间的遍历方向要不断交替

最终返回一个二维列表，
其中每个子列表表示一层的节点值。

## 示例

### 示例 1

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[20,9],[15,7]]
```

### 示例 2

```text
输入：root = [1]
输出：[[1]]
```

### 示例 3

```text
输入：root = []
输出：[]
```

## 题意理解

这道题和普通的层序遍历非常像，
本质上仍然是：

- 一层一层访问节点

不同点在于：

- 普通层序遍历：每一层都从左到右
- 这道题：每一层方向交替

例如这棵树：

```text
        3
      /   \
     9     20
          /  \
         15   7
```

如果是普通层序遍历，结果是：

```text
[[3],[9,20],[15,7]]
```

但这题要求第二层反过来，
所以答案变成：

```text
[[3],[20,9],[15,7]]
```

所以可以把这题理解成：

- 先按层遍历
- 再在每一层收集答案时，按照当前层方向决定顺序

## 最直接的想法：先正常按层遍历，再把需要的层翻转

最容易想到的方法是：

1. 先做普通层序遍历
2. 得到每一层从左到右的结果
3. 如果当前层应该从右到左，就把这一层翻转

比如：

```text
普通层序结果：[[3],[9,20],[15,7]]
把第 2 层翻转：[[3],[20,9],[15,7]]
```

这个思路其实已经能通过这道题了。

因为：

- 层序遍历本来就是正确的主体
- 锯齿形只是额外多了一个“方向变化”的要求

## 优化思路：层序遍历 + 方向标志

### 核心想法

我们还是使用队列做广度优先搜索（BFS），
因为题目本质没有变：

- 仍然是在按层遍历二叉树

只不过我们额外加一个方向标志 `left_to_right`：

- 如果它是 `True`，当前层从左到右收集
- 如果它是 `False`，当前层从右到左收集

这样每处理完一层后，
把这个标志取反即可：

```python
left_to_right = not left_to_right
```

### 两种实现方式

#### 写法一：先正常加入，最后翻转

做法是：

- 当前层先按弹出顺序收集到列表里
- 如果这一层方向是从右到左，就调用 `reverse()`

优点：

- 容易理解
- 容易默写

#### 写法二：收集时直接控制方向

还可以在当前层使用双端队列 `deque`：

- 从左到右时，用 `append()`
- 从右到左时，用 `appendleft()`

这样这一层收集完之后，
天然就是目标顺序，
不需要再额外翻转。

这份 README 的详细代码用的是这种写法，
因为它更能体现“方向控制”的本质。

## 用示例手推一遍

以：

```text
root = [3,9,20,null,null,15,7]
```

为例。

对应二叉树：

```text
        3
      /   \
     9     20
          /  \
         15   7
```

初始状态：

```text
queue = [3]
result = []
left_to_right = True
```

### 第 1 层

- 当前队列里只有 `3`
- 这一层方向是从左到右

处理 `3`：

- 把 `3` 加入当前层结果
- 把它的左右孩子 `9`、`20` 加入队列

这一层结束后：

```text
result = [[3]]
queue = [9,20]
left_to_right = False
```

### 第 2 层

- 当前层节点是 `9`、`20`
- 这一层方向是从右到左

按队列顺序弹出时仍然是：

- 先弹出 `9`
- 再弹出 `20`

但由于当前层要求“从右到左”，
所以收集时：

- `9` 放到当前层结果左边
- `20` 再放到当前层结果左边

于是当前层结果变成：

```text
[20,9]
```

同时把 `20` 的左右孩子 `15`、`7` 放入队列。

这一层结束后：

```text
result = [[3],[20,9]]
queue = [15,7]
left_to_right = True
```

### 第 3 层

- 当前层节点是 `15`、`7`
- 方向重新变回从左到右

所以这一层结果是：

```text
[15,7]
```

最终得到：

```text
[[3],[20,9],[15,7]]
```

## 为什么这样写

### 1. 题目本质仍然是层序遍历

虽然题目名字里多了“锯齿形”，
但“锯齿形”并没有改变遍历框架。

真正的主干仍然是：

- 一层一层处理节点

因此最自然的基础解法仍然是 BFS + 队列。

### 2. 方向变化只影响“当前层结果的存放顺序”

这题里一个很容易混淆的点是：

- 当前层从右到左输出

并不意味着：

- 下一层入队时也要改成先右后左

队列里子节点的加入顺序仍然保持：

- 先左孩子
- 再右孩子

因为我们要保证下一层的节点结构仍然是正常的层序顺序。

真正需要改变的，
只是“当前层答案怎么放”。

### 3. 用布尔标志切换方向非常直观

每处理完一层，
方向一定会变化一次。

所以用一个布尔变量：

```python
left_to_right = not left_to_right
```

就可以非常清楚地表达：

- 这一层从左到右
- 下一层从右到左
- 再下一层又从左到右

逻辑非常顺。

## 算法步骤

1. 如果根节点为空，直接返回空列表 `[]`
2. 创建结果列表 `result`
3. 创建队列 `queue`，先把根节点放进去
4. 创建方向标志 `left_to_right = True`
5. 当队列不为空时，先记录当前层节点数 `level_size`
6. 创建一个双端队列 `level`，用于保存当前层结果
7. 循环 `level_size` 次，每次从队列头部取出一个节点
8. 如果当前层是从左到右，就把节点值加到 `level` 右边
9. 如果当前层是从右到左，就把节点值加到 `level` 左边
10. 如果当前节点有左孩子，就加入队列
11. 如果当前节点有右孩子，就加入队列
12. 当前层结束后，把 `level` 转成列表加入 `result`
13. 切换方向标志
14. 队列为空时，返回 `result`

## 复杂度分析

### 时间复杂度

`O(n)`

其中 `n` 是二叉树中的节点总数。

原因是：

- 每个节点只会进入队列一次
- 每个节点只会从队列中取出一次
- 每个节点的值也只会被加入当前层结果一次

所以整体仍然是线性时间。

### 空间复杂度

`O(n)`

原因是：

- 队列在最坏情况下可能同时保存一整层节点
- 结果列表需要保存所有节点值
- 当前层的双端队列也最多保存一层节点

因此总体空间复杂度是 `O(n)`。

## Python 参考实现（详细注释）

```python
from collections import deque


class Solution:
    def zigzagLevelOrder(self, root):
        # 如果整棵树为空，直接返回空列表。
        if not root:
            return []

        # result 用来保存最终答案。
        result = []

        # queue 用来做层序遍历。
        # 初始时把根节点放进去。
        queue = deque([root])

        # True 表示当前层从左到右。
        # False 表示当前层从右到左。
        left_to_right = True

        # 只要队列里还有节点，就说明还有层没有处理完。
        while queue:
            # 当前层的节点个数。
            level_size = len(queue)

            # 用双端队列收集当前层结果。
            # 这样就可以根据方向决定从左放还是从右放。
            level = deque()

            # 这一轮只处理当前层的节点。
            for _ in range(level_size):
                node = queue.popleft()

                # 如果当前层方向是从左到右，
                # 就把节点值放到 level 的右边。
                if left_to_right:
                    level.append(node.val)
                else:
                    # 如果当前层方向是从右到左，
                    # 就把节点值放到 level 的左边。
                    level.appendleft(node.val)

                # 子节点入队顺序仍然保持“先左后右”。
                # 注意：锯齿形只影响当前层的输出顺序，
                # 不影响下一层节点进入队列的顺序。
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            # 当前层处理完，把双端队列转成普通列表加入答案。
            result.append(list(level))

            # 下一层方向与当前层相反。
            left_to_right = not left_to_right

        return result
```

## 这段代码最值得记住的地方

最值得记住的是这两个点：

### 1. 还是标准层序遍历骨架

```python
level_size = len(queue)
for _ in range(level_size):
    node = queue.popleft()
```

这几句负责：

- 一次只处理一层
- 不让不同层的数据混在一起

### 2. 锯齿形的本质只是“当前层怎么放值”

```python
if left_to_right:
    level.append(node.val)
else:
    level.appendleft(node.val)
```

也就是说：

- 遍历节点的顺序本质上还是层序
- 真正变化的只是当前层结果的拼接方向

## 常见错误

### 1. 误以为从右到左时，子节点也要先右后左入队

这是最常见的误区之一。

要记住：

- 队列维护的是“层序遍历结构”
- 锯齿形只影响当前层结果的输出顺序

所以子节点仍然应该：

- 先左孩子入队
- 再右孩子入队

### 2. 忘记每一层结束后切换方向

如果漏掉：

```python
left_to_right = not left_to_right
```

那整棵树就会一直按照同一个方向遍历，
失去“锯齿形”的效果。

### 3. 不先记录当前层节点数，导致层与层混在一起

如果没有：

```python
level_size = len(queue)
```

那么你在遍历当前层的同时又不断往队列里加入下一层节点，
就很容易让不同层的数据混在一起。

### 4. 使用双端队列后，忘记转成普通列表

如果当前层用了 `deque`，
最后加入答案时最好写成：

```python
result.append(list(level))
```

这样最终返回值就和题目要求的列表格式保持一致。

### 5. 没有处理空树

如果 `root = []`，
应该直接返回：

```python
[]
```

而不是报错，
也不是返回 `None`。

## 适合你自己再写一遍的版本

如果你想先记一个最容易默写的版本，
推荐记下面这个“先收集、再翻转”的写法：

```python
from collections import deque


class Solution:
    def zigzagLevelOrder(self, root):
        if not root:
            return []

        result = []
        queue = deque([root])
        left_to_right = True

        while queue:
            level = []

            for _ in range(len(queue)):
                node = queue.popleft()
                level.append(node.val)

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            if not left_to_right:
                level.reverse()

            result.append(level)
            left_to_right = not left_to_right

        return result
```

如果你想记住更贴近“方向控制本质”的版本，
就记详细实现里的 `deque + appendleft()` 写法。

## 一句话总结

这道题的关键是：

**主体仍然是标准的层序遍历，所谓锯齿形只是给每一层加上一个方向标志，让当前层结果在“从左到右”和“从右到左”之间交替即可。**
