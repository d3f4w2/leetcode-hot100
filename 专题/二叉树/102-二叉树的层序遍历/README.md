# 102. 二叉树的层序遍历

## 所属专题

- 二叉树

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的 **层序遍历**。

也就是说：

- 按层一层一层访问
- 每一层从左到右访问节点

最终返回一个二维列表，
其中每个子列表表示一层的节点值。

## 示例

### 示例 1

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]
```

### 示例 2

```text
输入：root = [1]
输出：[[1]]
```

### 示例 3

```text
输入：root = []
输出：[]
```

## 题意理解

这道题不是让我们用：

- 前序遍历
- 中序遍历
- 后序遍历

去一条路走到底，
而是要求：

- 先访问第 1 层
- 再访问第 2 层
- 再访问第 3 层

也就是典型的“按层扩散”的顺序。

例如：

```text
        3
      /   \
     9     20
          /  \
         15   7
```

按层遍历的顺序应该是：

- 第 1 层：`[3]`
- 第 2 层：`[9,20]`
- 第 3 层：`[15,7]`

所以最终结果是：

```text
[[3],[9,20],[15,7]]
```

## 最直接的想法：一层一层往下扫

题目既然强调“层序遍历”，
那最自然的思路就是：

- 先处理当前层的所有节点
- 再把下一层的节点收集起来
- 然后继续处理下一层

这种“从近到远、逐层推进”的方式，
正是广度优先搜索（BFS）的典型特征。

而 BFS 最常用的数据结构就是：

- 队列

因为队列是先进先出，
非常适合维护“当前层先进去的节点先处理”。

## 优化思路：使用队列进行广度优先搜索

### 核心想法

我们用一个队列 `queue` 来保存当前还没有处理的节点。

一开始：

- 把根节点放进队列

然后重复下面的过程：

1. 先记录当前队列的长度，也就是当前层的节点数
2. 把这一层的节点依次取出来
3. 记录它们的值
4. 再把它们的左右孩子加入队列
5. 当前层处理完后，把这一层的结果加入答案

这样循环下去，
直到队列为空为止。

### 为什么要先记录当前层节点数

因为队列里不仅有当前层的节点，
在处理过程中还会不断加入下一层的节点。

如果不先记录“这一层原本有多少个节点”，
就会把下一层也一起处理掉，
导致层和层之间混在一起。

所以每次进入 `while queue:` 时，
都要先做：

```python
level_size = len(queue)
```

这个 `level_size` 就表示：

- 当前这一层总共有多少个节点

接下来只循环这么多次，
就能保证这一轮只处理当前层。

## 用示例手推一遍

以：

```text
root = [3,9,20,null,null,15,7]
```

为例。

对应的树是：

```text
        3
      /   \
     9     20
          /  \
         15   7
```

### 初始状态

队列中只有根节点：

```text
queue = [3]
result = []
```

### 第 1 轮

- `level_size = 1`
- 说明当前层只有一个节点：`3`

处理后：

- 当前层结果：`[3]`
- 把 `9` 和 `20` 加入队列

此时：

```text
result = [[3]]
queue = [9,20]
```

### 第 2 轮

- `level_size = 2`
- 说明当前层有两个节点：`9` 和 `20`

处理 `9`：

- 记录值 `9`
- 它没有子节点，不入队

处理 `20`：

- 记录值 `20`
- 把 `15` 和 `7` 加入队列

此时：

```text
result = [[3],[9,20]]
queue = [15,7]
```

### 第 3 轮

- `level_size = 2`
- 当前层节点是 `15` 和 `7`

处理后：

```text
result = [[3],[9,20],[15,7]]
queue = []
```

队列为空，遍历结束。

## 为什么这样写

### 1. 层序遍历天然适合 BFS

树的遍历里：

- 深度优先搜索更适合“一条路走到底”
- 广度优先搜索更适合“一层一层向外扩展”

这道题明确要求按层访问，
所以 BFS 是最贴切的做法。

### 2. 队列正好维护访问顺序

当前层的节点先进入队列，
就会先被取出来处理。

而它们的孩子会在后面进入队列，
自然就形成了“先当前层，后下一层”的顺序。

### 3. 每一轮 `for` 循环只处理一层

这道题能否写对的关键，
就在于“分层”这一步。

通过：

```python
level_size = len(queue)
```

我们固定住当前层节点个数，
然后只弹出这 `level_size` 个节点。

这样即使过程中不断加入子节点，
也不会影响当前层的处理边界。

## 算法步骤

1. 如果根节点为空，返回空列表 `[]`
2. 创建结果列表 `result`
3. 创建队列 `queue`，并把根节点加入队列
4. 当队列不为空时，先记录当前层节点数 `level_size`
5. 创建列表 `level` 用来保存当前层节点值
6. 循环 `level_size` 次，每次从队列头部取出一个节点
7. 把该节点的值加入 `level`
8. 如果左孩子存在，则加入队列
9. 如果右孩子存在，则加入队列
10. 当前层处理完后，把 `level` 加入 `result`
11. 队列为空后，返回 `result`

## 复杂度分析

### 时间复杂度

`O(n)`

其中 `n` 是二叉树的节点数。

原因是：

- 每个节点都会入队一次、出队一次
- 每个节点只会被访问一次

### 空间复杂度

`O(n)`

原因是：

- 队列在最坏情况下可能会同时存储一整层的节点
- 结果列表也需要保存所有节点值

## Python 参考实现（详细注释）

```python
from collections import deque


class Solution:
    def levelOrder(self, root):
        if not root:
            return []

        result = []
        queue = deque([root])

        while queue:
            # 当前层一共有多少个节点
            level_size = len(queue)
            level = []

            for _ in range(level_size):
                node = queue.popleft()
                level.append(node.val)

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            result.append(level)

        return result
```

## 这段代码最值得记住的地方

这题最核心的是下面这几句：

```python
level_size = len(queue)
for _ in range(level_size):
    node = queue.popleft()
```

它表达的意思是：

- 先锁定当前层有多少个节点
- 再一次性把这一层处理完

这就是“层序遍历”能正确分层的关键。

## 常见错误

### 1. 不记录当前层节点数，导致所有节点混在一起

如果你只是一直从队列里取节点、再把子节点加进去，
但没有提前记录 `level_size`，
那就很容易把不同层的数据放进同一个列表里。

### 2. 把这题写成 DFS，却没有正确处理层号

这题当然也可以用 DFS + 层号去做，
但入门时最推荐的还是 BFS，
因为它和“按层遍历”的题意最直接对应。

### 3. 忘记处理空树

如果 `root` 是空，
应该直接返回：

```python
[]
```

### 4. 用列表代替队列时频繁 `pop(0)`

如果用普通列表做队列，
每次 `pop(0)` 的代价较高。

所以更推荐使用：

```python
from collections import deque
```

再配合：

```python
popleft()
```

## 一句话总结

这道题的关键是：

**使用队列做广度优先搜索，每次先固定当前层的节点数，再把这一层从左到右完整处理出来。**
