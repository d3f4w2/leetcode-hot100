# 104. 二叉树的最大深度

## 所属专题
- 二叉树

## 题目描述

给定一个二叉树 `root`，返回它的最大深度。

二叉树的最大深度是指：

- 从根节点到最远叶子节点的最长路径上的节点数

这里的叶子节点指的是：

- 没有左孩子也没有右孩子的节点

## 示例

### 示例 1

```text
输入：root = [3,9,20,null,null,15,7]
输出：3
```

对应的二叉树如下：

```text
    3
   / \
  9  20
    /  \
   15   7
```

最长路径可以是：

- `3 -> 20 -> 15`
- `3 -> 20 -> 7`

所以最大深度为 `3`。

### 示例 2

```text
输入：root = [1,null,2]
输出：2
```

## 题意理解

这道题本质上是在问：

- 以当前节点为根的这棵树有多高

如果你站在某个节点上，
想知道它这棵子树的最大深度，
其实只需要知道两件事：

- 左子树的最大深度
- 右子树的最大深度

谁更深，当前节点这棵树就跟着谁走，
最后再把当前节点自己算进去。

所以这道题最自然的思路就是递归。

## 为什么适合用递归

一棵树的最大深度，
可以拆成左右两棵更小的树的最大深度。

这正符合递归的特点：

- 大问题可以拆成相同类型的小问题
- 每个子问题的解法和原问题完全一致

也就是说，
如果我们已经知道：

- `root.left` 的最大深度
- `root.right` 的最大深度

那么当前节点 `root` 的最大深度就是：

```text
max(左子树深度, 右子树深度) + 1
```

这里的 `+ 1` 表示把当前节点自己也算进去。

## 递归定义

定义函数：

```text
maxDepth(root) = 以 root 为根节点的二叉树最大深度
```

那么题目要的答案就是：

```text
maxDepth(root)
```

## 递归终止条件

如果当前节点为空：

```text
root is None
```

说明这棵树没有节点，
深度自然是 `0`。

所以：

```text
if not root:
    return 0
```

## 递归关系

如果当前节点不为空，
那么它的最大深度等于：

- 左子树最大深度
- 右子树最大深度
- 取两者较大值
- 再加上当前这一层

所以递归关系为：

```text
maxDepth(root) = max(maxDepth(root.left), maxDepth(root.right)) + 1
```

## 用示例手推一遍

以这棵树为例：

```text
    3
   / \
  9  20
    /  \
   15   7
```

我们从根节点 `3` 开始看。

### 1. 看节点 `3`

要算 `3` 的最大深度，
先去算：

- `9` 的最大深度
- `20` 的最大深度

### 2. 看节点 `9`

节点 `9` 没有左右孩子。

所以：

- `maxDepth(9.left) = 0`
- `maxDepth(9.right) = 0`

因此：

```text
maxDepth(9) = max(0, 0) + 1 = 1
```

### 3. 看节点 `20`

节点 `20` 有两个孩子：

- `15`
- `7`

先分别计算它们的深度。

### 4. 看节点 `15`

`15` 是叶子节点，
所以：

```text
maxDepth(15) = 1
```

### 5. 看节点 `7`

`7` 也是叶子节点，
所以：

```text
maxDepth(7) = 1
```

### 6. 回到节点 `20`

此时：

- 左子树深度是 `1`
- 右子树深度是 `1`

所以：

```text
maxDepth(20) = max(1, 1) + 1 = 2
```

### 7. 回到根节点 `3`

现在我们已经知道：

- `maxDepth(9) = 1`
- `maxDepth(20) = 2`

所以：

```text
maxDepth(3) = max(1, 2) + 1 = 3
```

最终答案就是：

```text
3
```

## 算法步骤

1. 如果当前节点为空，返回 `0`
2. 递归计算左子树最大深度
3. 递归计算右子树最大深度
4. 返回 `max(左深度, 右深度) + 1`

## Python 参考实现

```python
class Solution:
    def maxDepth(self, root):
        if not root:
            return 0
        return max(self.maxDepth(root.left), self.maxDepth(root.right)) + 1
```

## 为什么 `+ 1`

很多人看到这句会疑惑：

```python
return max(self.maxDepth(root.left), self.maxDepth(root.right)) + 1
```

为什么最后要 `+ 1`？

因为：

- 左右子树的递归结果，只计算了子树自己的深度
- 但当前节点 `root` 这一层还没有算进去

所以必须额外加上当前这一层。

例如：

- 如果某个节点左右子树深度都是 `0`
- 说明它自己是叶子节点

那它的深度应该是：

```text
max(0, 0) + 1 = 1
```

这正好符合我们对叶子节点深度的理解。

## 复杂度分析

### 时间复杂度

`O(n)`

因为：

- 每个节点都会被访问一次

其中 `n` 是二叉树的节点总数。

### 空间复杂度

`O(h)`

因为递归会占用系统调用栈，
栈的深度取决于树的高度 `h`。

- 平衡二叉树时，`h` 约为 `log n`
- 极端退化成链表时，`h` 约为 `n`

## 常见错误

### 1. 把空节点深度写成 `1`

空节点不算层数，
所以应该返回：

```python
0
```

### 2. 忘记加当前节点这一层

如果只写：

```python
max(self.maxDepth(root.left), self.maxDepth(root.right))
```

就漏掉了当前节点本身。

### 3. 把“深度”理解成边数

这道题里求的是：

- 路径上的节点数

不是边数。

所以单个节点的树，
最大深度应该是 `1`，不是 `0`。

## 一句话总结

这道题的核心就是：

**一棵树的最大深度 = 左右子树最大深度的较大值 + 当前这一层。**
