# 003. 无重复字符的最长子串

## 所属专题

- 滑动窗口

## 题目描述

给定一个字符串 `s`，请你找出其中 **不含有重复字符的最长子串** 的长度。

注意：

- 这里说的是 **子串**，不是子序列
- 子串必须是连续的一段字符

## 示例

### 示例 1

```text
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

### 示例 2

```text
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

### 示例 3

```text
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3。
请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。
```

## 题意理解

这道题要求我们在字符串里找到一段：

- 连续
- 没有重复字符
- 尽可能长

并且最后返回的是：

- **长度**

不是：

- 这段子串本身

比如：

```text
s = "abcabcbb"
```

其中：

- `"abc"` 没有重复字符，长度是 `3`
- 再往后扩展就会遇到重复字符

所以答案是 `3`。

这道题最关键的地方有两个：

1. 必须是“子串”，也就是连续的一段
2. 窗口里一旦出现重复字符，就不能再算合法答案

## 最直接的想法：暴力枚举

最容易想到的方法，就是枚举所有子串。

具体做法：

- 枚举子串起点
- 枚举子串终点
- 取出这一段子串
- 检查它有没有重复字符
- 如果没有，就更新最长长度

这个方法当然能做出来，但问题也很明显。

### 问题 1：子串数量很多

一个长度为 `n` 的字符串，子串数量大约是 `O(n^2)`。

### 问题 2：每个子串还要判断是否重复

如果每次都重新检查一遍有没有重复字符，整体复杂度会更高。

所以暴力方法通常会达到 `O(n^3)` 级别，效率不够好。

于是我们要继续想：

**能不能在扫描字符串的过程中，始终维护一个“当前没有重复字符的区间”？**

## 优化思路：滑动窗口 + 哈希集合

这是这道题最经典的做法。

### 什么叫滑动窗口

我们可以把字符串中的一段连续区间，看成一个“窗口”。

比如：

```text
s = "abcabcbb"
```

如果当前窗口是：

```text
"abc"
```

那就表示我们正在观察这段连续子串。

窗口有两个边界：

- 左边界 `left`
- 右边界 `right`

只要窗口内没有重复字符，它就是一个合法候选答案。

### 哈希集合里存什么

我们用一个集合 `char_set` 来记录：

- 当前窗口里出现过哪些字符

比如当前窗口是：

```text
"abc"
```

那么集合可能就是：

```python
{'a', 'b', 'c'}
```

这样我们就能快速判断：

- 某个字符是否已经在当前窗口里出现过

### 右指针负责扩张窗口

我们让 `right` 从左到右遍历整个字符串。

每次准备把 `s[right]` 放进窗口时，分两种情况：

#### 情况 1：`s[right]` 不在集合中

说明它没有重复，可以放心加入窗口。

这时：

- 把 `s[right]` 加入集合
- 更新最长长度

#### 情况 2：`s[right]` 已经在集合中

说明窗口里出现了重复字符。

这时当前窗口不再合法，我们必须缩小窗口。

### 左指针负责收缩窗口

当遇到重复字符时，不能只动一次 `left`，而是要：

- 一直移动 `left`
- 一边移动，一边把移出窗口的字符从集合里删除
- 直到窗口内不再包含重复字符为止

也就是说，这里必须写：

```python
while s[right] in char_set:
```

而不是：

```python
if s[right] in char_set:
```

因为有时需要连续删掉多个字符，重复问题才会真正消失。

### 为什么这个方法是 `O(n)`

虽然看起来有一个 `for` 和一个 `while`，但并不是 `O(n^2)`。

原因是：

- 每个字符最多被右指针加入窗口一次
- 每个字符最多被左指针移出窗口一次

也就是说，每个字符总共处理次数是有限的，所以整体是 `O(n)`。

## 用示例手推一遍

以示例 1 为例：

```text
s = "abcabcbb"
```

初始状态：

- `left = 0`
- `char_set = {}`
- `max_length = 0`

### 第 1 步：`right = 0`

- 当前字符是 `a`
- `a` 不在集合中
- 加入集合后，窗口是 `"a"`
- 当前长度是 `1`

更新：

```text
max_length = 1
```

### 第 2 步：`right = 1`

- 当前字符是 `b`
- `b` 不在集合中
- 加入后窗口是 `"ab"`
- 当前长度是 `2`

更新：

```text
max_length = 2
```

### 第 3 步：`right = 2`

- 当前字符是 `c`
- `c` 不在集合中
- 加入后窗口是 `"abc"`
- 当前长度是 `3`

更新：

```text
max_length = 3
```

### 第 4 步：`right = 3`

- 当前字符是 `a`
- 发现 `a` 已经在集合中，出现重复

于是开始移动 `left`：

- 删除 `s[left] = 'a'`
- `left` 从 `0` 变成 `1`

现在重复消失了，再把当前这个 `a` 加入。

此时窗口变成：

```text
"bca"
```

长度仍然是 `3`，最大值不变。

### 第 5 步：`right = 4`

- 当前字符是 `b`
- 同样出现重复
- 删除左边的 `b`
- 再把当前 `b` 加入

窗口变成：

```text
"cab"
```

长度还是 `3`。

### 第 6 步：`right = 5`

- 当前字符是 `c`
- 处理重复后，窗口变成 `"abc"`
- 长度仍然是 `3`

### 第 7 步：`right = 6`

- 当前字符是 `b`
- 这时窗口里已经有 `b`
- 需要不断移动 `left`

删除过程：

- 先删 `a`
- 发现 `b` 还在
- 再删 `b`

之后再加入当前 `b`。

窗口变成：

```text
"cb"
```

长度是 `2`。

### 第 8 步：`right = 7`

- 当前字符是 `b`
- 再次出现重复
- 收缩窗口后只剩 `"b"`

最终最大值始终是：

```text
3
```

## 为什么这样写

这道题的写法看起来不复杂，但有几个关键点必须真正理解。

### 1. 窗口内必须始终保持“无重复”

滑动窗口不是随便取一段，而是要维护一个不变量：

- 当前窗口中的字符不能重复

只要这个条件成立，窗口长度就可以拿来更新答案。

### 2. 一旦重复，就先收缩，再扩张

当 `s[right]` 和窗口里的某个字符重复时，
不能直接跳过去，也不能硬加进去。

正确做法是：

- 先把左边的字符一个个移走
- 直到窗口恢复合法
- 再把当前字符放进来

### 3. 这里必须用 `while`，不能只用 `if`

因为一个重复字符，可能需要移除多个左侧字符才能解决。

例如：

```text
s = "abba"
```

当右指针走到最后一个 `a` 时，
如果你只收缩一次，很可能窗口里仍然有重复字符。

所以必须持续收缩到合法为止。

### 4. 这道题求的是“最长合法窗口”

所以整个过程的目标不是记住某个具体子串，
而是不断维护：

- 当前合法窗口长度
- 历史最大长度

## 算法步骤

1. 创建一个空集合 `char_set`，用于记录窗口中的字符
2. 初始化左指针 `left = 0`
3. 初始化答案 `max_length = 0`
4. 用右指针 `right` 从左到右遍历字符串
5. 如果 `s[right]` 已经在集合中，就不断移动 `left`，并把移出的字符从集合中删除
6. 当窗口恢复无重复后，把 `s[right]` 加入集合
7. 用当前窗口长度 `right - left + 1` 更新答案
8. 遍历结束后，返回 `max_length`

## 复杂度分析

### 时间复杂度

`O(n)`

原因：

- 右指针从左到右遍历一遍字符串
- 左指针也只会单调向右移动
- 每个字符最多进入集合一次、移出集合一次

### 空间复杂度

`O(min(n, m))`

其中：

- `n` 是字符串长度
- `m` 是字符集大小

原因：

- 集合中最多保存当前窗口内的不重复字符
- 最多不超过字符串长度，也不会超过字符集大小

## Python 参考实现（详细注释）

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 用集合记录当前窗口中已经出现过的字符。
        char_set = set()

        # left 表示当前窗口的左边界。
        left = 0

        # max_length 用来记录历史上最长的合法窗口长度。
        max_length = 0

        # right 从左到右扩张窗口。
        for right in range(len(s)):
            # 如果当前字符已经出现在窗口中，
            # 说明窗口内有重复字符，当前窗口不合法。
            # 这时要不断收缩左边界，直到重复消失。
            while s[right] in char_set:
                # 把左边即将移出窗口的字符，从集合中删除。
                char_set.remove(s[left])

                # 左边界右移，表示窗口缩小。
                left += 1

            # 走到这里，说明 s[right] 已经可以安全加入窗口。
            char_set.add(s[right])

            # 当前窗口长度是 right - left + 1。
            # 用它来更新历史最大值。
            max_length = max(max_length, right - left + 1)

        return max_length
```

## 这段代码最值得记住的地方

你在自己手写的时候，重点记住下面这条主线：

```python
char_set = set()
left = 0
max_length = 0

for right in range(len(s)):
    while s[right] in char_set:
        char_set.remove(s[left])
        left += 1

    char_set.add(s[right])
    max_length = max(max_length, right - left + 1)
```

本质上就是一句话：

**右指针负责把字符加入窗口，左指针负责在出现重复时把窗口缩回合法状态。**

## 常见错误

### 1. 把“子串”理解成“子序列”

题目要的是：

- 连续的一段字符

不是：

- 可以跳着选的字符

所以像 `"pwke"` 不是 `"pwwkew"` 的子串。

### 2. 遇到重复时只用 `if`，不用 `while`

这会导致窗口中可能仍然残留重复字符。

推荐固定写法：

```python
while s[right] in char_set:
```

### 3. 忘记在移动 `left` 时同步删除集合中的字符

如果只写：

```python
left += 1
```

却没有：

```python
char_set.remove(s[left])
```

那么集合中的内容就和真实窗口不一致了。

### 4. 窗口还没恢复合法就更新答案

一定要先保证：

- 当前窗口没有重复字符

再去更新最大长度。

## 一句话总结

这道题的关键不是“枚举所有子串”，而是：

**用滑动窗口始终维护一段“无重复字符”的连续区间，一旦重复就收缩左边界，直到窗口重新合法。**
