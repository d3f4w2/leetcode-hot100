# 071. 简化路径

## 所属专题

- 栈

## 题目描述

给你一个字符串 `path`，表示指向某一文件或目录的 Unix 风格**绝对路径**（一定以 `'/'` 开头）。

请你将它转化为更加简洁的**规范路径**。

在 Unix 风格文件系统中：

- `.` 表示当前目录
- `..` 表示返回上一级目录
- 多个连续斜杠 `//` 会被视为一个斜杠 `/`
- 只有 `.` 和 `..` 有特殊含义，像 `...` 这样的内容要当作普通目录名处理

返回简化后的规范路径。

规范路径需要满足：

- 以单个 `/` 开头
- 目录之间只用一个 `/` 分隔
- 不以 `/` 结尾（根目录除外）
- 不能继续退回到根目录之上

## 示例

### 示例 1

```text
输入：path = "/home/"
输出："/home"
解释：末尾的斜杠需要去掉。
```

### 示例 2

```text
输入：path = "/home//foo/"
输出："/home/foo"
解释：多个连续斜杠需要合并成一个。
```

### 示例 3

```text
输入：path = "/home/user/Documents/../Pictures"
输出："/home/user/Pictures"
解释：`..` 表示回到上一级目录，所以 `Documents` 会被移除。
```

### 示例 4

```text
输入：path = "/../"
输出："/"
解释：已经在根目录时，再往上退也还是根目录。
```

### 示例 5

```text
输入：path = "/.../a/../b/c/../d/./"
输出："/.../b/d"
解释：`...` 是普通目录名，不是特殊符号。
```

## 题意理解

这道题表面上是在“处理字符串”，
但本质上是在**模拟进入目录和返回上一级目录的过程**。

题目里的几种情况要分清：

- 空字符串：来自连续斜杠，比如 `//`，要忽略
- `.`：表示当前目录，路径不变，忽略
- `..`：表示回到上一级目录
- 其他字符串：都表示一个真实的目录名，需要保留下来

例如：

```text
"/a/./b/../../c/"
```

它的含义是：

1. 进入 `a`
2. `.` 不动
3. 进入 `b`
4. `..` 回退，离开 `b`
5. `..` 再回退，离开 `a`
6. 进入 `c`

最后结果就是：

```text
"/c"
```

这里最关键的一点是：

**每次遇到 `..`，要删除的总是“最近一次进入、但还没有被删除的目录”。**

这正是栈最适合处理的场景。

## 最直接的想法：直接拼接结果字符串

一个很自然的思路是：

- 先把路径按 `'/'` 切开
- 一段一段处理
- 遇到普通目录就拼到结果字符串后面
- 遇到 `..` 就想办法把结果字符串最后一个目录删掉

这个思路并不是错的，
但是写起来会比较别扭，因为：

- 你需要频繁处理字符串拼接
- 你需要找到“最后一个 `/` 在哪里”
- 删除最后一个目录时不如删除栈顶元素那么直接

所以虽然本质上还是“模拟路径变化”，
但直接用字符串维护会让代码不够清晰。

我们可以继续想：

**既然 `..` 删除的永远是最近加入的那个目录，那是不是可以把这些目录按加入顺序存起来？**

## 优化思路：用栈维护当前有效路径

### 为什么想到栈

路径中的目录变化满足：

- 进入新目录：把目录记下来
- 回到上一级：把最近进入的目录删掉

这就是典型的：

- 后进先出

而“后进先出”正是栈的核心特征。

### 栈里放什么

栈里只保存**当前路径中仍然有效的目录名**。

比如处理到：

```text
"/home/user/docs"
```

那么栈里可以理解为：

```text
["home", "user", "docs"]
```

它表示当前规范路径是：

```text
"/home/user/docs"
```

### 遍历每一段时怎么处理

把 `path` 按 `'/'` 分割后，依次处理每个部分 `part`：

1. 如果 `part == ""`
   说明是连续斜杠产生的空段，忽略
2. 如果 `part == "."`
   表示当前目录，不影响路径，忽略
3. 如果 `part == ".."`
   如果栈不为空，就弹出栈顶，表示回到上一级
4. 其他情况
   都是正常目录名，直接入栈

最后再把栈里的目录用 `'/'` 连接起来，
前面补一个根目录的 `'/'`，
就得到了规范路径。

### 为什么 `...` 不能特殊处理

题目特别提醒：

- 只有 `.` 和 `..` 有特殊含义

所以：

- `...`
- `....`
- `.config`

这些都只是普通目录名，
必须像正常字符串一样入栈。

这也是这题很容易踩坑的地方。

## 用示例手推一遍

我们用这个稍微复杂一点的例子：

```text
path = "/.../a/../b/c/../d/./"
```

先按 `'/'` 分割：

```text
["", "...", "a", "..", "b", "c", "..", "d", ".", ""]
```

下面一步一步看栈的变化。

### 第 1 步：读到 `""`

- 空字符串，忽略
- 栈不变

```text
[]
```

### 第 2 步：读到 `"..."`

- 这不是 `.`，也不是 `..`
- 它是普通目录名，入栈

```text
["..."]
```

### 第 3 步：读到 `"a"`

- 普通目录，入栈

```text
["...", "a"]
```

### 第 4 步：读到 `".."`

- 回到上一级
- 弹出最近进入的目录 `a`

```text
["..."]
```

### 第 5 步：读到 `"b"`

- 普通目录，入栈

```text
["...", "b"]
```

### 第 6 步：读到 `"c"`

- 普通目录，入栈

```text
["...", "b", "c"]
```

### 第 7 步：读到 `".."`

- 回到上一级
- 弹出 `c`

```text
["...", "b"]
```

### 第 8 步：读到 `"d"`

- 普通目录，入栈

```text
["...", "b", "d"]
```

### 第 9 步：读到 `"."`

- 当前目录，忽略

```text
["...", "b", "d"]
```

### 第 10 步：读到 `""`

- 空字符串，忽略

```text
["...", "b", "d"]
```

最后把栈拼起来：

```text
"/.../b/d"
```

这就是最终答案。

## 为什么这样写

### 1. 为什么先 `split('/')`

因为路径天然就是按 `'/'` 分段的。

一旦切开以后，
每个部分只需要判断它属于哪一种：

- 空字符串
- `.`
- `..`
- 普通目录

逻辑会非常清楚。

### 2. 为什么遇到空字符串要跳过

因为像：

```text
"/home//foo/"
```

分割后会出现空字符串：

```text
["", "home", "", "foo", ""]
```

这些空字符串并不代表真实目录，
只是多余斜杠留下的结果，
所以必须忽略。

### 3. 为什么根目录下的 `..` 不能继续弹

题目给的是**绝对路径**，
也就是说起点一定是根目录 `/`。

如果当前已经没有目录了，
再遇到 `..`，
也不能跑到根目录上面去。

所以正确处理是：

- 栈非空才弹出
- 栈为空就忽略

### 4. 为什么最后要写成 `'/' + '/'.join(stack)`

因为规范路径要求：

- 一定以 `/` 开头
- 目录之间只保留一个 `/`
- 如果栈为空，要返回根目录 `/`

而：

```python
'/' + '/'.join(stack)
```

正好能同时满足这些要求。

例如：

- `stack = ["home", "foo"]` 时，结果是 `"/home/foo"`
- `stack = []` 时，结果是 `"/"`

## 算法步骤

1. 创建一个空栈 `stack`
2. 用 `path.split('/')` 把路径切成若干段
3. 依次遍历每一段 `part`
4. 如果 `part` 是空字符串或 `.`，跳过
5. 如果 `part` 是 `..`，并且栈不为空，就弹出栈顶
6. 如果 `part` 是普通目录名，就把它压入栈中
7. 遍历结束后，用 `'/'` 把栈中目录连接起来
8. 在最前面补上 `/`，返回结果

## 复杂度分析

### 时间复杂度

`O(n)`

其中 `n` 是字符串 `path` 的长度。

原因：

- `split('/')` 需要遍历一遍字符串
- 后续遍历每一段也是线性的
- 每个目录名最多入栈一次、出栈一次

### 空间复杂度

`O(n)`

原因：

- 最坏情况下，路径中的所有目录都会进入栈中

## Python 参考实现（详细注释）

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        # 栈中保存“当前仍然有效”的目录名。
        # 例如 stack = ["home", "user"] 表示当前路径是 /home/user
        stack = []

        # 用 / 切开路径，逐段处理。
        for part in path.split('/'):
            # 空字符串：来自连续斜杠 // 或开头/结尾的 /
            # 当前目录 .：对路径没有影响
            if part == "" or part == ".":
                continue

            # .. 表示回到上一级目录。
            # 只有当前确实有上一级目录时，才需要弹栈。
            if part == "..":
                if stack:
                    stack.pop()
            else:
                # 其余所有情况都当作普通目录名。
                # 注意：... 也属于普通目录名，不能特殊处理。
                stack.append(part)

        # 把所有有效目录重新用 / 连接起来。
        # 如果 stack 为空，'/'.join(stack) 是空字符串，
        # 最终结果自然就是根目录 "/"
        return "/" + "/".join(stack)
```

## 这段代码最值得记住的地方

你自己默写时，最值得记住的是下面这条主线：

```python
stack = []

for part in path.split('/'):
    if part == "" or part == ".":
        continue
    if part == "..":
        if stack:
            stack.pop()
    else:
        stack.append(part)

return "/" + "/".join(stack)
```

本质上就是一句话：

**把路径拆成一段一段，普通目录入栈，`..` 就弹栈，最后再把栈还原成路径。**

## 常见错误

### 1. 把 `...` 当成 `..`

只有：

- `.`
- `..`

有特殊含义。

像 `...` 这样的字符串必须当作普通目录名保留。

### 2. 忘记跳过空字符串

如果不跳过空字符串，
像 `"/home//foo/"` 这种路径就会把空目录错误地加进去。

### 3. 对空栈直接 `pop()`

例如：

```text
"/../"
```

这时已经在根目录，
再遇到 `..` 不能直接弹栈，
否则会报错。

### 4. 返回结果时少了根目录前缀 `/`

如果最后只写：

```python
'/'.join(stack)
```

那么得到的会是：

```text
"home/foo"
```

但题目要求的是绝对路径，
必须返回：

```text
"/home/foo"
```

### 5. 最后把空栈返回成空字符串

当路径最终回到根目录时，
正确答案应该是：

```text
"/"
```

而不是空字符串 `""`。

## 适合自己默写的精简版本

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []

        for part in path.split('/'):
            if part == "" or part == ".":
                continue
            if part == "..":
                if stack:
                    stack.pop()
            else:
                stack.append(part)

        return "/" + "/".join(stack)
```

## 一句话总结

这道题的关键是：

**把路径看成一系列目录操作，用栈维护“当前有效路径”，这样就能自然地处理 `.`、`..`、连续斜杠以及回退目录。**
