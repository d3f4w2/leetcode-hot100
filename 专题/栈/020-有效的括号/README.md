# 020. 有效的括号

## 所属专题

- 栈

## 题目描述

给定一个只包括：

- `'('`
- `')'`
- `'{'`
- `'}'`
- `'['`
- `']'`

的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合
2. 左括号必须以正确的顺序闭合
3. 每个右括号都有一个对应的相同类型的左括号

## 示例

### 示例 1

```text
输入：s = "()[]{}"
输出：true
```

### 示例 2

```text
输入：s = "(]"
输出：false
```

### 示例 3

```text
输入：s = "([)]"
输出：false
```

### 示例 4

```text
输入：s = "{[]}"
输出：true
```

## 题意理解

这道题表面上是在判断括号，
但本质上是在检查两件事：

- 括号类型是否匹配
- 括号闭合顺序是否正确

例如：

```text
"()[]{}"
```

这是有效的，
因为每个左括号都被正确类型的右括号关闭了。

但：

```text
"(]"
```

就是无效的，
因为 `(` 不能和 `]` 配对。

再比如：

```text
"([)]"
```

也是无效的。

虽然它里面有：

- `(` 和 `)`
- `[` 和 `]`

但闭合顺序不对。

也就是说，这道题不仅要看“有没有配对”，
还要看：

- 是不是最后打开的括号，最先被关闭

这正是栈最擅长处理的结构。

## 最直接的想法：不停找相邻配对再删除

最容易想到的一种方法是：

- 如果字符串中出现 `()`、`[]`、`{}`
- 就把它们删掉
- 一直重复这个过程
- 最后如果字符串能删成空串，就说明有效

例如：

```text
"{[]}"
```

可以这样删：

- 先删 `[]`，得到 `{}`
- 再删 `{}`，得到空串

所以它有效。

这个想法是对的，
但实现起来效率不高。

因为每次删除都可能产生新的字符串，
反复扫描会比较慢。

所以我们要找一个更适合“后进先出”结构的做法。

## 优化思路：栈

这是这道题最经典的解法。

### 为什么想到栈

括号匹配的过程，本质上是：

- 最近打开的括号
- 必须最先被正确关闭

这正好符合：

- **后进先出**

而“后进先出”就是栈的典型特征。

### 栈里存什么

我们用一个栈 `stack` 来存：

- 还没有被匹配掉的左括号

例如遍历到：

```text
"(["
```

那么栈里就是：

```text
['(', '[']
```

意思是：

- `(` 还没匹配
- `[` 也还没匹配

并且 `[` 是最后进去的，
所以它应该先匹配。

### 遇到左括号时怎么做

如果当前字符是：

- `(`
- `[`
- `{`

那就直接入栈。

因为它暂时还没有对应的右括号。

### 遇到右括号时怎么做

如果当前字符是右括号，
那就要检查：

- 栈顶是不是和它匹配的左括号

比如当前字符是：

```text
')'
```

那栈顶必须是：

```text
'('
```

否则就是无效字符串。

### 为什么要用映射表 `mapping`

我们通常会写：

```python
mapping = {')': '(', ']': '[', '}': '{'}
```

它表示：

- 右括号对应哪个左括号

这样当我们遇到右括号时，
就能立刻知道：

- 我期待栈顶是什么

例如当前字符是 `]`，
那就去看：

```python
mapping[']']
```

结果是 `'['`。

如果栈顶不是 `'['`，那就直接返回 `False`。

## 用示例手推一遍

以示例：

```text
s = "()[]{}"
```

为例。

### 第 1 步：读到 `(`

- 是左括号
- 入栈

栈变成：

```text
['(']
```

### 第 2 步：读到 `)`

- 是右括号
- 它要求匹配的左括号是 `(`
- 栈顶刚好也是 `(`

所以把栈顶弹出。

栈变成：

```text
[]
```

### 第 3 步：读到 `[`

- 左括号，入栈

栈变成：

```text
['[']
```

### 第 4 步：读到 `]`

- 右括号
- 需要匹配 `[`
- 栈顶正好是 `[`

弹出后：

```text
[]
```

### 第 5 步：读到 `{`

- 左括号，入栈

栈变成：

```text
['{']
```

### 第 6 步：读到 `}`

- 右括号
- 需要匹配 `{`
- 栈顶正好是 `{`

弹出后：

```text
[]
```

最终遍历结束，栈也为空。

说明：

- 所有左括号都被正确匹配掉了

所以答案是：

```text
true
```

## 再看一个错误例子

```text
s = "([)]"
```

过程：

- 读 `(`，栈：`['(']`
- 读 `[`，栈：`['(', '[']`
- 读 `)`，它需要匹配 `(`

但当前栈顶是：

```text
'['
```

这就说明顺序错了，
所以应该立刻返回 `False`。

## 为什么这样写

这道题最核心的点，是理解为什么“最后打开的括号必须最先关闭”。

### 1. 括号天然是嵌套结构

例如：

```text
{ [ ( ) ] }
```

你会发现：

- 最里面的先关
- 最外面的后关

这和栈的出入顺序完全一致。

### 2. 栈顶永远代表“当前最需要被匹配的左括号”

只要当前右括号不能匹配栈顶，
就说明结构已经错了。

这时不用继续看后面，
直接返回 `False` 即可。

### 3. 最后栈必须为空

如果遍历结束后栈还不空，
说明还有左括号没被关闭。

例如：

```text
"(("
```

虽然过程中没有出现错误右括号，
但它仍然是无效的。

所以最终必须检查：

- 栈是否为空

## 算法步骤

1. 创建一个空栈 `stack`
2. 创建映射表 `mapping`，表示每种右括号对应的左括号
3. 从左到右遍历字符串中的每个字符
4. 如果当前字符是右括号：
   - 如果栈为空，直接返回 `False`
   - 或者栈顶弹出的左括号和它不匹配，也返回 `False`
5. 如果当前字符是左括号，就把它压入栈中
6. 遍历结束后，如果栈为空，返回 `True`；否则返回 `False`

## 复杂度分析

### 时间复杂度

`O(n)`

其中：

- `n` 是字符串长度

原因：

- 每个字符最多入栈一次、出栈一次

### 空间复杂度

`O(n)`

原因：

- 最坏情况下，字符串全是左括号
- 那么栈中会存下全部字符

## Python 参考实现（详细注释）

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 栈用来保存还没有被匹配掉的左括号。
        stack = []

        # 记录每种右括号应该对应哪种左括号。
        mapping = {
            ')': '(',
            '}': '{',
            ']': '['
        }

        for char in s:
            # 如果当前字符是右括号，
            # 就检查它是否能和栈顶左括号匹配。
            if char in mapping:
                # 栈为空，说明没有左括号可匹配。
                # 或者弹出的左括号类型不对，也是不合法。
                if not stack or stack.pop() != mapping[char]:
                    return False
            else:
                # 当前字符是左括号，先入栈等待后续匹配。
                stack.append(char)

        # 所有字符处理完后，栈必须为空才说明全部匹配成功。
        return not stack
```

## 这段代码最值得记住的地方

你在自己手写的时候，重点记住下面这条主线：

```python
stack = []
mapping = {')': '(', '}': '{', ']': '['}

for char in s:
    if char in mapping:
        if not stack or stack.pop() != mapping[char]:
            return False
    else:
        stack.append(char)

return not stack
```

本质上就是一句话：

**左括号入栈，右括号就去检查并弹出对应的栈顶左括号，最后栈必须为空。**

## 常见错误

### 1. 只检查括号数量，不检查顺序

例如：

```text
"([)]"
```

左右括号数量都对，
但顺序错了，仍然应该返回 `False`。

### 2. 遇到右括号时没有先判断栈是否为空

例如：

```text
")"
```

这时根本没有左括号可以匹配，
应该立刻返回 `False`。

### 3. 忘记最后检查栈是否为空

例如：

```text
"(("
```

遍历过程中没有触发错误，
但最后还有左括号没匹配，
所以仍然是无效字符串。

### 4. 把左括号和右括号的映射方向写乱

推荐固定写法：

```python
mapping = {')': '(', '}': '{', ']': '['}
```

这样遇到右括号时，直接查它期望匹配谁。


## 一句话总结

这道题的关键不是“数括号个数”，而是：

**利用栈维护还未匹配的左括号，让括号匹配过程严格遵守后进先出的顺序。**
