# 020. 有效的括号

## 所属专题

- 栈

## 题目描述

给定一个只包括：

- `'('`
- `')'`
- `'{'`
- `'}'`
- `'['`
- `']'`

的字符串 `s`，判断字符串是否有效。

有效字符串需要满足：

1. 左括号必须用相同类型的右括号闭合
2. 左括号必须以正确的顺序闭合
3. 每个右括号都必须有一个对应的左括号

## 示例

### 示例 1

```text
输入：s = "()[]{}"
输出：true
```

### 示例 2

```text
输入：s = "(]"
输出：false
```

### 示例 3

```text
输入：s = "([)]"
输出：false
```

### 示例 4

```text
输入：s = "{[]}"
输出：true
```

## 题意理解

这道题看起来是在判断“括号能不能两两配对”，
但真正要检查的是两件事：

- 类型是否匹配
- 顺序是否正确

比如：

```text
"()[]{}"
```

这是有效的，因为每个左括号都被同类型的右括号正确关闭了。

而：

```text
"(]"
```

是无效的，因为 `(` 不能和 `]` 配对。

再看：

```text
"([)]"
```

它也无效。

虽然里面确实有：

- `(` 和 `)`
- `[` 和 `]`

但是闭合顺序错了。

也就是说，这道题不是只看“有没有配对成功”，
而是要看：

**最后打开的括号，必须最先关闭。**

这正是栈最擅长处理的场景。

## 最直接的想法：不断删除成对括号

有些人一开始会想到：

- 如果字符串里出现 `()`
- 或者出现 `[]`
- 或者出现 `{}`
- 就把它删掉
- 反复执行，直到删不动为止

例如：

```text
"{[]}"
```

可以这样删：

- 先删掉 `[]`，得到 `{}`
- 再删掉 `{}`，得到空串

这样思路上是能做出来的，
但是效率并不好，因为你会不断创建新字符串、反复扫描。

所以我们需要一个更适合“后进先出”结构的做法。

## 正确思路：用栈维护还没闭合的左括号

### 为什么想到栈

括号匹配的本质是：

- 最近打开的左括号
- 必须最先被关闭

这就是典型的：

- 后进先出

而“后进先出”正是栈的核心特征。

### 栈里放什么

栈里保存：

- 还没有被匹配掉的左括号

例如遍历到：

```text
"(["
```

那么栈中就是：

```text
['(', '[']
```

表示：

- `(` 还没匹配
- `[` 也还没匹配

而且 `[` 是最后进入栈的，
所以它应该最先被匹配。

### 遇到左括号怎么处理

如果当前字符是：

- `(`
- `[`
- `{`

那就直接入栈。

因为它暂时还没有对应的右括号来关闭。

### 遇到右括号怎么处理

如果当前字符是右括号，
就要检查：

- 栈是否为空
- 栈顶是不是和它匹配的左括号

如果不是，说明字符串无效，直接返回 `False`。

### 为什么要用映射表

通常我们会写：

```python
mapping = {
    ')': '(',
    ']': '[',
    '}': '{'
}
```

它的含义是：

- 每种右括号，应该匹配哪种左括号

这样当我们遇到右括号时，
就能立刻知道它期望匹配谁。

例如当前字符是 `]`，
那它要求栈顶必须是 `[`。

## 用示例手推一遍

以：

```text
s = "()[]{}"
```

为例。

### 第 1 步：读到 `(`

- 是左括号，入栈

栈变成：

```text
['(']
```

### 第 2 步：读到 `)`

- 是右括号
- 它要求匹配 `(`
- 栈顶刚好也是 `(`

所以把栈顶弹出。

栈变成：

```text
[]
```

### 第 3 步：读到 `[`

- 左括号，入栈

栈变成：

```text
['[']
```

### 第 4 步：读到 `]`

- 右括号
- 它要求匹配 `[`
- 栈顶正好是 `[`

弹出后：

```text
[]
```

### 第 5 步：读到 `{`

- 左括号，入栈

栈变成：

```text
['{']
```

### 第 6 步：读到 `}`

- 右括号
- 它要求匹配 `{`
- 栈顶正好是 `{`

弹出后：

```text
[]
```

遍历结束后，栈为空，
说明所有左括号都成功匹配。

所以答案是：

```text
true
```

## 再看一个错误示例

```text
s = "([)]"
```

遍历过程：

- 读到 `(`，入栈，栈为 `['(']`
- 读到 `[`，入栈，栈为 `['(', '[']`
- 读到 `)`，它需要匹配 `(`

但这时栈顶却是：

```text
'['
```

这说明闭合顺序错了，
应该立刻返回 `False`。

## 算法步骤

1. 创建一个空栈 `stack`
2. 创建映射表 `mapping = {')': '(', ']': '[', '}': '{'}`
3. 从左到右遍历字符串中的每个字符
4. 如果当前字符是右括号：
5. 先判断栈是否为空，若为空直接返回 `False`
6. 再判断栈顶弹出的左括号是否和它匹配，若不匹配返回 `False`
7. 如果当前字符是左括号，就把它压入栈中
8. 遍历结束后，如果栈为空返回 `True`，否则返回 `False`

## 为什么最后要检查栈是否为空

因为有一种情况是：

- 遍历过程中没有出现“错误的右括号”
- 但仍然有左括号没有被关闭

例如：

```text
"(("
```

它在遍历过程中不会触发“立即失败”，
但最终栈里还剩下两个左括号。

这说明字符串仍然无效。

所以最后必须检查：

- 栈是否为空

只有栈空了，才说明所有括号都正确匹配完毕。

## 复杂度分析

### 时间复杂度

`O(n)`

其中：

- `n` 是字符串长度

原因是：

- 每个字符最多入栈一次
- 每个字符最多出栈一次

### 空间复杂度

`O(n)`

原因是：

- 最坏情况下，字符串全是左括号
- 那么这些字符都会暂时保存在栈中

## Python 参考实现

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        mapping = {
            ')': '(',
            ']': '[',
            '}': '{'
        }

        for char in s:
            if char in mapping:
                if not stack or stack.pop() != mapping[char]:
                    return False
            else:
                stack.append(char)

        return not stack
```

## 这段代码最值得记住的主线

你真正要记住的不是整段代码，
而是下面这个逻辑骨架：

```python
stack = []
mapping = {')': '(', ']': '[', '}': '{'}

for char in s:
    if char in mapping:
        if not stack or stack.pop() != mapping[char]:
            return False
    else:
        stack.append(char)

return not stack
```

可以概括成一句话：

**左括号入栈，右括号就检查并弹出对应的栈顶左括号，最后栈必须为空。**

## 常见错误

### 1. 只检查括号数量，不检查顺序

比如：

```text
"([)]"
```

虽然左右括号数量都对，
但闭合顺序错了，答案仍然应该是 `False`。

### 2. 遇到右括号时没有先判断栈是否为空

例如：

```text
")"
```

这时根本没有左括号可以匹配，
应该立刻返回 `False`。

### 3. 忘记最后检查栈是否为空

例如：

```text
"(("
```

遍历过程中没有出错，
但最后仍有左括号没被匹配，
所以还是无效字符串。

### 4. 把映射方向写反后又在判断时绕晕自己

推荐固定写法：

```python
mapping = {')': '(', ']': '[', '}': '{'}
```

这样遇到右括号时，
直接看它“应该匹配谁”即可。

## 一句话总结

这道题的关键是：

**用栈保存还没匹配的左括号，让括号匹配过程严格遵守“后进先出”，这样就能同时检查括号类型和闭合顺序是否正确。**
