# 048. 旋转图像

## 所属专题

- 矩阵

## 题目描述

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。
请你将图像 **顺时针旋转 90 度**。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入矩阵，
不能再额外使用另一个同样大小的矩阵来存放旋转后的结果。

## 示例

### 示例 1

```text
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

### 示例 2

```text
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

## 题意理解

这道题不是让我们“新建一个矩阵，把答案填进去”。

而是要求：

- 直接在原矩阵上修改
- 最终让整个矩阵看起来像被顺时针旋转了 90 度

例如：

```text
1 2 3
4 5 6
7 8 9
```

顺时针旋转 90 度后变成：

```text
7 4 1
8 5 2
9 6 3
```

你可以观察一下位置变化：

- 左下角的 `7` 跑到了左上角
- 中间的 `5` 还在中间
- 左上角的 `1` 跑到了右上角

所以这题的关键不只是“算出结果”，
更重要的是：

**如何在不额外开辟新矩阵的情况下，把矩阵原地变成旋转后的样子。**

## 最直接的想法：新建一个矩阵

如果不考虑“原地修改”的限制，
那最直接的思路其实很简单：

- 新建一个同样大小的矩阵 `new_matrix`
- 遍历原矩阵中每个位置 `(i, j)`
- 把它放到旋转后的新位置上

顺时针旋转 90 度时，位置变换规律是：

```text
(i, j) -> (j, n - 1 - i)
```

例如在 `3 × 3` 矩阵中：

- `1` 在 `(0, 0)`，旋转后去 `(0, 2)`
- `2` 在 `(0, 1)`，旋转后去 `(1, 2)`
- `7` 在 `(2, 0)`，旋转后去 `(0, 0)`

这种写法思路很直观，
但是它需要额外的 `O(n²)` 空间，
不符合题目“必须原地旋转”的要求。

所以我们要继续想：

**能不能把这个变化拆成几步原地操作？**

## 优化思路：转置 + 每行翻转

这是这道题最常见、也最好理解的原地解法。

### 第一步：先转置

所谓转置，就是：

- 行列互换
- 把 `matrix[i][j]` 和 `matrix[j][i]` 交换

例如原矩阵：

```text
1 2 3
4 5 6
7 8 9
```

转置后得到：

```text
1 4 7
2 5 8
3 6 9
```

你会发现：

- 原来的第 1 行变成了第 1 列
- 原来的第 2 行变成了第 2 列

### 第二步：再把每一行左右翻转

对转置后的矩阵：

```text
1 4 7
2 5 8
3 6 9
```

每一行做一次反转：

```text
7 4 1
8 5 2
9 6 3
```

这就正好是顺时针旋转 90 度后的结果。

所以顺时针旋转 90 度可以拆成：

1. 沿主对角线转置
2. 每一行再左右翻转

而且这两步都可以在原矩阵上直接完成。

## 为什么这样做是对的

我们从下标变化来理解。

原矩阵中某个元素在位置：

```text
(i, j)
```

### 转置之后

它会到：

```text
(j, i)
```

### 再把这一行翻转

在一行长度为 `n` 的情况下，
第 `i` 列翻转后会去：

```text
n - 1 - i
```

所以 `(j, i)` 最终会去：

```text
(j, n - 1 - i)
```

这正好就是顺时针旋转 90 度的位置变化规律：

```text
(i, j) -> (j, n - 1 - i)
```

所以“转置 + 每行翻转”是完全正确的。

## 用示例手推一遍

以：

```text
matrix = [[1,2,3],[4,5,6],[7,8,9]]
```

为例。

### 第 1 步：转置

只交换主对角线右上方的元素和对应的左下方元素。

需要交换：

- `(0,1)` 和 `(1,0)`，也就是 `2` 和 `4`
- `(0,2)` 和 `(2,0)`，也就是 `3` 和 `7`
- `(1,2)` 和 `(2,1)`，也就是 `6` 和 `8`

交换后矩阵变成：

```text
1 4 7
2 5 8
3 6 9
```

### 第 2 步：翻转每一行

第一行：

```text
1 4 7 -> 7 4 1
```

第二行：

```text
2 5 8 -> 8 5 2
```

第三行：

```text
3 6 9 -> 9 6 3
```

最终得到：

```text
7 4 1
8 5 2
9 6 3
```

这正是题目要求的答案。

## 为什么转置时 `j` 从 `i` 开始

代码里这一段是：

```python
for i in range(n):
    for j in range(i, n):
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
```

很多人第一次看这里会疑惑：

为什么 `j` 不是从 `0` 开始？

原因是：

- 对角线上的元素 `(i, i)` 和自己交换，不影响结果
- 如果 `j` 从 `0` 开始，像 `(0,1)` 和 `(1,0)` 这对位置会被交换两次

例如：

- 当 `i = 0, j = 1` 时，会交换一次
- 当 `i = 1, j = 0` 时，又会交换回来

这样就白做了。

所以我们只需要处理主对角线及其右上方区域，
保证每一对位置只交换一次。

## 为什么每行翻转可以直接 `reverse()`

转置后，我们需要把每一行左右反转。

Python 里：

```python
matrix[i].reverse()
```

表示原地反转这一行。

这正好符合题目要求的“原地修改”，
不会额外创建新的矩阵。

## 另一种思路：四个角一组交换

除了“转置 + 翻转”之外，
这道题还有另一种经典写法：

- 每次处理四个对应位置
- 一次把四个数轮换

例如一个元素旋转后会依次影响四个位置：

```text
上 -> 右 -> 下 -> 左
```

这种方法同样可以做到 `O(1)` 额外空间。

不过从理解和记忆角度来说，
“转置 + 每行翻转”通常更自然、也更不容易写错，
所以更适合作为主解法。

## 算法步骤

1. 设矩阵大小为 `n`
2. 先对矩阵做转置
3. 转置时，只遍历主对角线及其右上方区域
4. 对每一对 `(i, j)` 与 `(j, i)` 进行交换
5. 转置完成后，遍历每一行
6. 将每一行原地反转
7. 最终矩阵就是顺时针旋转 90 度后的结果

## 复杂度分析

### 时间复杂度

`O(n²)`

原因是：

- 转置需要遍历矩阵的一半数量级元素，仍然是 `O(n²)`
- 每一行翻转总共也需要处理 `n²` 个元素量级

所以总时间复杂度为：

`O(n²)`

### 空间复杂度

`O(1)`

因为整个过程中只是在原矩阵上交换元素，
没有创建额外的同规模矩阵。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)

        # 第一步：转置矩阵。
        # 只需要遍历主对角线及其右上方区域，
        # 把 matrix[i][j] 和 matrix[j][i] 交换即可。
        for i in range(n):
            for j in range(i, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 第二步：把每一行原地翻转。
        # 转置 + 每行翻转，等价于顺时针旋转 90 度。
        for i in range(n):
            matrix[i].reverse()
```

## 常见错误

### 1. 新建了一个新矩阵

如果你写成：

```python
new_matrix = [[0] * n for _ in range(n)]
```

虽然逻辑上也能做出来，
但不符合题目“必须原地修改”的要求。

### 2. 转置时双重循环都从 `0` 开始

错误写法类似：

```python
for i in range(n):
    for j in range(n):
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
```

这样很多元素会交换两次，
最后又被换回去，结果不对。

正确做法是：

```python
for j in range(i, n):
```

### 3. 把“顺时针”写成了“逆时针”

要特别注意：

- 顺时针 90 度：转置后翻转每一行
- 逆时针 90 度：转置后翻转每一列，或者先上下翻转再转置

这两种不要混淆。

### 4. 忘记这是原地修改题

这题的函数通常不需要 `return` 新矩阵，
而是直接修改传入的 `matrix`。

## 适合自己默写的精简版本

```python
from typing import List


class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)

        for i in range(n):
            for j in range(i, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        for row in matrix:
            row.reverse()
```

## 一句话总结

这道题的关键是：

**把“顺时针旋转 90 度”拆成两步原地操作：先沿主对角线转置，再把每一行左右翻转，这样既满足原地修改要求，又能用 `O(1)` 额外空间完成旋转。**
