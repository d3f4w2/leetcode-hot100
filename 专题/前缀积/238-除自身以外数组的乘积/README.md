# 238. 除自身以外数组的乘积

## 所属专题

- 前缀积

## 题目描述

给你一个整数数组 `nums`，返回数组 `answer`，其中：

- `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积

题目保证：

- 数组 `nums` 之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位整数范围内

并且要求：

- **不要使用除法**
- 在 **`O(n)` 时间复杂度** 内完成

## 示例

### 示例 1

```text
输入：nums = [1,2,3,4]
输出：[24,12,8,6]
```

## 题意理解

这道题要求我们对数组中的每一个位置 `i`，都计算一个值：

- 把除了 `nums[i]` 以外的所有数乘起来

例如：

```text
nums = [1,2,3,4]
```

那么：

- `answer[0] = 2 * 3 * 4 = 24`
- `answer[1] = 1 * 3 * 4 = 12`
- `answer[2] = 1 * 2 * 4 = 8`
- `answer[3] = 1 * 2 * 3 = 6`

所以结果是：

```text
[24,12,8,6]
```

这道题有两个关键限制一定要注意：

1. 不能用除法
2. 要求 `O(n)` 时间复杂度

也就是说，那种“先把所有数乘起来，再除以当前数”的写法，即使你想到了，也不符合题目要求。

## 最直接的想法：对每个位置重新乘一遍

最容易想到的方法是：

- 枚举每个位置 `i`
- 再遍历一遍整个数组
- 把除了 `i` 以外的所有数字都乘起来

例如：

```python
answer = []

for i in range(len(nums)):
    product = 1
    for j in range(len(nums)):
        if i != j:
            product *= nums[j]
    answer.append(product)
```

这个方法肯定能做出来，逻辑也很直接。

但是问题是：

- 外层遍历 `n` 次
- 内层每次又遍历 `n` 次

所以时间复杂度是：

`O(n^2)`

不满足题目要求的 `O(n)`。

## 一个看起来更快、但题目不允许的想法：总乘积再除

很多人会自然想到：

1. 先把所有元素乘起来，得到总乘积 `total`
2. 对于每个位置，直接计算 `total / nums[i]`

这个想法看起来像是 `O(n)`，但有两个问题：

### 问题 1：题目明确禁止使用除法

所以这种写法直接不符合要求。

### 问题 2：如果数组里有 `0`，会很麻烦

例如：

- 有一个 `0` 时，大多数位置结果都会变成 `0`
- 有两个及以上 `0` 时，结果会更特殊

所以除法思路本身也不稳定。

因此我们需要一个：

- 不用除法
- 仍然能在 `O(n)` 时间完成

的办法。

## 优化思路：前缀积 + 后缀积

这是这道题最经典的做法。

### 核心想法

对于位置 `i` 来说，
除自身以外的乘积，其实就是两部分相乘：

1. `i` 左边所有数的乘积
2. `i` 右边所有数的乘积

也就是说：

```text
answer[i] = 左边乘积 × 右边乘积
```

例如在：

```text
nums = [1,2,3,4]
```

对于位置 `2`，也就是数字 `3`：

- 左边乘积是 `1 * 2 = 2`
- 右边乘积是 `4`

所以：

```text
answer[2] = 2 * 4 = 8
```

### 先想一个容易理解的版本

我们可以先定义两个数组：

- `left[i]`：表示 `i` 左边所有数的乘积
- `right[i]`：表示 `i` 右边所有数的乘积

那么最后：

```text
answer[i] = left[i] * right[i]
```

这个思路非常清楚：

- 左边的贡献单独算
- 右边的贡献单独算
- 最后合并

### 再把空间优化掉

题目希望尽量做到常数额外空间。

其实我们没有必要真的开一个完整的 `right` 数组。

可以这样做：

#### 第一步：先用 `answer` 存左边乘积

让：

- `answer[i]` 先表示位置 `i` 左边所有数的乘积

例如：

```text
nums = [1,2,3,4]
```

处理完后：

```text
answer = [1,1,2,6]
```

为什么是这个结果？

- `answer[0] = 1`，因为第 0 个位置左边没有数，空乘积记作 `1`
- `answer[1] = 1`
- `answer[2] = 1 * 2 = 2`
- `answer[3] = 1 * 2 * 3 = 6`

#### 第二步：从右往左维护一个右边乘积 `right`

然后我们再从右往左扫一遍数组。

用变量：

```python
right = 1
```

表示“当前位置右边所有数的乘积”。

在遍历到位置 `i` 时：

- 当前的 `answer[i]` 已经是左边乘积
- `right` 正好是右边乘积

所以直接：

```python
answer[i] *= right
```

就得到了最终答案。

之后再更新：

```python
right *= nums[i]
```

让 `right` 变成下一个位置所需要的右边乘积。

这样就不需要额外的 `right` 数组了。

## 用示例手推一遍

以示例 1 为例：

```text
nums = [1,2,3,4]
```

### 第 1 轮：先计算左边乘积

初始化：

```text
answer = [1,1,1,1]
```

然后从左到右更新：

- `i = 1`：`answer[1] = answer[0] * nums[0] = 1 * 1 = 1`
- `i = 2`：`answer[2] = answer[1] * nums[1] = 1 * 2 = 2`
- `i = 3`：`answer[3] = answer[2] * nums[2] = 2 * 3 = 6`

此时：

```text
answer = [1,1,2,6]
```

### 第 2 轮：从右往左乘上右边乘积

先令：

```text
right = 1
```

#### 处理 `i = 3`

- 当前 `answer[3] = 6`，表示左边乘积 `1 * 2 * 3`
- 当前 `right = 1`，表示右边没有数

所以：

```text
answer[3] = 6 * 1 = 6
```

然后更新：

```text
right = 1 * 4 = 4
```

#### 处理 `i = 2`

- 当前 `answer[2] = 2`
- 当前 `right = 4`

所以：

```text
answer[2] = 2 * 4 = 8
```

然后更新：

```text
right = 4 * 3 = 12
```

#### 处理 `i = 1`

- 当前 `answer[1] = 1`
- 当前 `right = 12`

所以：

```text
answer[1] = 1 * 12 = 12
```

然后更新：

```text
right = 12 * 2 = 24
```

#### 处理 `i = 0`

- 当前 `answer[0] = 1`
- 当前 `right = 24`

所以：

```text
answer[0] = 1 * 24 = 24
```

最终得到：

```text
[24,12,8,6]
```

## 为什么这样写

这道题最关键的地方，不在于背公式，而在于理解为什么能拆成“两边的乘积”。

### 1. 每个位置的答案，天然就是左边和右边两部分

对于 `nums[i]` 来说，
“除自己以外的乘积”不就是：

- 左边全部元素乘起来
- 再乘右边全部元素

所以这道题天然就适合“前缀 + 后缀”的思维。

### 2. `answer` 数组先存左边乘积，是为了复用空间

如果我们真的写两个数组：

- 一个 `left`
- 一个 `right`

当然也能做出来。

但其实：

- `answer` 最终本来就要返回

所以可以先把左边乘积直接存在 `answer` 里，省掉一个数组。

### 3. `right` 变量是“滚动维护”的后缀积

从右往左遍历时，
我们并不需要提前知道所有位置的右边乘积。

只需要用一个变量，边走边乘就行了。

这就是为什么空间可以优化到：

- 不计返回数组时，为 `O(1)`

### 4. 这个方法天然兼容 `0`

因为整个过程没有做除法，
只是老老实实地计算左边乘积和右边乘积。

所以即使数组里有 `0`，逻辑也仍然成立。

## 算法步骤

1. 创建长度为 `n` 的结果数组 `answer`，并全部初始化为 `1`
2. 从左到右遍历，令 `answer[i]` 存放位置 `i` 左边所有数的乘积
3. 初始化变量 `right = 1`
4. 从右到左遍历数组
5. 用 `answer[i] *= right` 把右边乘积乘进去
6. 再更新 `right *= nums[i]`
7. 遍历结束后，返回 `answer`

## 复杂度分析

### 时间复杂度

`O(n)`

原因：

- 我们只做了两次线性遍历
- 每个位置都只处理常数次

### 空间复杂度

`O(1)`

说明：

- 这里不计算返回数组 `answer` 的空间
- 除了 `answer` 以外，只用了一个变量 `right`

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)

        # answer[i] 先用来存“i 左边所有数的乘积”。
        # 一开始全部设成 1，因为乘法的单位元是 1。
        answer = [1] * n

        # 第一轮：从左到右，计算每个位置左边的乘积。
        # answer[0] 保持为 1，因为第 0 个位置左边没有元素。
        for i in range(1, n):
            answer[i] = answer[i - 1] * nums[i - 1]

        # right 用来记录“当前位置右边所有数的乘积”。
        # 一开始最右边位置右侧没有元素，所以也是 1。
        right = 1

        # 第二轮：从右到左，把右边乘积乘到 answer[i] 上。
        for i in range(n - 1, -1, -1):
            # 此时 answer[i] 是左边乘积，right 是右边乘积。
            # 两者相乘，就是最终答案。
            answer[i] *= right

            # 更新 right，供下一个位置使用。
            right *= nums[i]

        return answer
```

## 这段代码最值得记住的地方

你在自己手写的时候，重点记住下面这条主线：

```python
answer = [1] * len(nums)

for i in range(1, len(nums)):
    answer[i] = answer[i - 1] * nums[i - 1]

right = 1
for i in range(len(nums) - 1, -1, -1):
    answer[i] *= right
    right *= nums[i]
```

本质上就是一句话：

**先把每个位置左边的乘积存起来，再从右往左补上右边的乘积。**

## 常见错误

### 1. 直接使用除法

题目明确说了：

- 不允许使用除法

所以哪怕逻辑上能想到，也不能这样写。

### 2. 把左边乘积和右边乘积的定义写错

例如在计算左边乘积时，
当前 `answer[i]` 应该乘的是：

```python
nums[i - 1]
```

而不是 `nums[i]`。

因为 `answer[i]` 存的是“自己左边”的乘积，不应该把自己乘进去。

### 3. 从右往左时，更新顺序写反

正确顺序是：

```python
answer[i] *= right
right *= nums[i]
```

如果你先更新 `right`，就会把 `nums[i]` 自己错误地乘进去。

### 4. 忘记初始化为 `1`

无论是：

- `answer`
- 还是 `right`

初始值都应该是 `1`。

因为 `1` 是乘法单位元。

### 5. 把这题当成前缀和来写

这题虽然属于“前后缀”思路，
但这里维护的是：

- 乘积

不是：

- 和

如果你准备在自己的 `.ipy` 文件里默写，建议先记住下面这个精简版本：

```python
from typing import List


class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [1] * n

        for i in range(1, n):
            answer[i] = answer[i - 1] * nums[i - 1]

        right = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= right
            right *= nums[i]

        return answer
```

## 一句话总结

这道题的关键不是硬算“除了自己以外的所有乘积”，而是：

**把每个位置的答案拆成“左边乘积 × 右边乘积”，再用一个结果数组和一个右侧滚动变量把它在线性时间内拼出来。**
