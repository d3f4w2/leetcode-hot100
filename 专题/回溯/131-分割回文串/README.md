# 131. 分割回文串

## 所属专题

- 回溯

## 题目描述

给你一个字符串 `s`，
请你将 `s` 分割成一些子串，
使得每个子串都是**回文串**。

返回 `s` 的所有可能分割方案。

说明：

- 回文串指正着读和反着读都一样的字符串
- 返回答案的顺序可以任意

## 示例

### 示例 1

```text
输入：s = aab
输出：[[a,a,b],[aa,b]]
```

### 示例 2

```text
输入：s = a
输出：[[a]]
```

## 题意理解

这道题不是让我们判断：

- 能不能分割

而是要我们找出：

- **所有可能的分割方式**
- 并且每一段都必须是回文串

比如：

```text
s = aab
```

可以这样切：

- `a | a | b`
- `aa | b`

但不能这样切：

- `a | ab`

因为 `ab` 不是回文串。

所以这题的核心就是：

**枚举每一种切割方式，只保留每一段都是回文的方案。**

## 为什么适合用回溯

这题一看到“所有可能的方案”，
就很适合往回溯上想。

因为我们可以把问题看成：

- 从下标 `start` 开始
- 尝试切出一个子串 `s[start:i]`
- 如果这一段是回文，就把它加入当前路径
- 然后继续递归处理后面的部分

也就是说，
每一层递归都在决定：

- **当前位置这一刀要切到哪里**

只要把所有可能的切法都试一遍，
就能得到全部答案。

## 回溯的核心思路

我们定义函数：

```python
backtrack(start, path)
```

它表示：

- 当前要处理的起点是 `start`
- `path` 里保存的是已经切出来的若干回文子串

### 什么时候找到一个答案

当：

```python
start == len(s)
```

说明字符串已经被完整切完了。

此时 `path` 中保存的就是一种合法分割方案，
直接加入结果集即可。

### 当前层要做什么

如果还没有切到末尾，
就枚举当前这一段的结束位置：

```python
for end in range(start, len(s))
```

如果 `s[start:end+1]` 是回文串，
就说明这一步切法有效：

1. 把这个子串加入 `path`
2. 递归处理下一段 `end + 1`
3. 递归回来后撤销这次选择

这就是标准的回溯过程：

- 做选择
- 递归深入
- 撤销选择

## 如何判断回文

对于子串 `s[left:right+1]`，
可以使用双指针判断：

- 左指针从 `left` 开始
- 右指针从 `right` 开始
- 如果两边字符不同，就不是回文
- 如果一路向中间靠拢都相同，就是回文

```python
def is_palindrome(left, right):
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True
```

## 用示例手推一遍

以：

```text
s = aab
```

为例。

一开始调用：

```text
backtrack(0, [])
```

表示从下标 `0` 开始切。

### 第 1 层：从位置 0 开始尝试

可以尝试这些子串：

- `a`，是回文
- `aa`，是回文
- `aab`，不是回文

先选 `a`，路径变成：

```text
[a]
```

然后进入 `backtrack(1, [a])`。

接着从位置 `1` 开始：

- `a`，是回文
- `ab`，不是回文

再选 `a`，路径变成：

```text
[a, a]
```

然后进入 `backtrack(2, [a, a])`。

最后从位置 `2` 只能选：

- `b`，是回文

于是得到：

```text
[a, a, b]
```

这时 `start == len(s)`，
所以这是第一个答案。

回到第一层后，再尝试 `aa`，
再接上 `b`，得到第二个答案：

```text
[aa, b]
```

最终结果为：

```text
[[a,a,b],[aa,b]]
```

## 算法步骤

1. 定义结果数组 `result`
2. 定义回文判断函数 `is_palindrome(left, right)`
3. 定义回溯函数 `backtrack(start, path)`
4. 如果 `start == len(s)`，说明找到一种完整方案，加入结果
5. 枚举所有可能的结束位置 `end`
6. 如果 `s[start:end+1]` 是回文串，就加入路径并递归
7. 递归返回后执行 `path.pop()` 撤销选择
8. 最后返回所有结果

## Python 参考实现

```python
def partition(s):
    result = []

    def is_palindrome(left, right):
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True

    def backtrack(start, path):
        if start == len(s):
            result.append(path[:])
            return

        for end in range(start, len(s)):
            if is_palindrome(start, end):
                path.append(s[start:end + 1])
                backtrack(end + 1, path)
                path.pop()

    backtrack(0, [])
    return result
```

## 为什么这段代码是对的

因为它始终维护了一个重要条件：

- `path` 中的每个子串一定都是回文串

只有通过 `is_palindrome(start, end)` 检查的子串，
才会加入到路径里。

同时每次递归都会把起点推进到 `end + 1`，
所以字符串会被按顺序、无重叠地切分。

当 `start == len(s)` 时，
说明整个字符串已经恰好切完，
因此当前 `path` 一定是一种合法答案。

## 复杂度分析

### 时间复杂度

如果按这份代码的写法，
每次都现场用双指针判断回文，
最坏时间复杂度可以看作：

`O(n^2 * 2^n)`

很多资料也会近似写成 `O(n * 2^n)`，
那通常是在强调答案规模，
或者默认回文状态已经被预处理。

### 空间复杂度

不计结果集时，空间复杂度是：

`O(n)`

因为递归深度最多是 `n`，
而 `path` 最多也只会保存 `n` 段子串。

## 常见错误

### 1. 找到一个答案就直接结束

这题要求的是所有方案，
所以找到一个答案后还要继续回溯。

### 2. 忘记 `path.pop()`

如果不撤销选择，
后续递归就会受到前面路径的污染。

### 3. 切片边界写错

应该写：`s[start:end + 1]`，
因为 Python 切片右边界不包含当前下标。

### 4. 漏掉长度为 1 的子串

单个字符一定是回文串，
所以必须尝试 `end == start` 的情况。

### 5. 回文判断边界写错

双指针判断时应该使用：`while left < right`。

## 一句话总结

**这道题的关键就是：用回溯枚举每一刀切在哪里，并且只有当当前子串是回文串时才继续向下搜索，这样就能找出所有合法的回文分割方案。**
