# 079. 单词搜索

## 所属专题

- 回溯

## 题目描述

给定一个 `m x n` 的二维字符网格 `board` 和一个字符串 `word`，
如果 `word` 存在于网格中，返回 `True`；否则，返回 `False`。

单词必须按照字母顺序，
通过相邻的单元格内的字母构成。

这里的“相邻”只包括：

- 水平相邻
- 垂直相邻

不包括对角线。

同时还有一个非常重要的限制：

- 同一个单元格在一次路径中不能被重复使用

## 示例

### 示例 1

```text
输入：board = [[A,B,C,E],[S,F,C,S],[A,D,E,E]], word = ABCCED
输出：True
```

### 示例 2

```text
输入：board = [[A,B,C,E],[S,F,C,S],[A,D,E,E]], word = SEE
输出：True
```

### 示例 3

```text
输入：board = [[A,B,C,E],[S,F,C,S],[A,D,E,E]], word = ABCB
输出：False
```

## 题意理解

这道题不是让我们：

- 统计某个字母出现了多少次
- 也不是随便从棋盘里找出这些字母就行

而是要求：

- 从某个起点开始
- 按照 `word` 的字符顺序一个一个匹配
- 每一步只能走到上下左右相邻的位置
- 同一个格子不能重复走

比如示例 1：

```text
board =
[
  [A,B,C,E],
  [S,F,C,S],
  [A,D,E,E]
]

word = ABCCED
```

它要求我们真的在网格中走出这样一条路径：

- `A -> B -> C -> C -> E -> D`

如果只是这些字母都存在，
但它们不能连成一条合法路径，
那也要返回 `False`。

所以这道题的本质是：

- 在网格中寻找一条路径
- 让这条路径拼出来的字符刚好等于 `word`

## 最直接的想法：从每个格子出发试一遍

如果不知道单词从哪里开始，
那最自然的做法就是：

- 把每个格子都当成起点试一遍

对于某个起点 `(i, j)`：

- 如果它和 `word[0]` 不相等，直接跳过
- 如果相等，就继续看它的上下左右，能不能匹配 `word[1]`
- 再继续找 `word[2]`
- 一直找到最后一个字符

这个过程会不断出现“往下试一条路”的行为：

- 当前格子选了
- 下一步往四个方向试
- 如果这条路走不通，再退回来换别的方向

这正是典型的：

- 深度优先搜索（DFS）
- 回溯

## 优化思路：DFS + 回溯

### 核心想法

我们定义一个递归函数：

```text
dfs(i, j, index)
```

它表示：

- 当前来到位置 `(i, j)`
- 现在要匹配 `word[index]`

如果当前位置刚好能匹配当前字符，
我们就继续去它的四个方向，
尝试匹配下一个字符。

### 递归里要解决的几个问题

#### 1. 越界了怎么办

如果 `(i, j)` 超出了网格范围，
这条路肯定不合法，直接返回 `False`。

#### 2. 当前字符不匹配怎么办

如果：

```text
board[i][j] != word[index]
```

说明这条路走错了，直接返回 `False`。

#### 3. 什么时候说明已经找到单词

如果当前字符已经是 `word` 的最后一个字符，
并且它也匹配成功，
那么就说明整条路径找到了，直接返回 `True`。

#### 4. 如何防止重复使用同一个格子

这是这道题最关键的限制。

常见做法有两种：

- 使用 `visited` 数组
- 直接在原网格上做临时标记

这里我们用更简洁的做法：

- 先把当前格子的字符临时改成一个特殊值，比如 `'#'`
- 表示这个格子当前路径已经用过了
- 递归结束后再恢复原来的字符

这样就能避免同一条路径里重复进入同一个格子。

这一步就叫：

- 做选择
- 递归搜索
- 撤销选择

也就是回溯。

## 用示例手推一遍

以示例 1 为例：

```text
board =
[
  [A,B,C,E],
  [S,F,C,S],
  [A,D,E,E]
]

word = ABCCED
```

### 第 1 步：先找起点

因为单词第一个字符是 `A`，
所以我们会遍历整个网格，
找到可能的起点。

例如先看到左上角：

```text
(0, 0) = 'A'
```

它和 `word[0]` 相同，
于是从这里开始 DFS。

### 第 2 步：匹配 `B`

当前已经匹配了：

```text
A
```

接下来要找 `word[1] = 'B'`。

从 `(0, 0)` 出发，
只能看上下左右：

- 上：越界
- 下：`S`
- 左：越界
- 右：`B`

只有右边符合，
所以继续走到 `(0, 1)`。

### 第 3 步：继续匹配 `C`

此时已经匹配：

```text
A -> B
```

下一个字符是 `C`。

从 `(0, 1)` 看四周，
可以继续走到 `(0, 2)`。

### 第 4 步：再匹配一个 `C`

接着从第一个 `C` 出发，
下一个要找的还是 `C`。

这时可以往下走到：

```text
(1, 2) = 'C'
```

### 第 5 步：匹配 `E`

从 `(1, 2)` 出发继续找 `E`，
可以走到：

```text
(2, 2) = 'E'
```

### 第 6 步：匹配最后一个 `D`

再从 `(2, 2)` 出发找 `D`，
可以走到：

```text
(2, 1) = 'D'
```

这样就完整匹配出了：

```text
A -> B -> C -> C -> E -> D
```

所以返回：

```text
True
```

## 为什么这样写

### 1. 起点不确定，只能枚举所有起点

题目没有告诉我们从哪里开始，
所以只能：

- 把每个格子都当成起点去试

只要有一个起点能成功，
整题答案就是 `True`。

### 2. 每走一步都会分叉，天然适合 DFS

从当前格子出发，
下一步最多有四个方向可走：

- 上
- 下
- 左
- 右

这就是一棵搜索树。

只要某个方向能走通，
就说明找到答案。

### 3. 同一个格子不能重复用，所以必须“标记 + 恢复”

如果不做访问标记，
搜索时就可能来回绕圈，
甚至把同一个格子重复使用，
违反题目要求。

所以在递归进入下一层前：

- 先把当前格子标记为已使用

递归回来后：

- 再恢复原值

这就是回溯最典型的写法。

### 4. 只要找到一条合法路径，就可以立刻返回

这题不是要统计一共有多少种走法，
而是只问：

- 存不存在

所以一旦某条路径成功，
就可以一路返回 `True`，
不需要继续搜索其他路径。

## 算法步骤

1. 先得到网格的行数 `m` 和列数 `n`
2. 定义递归函数 `dfs(i, j, index)`，表示从 `(i, j)` 开始匹配 `word[index]`
3. 如果当前位置越界，返回 `False`
4. 如果当前位置字符不等于 `word[index]`，返回 `False`
5. 如果当前已经匹配到 `word` 的最后一个字符，返回 `True`
6. 先保存当前格子的字符，并把它临时改为 `'#'`
7. 分别递归搜索上、下、左、右四个方向，去匹配下一个字符
8. 如果四个方向中有一个返回 `True`，说明找到了答案
9. 无论成功还是失败，都要把当前格子恢复成原字符
10. 枚举每一个格子作为起点，只要某次 DFS 成功，就返回 `True`
11. 如果所有起点都失败，返回 `False`

## 复杂度分析

设网格大小为 `m x n`，
单词长度为 `L`。

### 时间复杂度

`O(m × n × 4^L)`

可以这样理解：

- 最外层最多会从每个格子出发一次
- 每次搜索时，最坏情况下每一层都可能往四个方向扩展
- 搜索深度最多是 `L`

所以常见写法记为：

`O(m × n × 4^L)`

### 空间复杂度

`O(L)`

原因是：

- 递归调用栈的最大深度不会超过单词长度 `L`
- 这里采用原地标记，没有额外开 `visited` 矩阵

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])

        def dfs(i: int, j: int, index: int) -> bool:
            # 如果当前位置字符和当前要匹配的字符不同，
            # 说明这条路径走不通。
            if board[i][j] != word[index]:
                return False

            # 如果当前字符已经是 word 的最后一个字符，
            # 并且它也匹配成功了，说明整个单词找到了。
            if index == len(word) - 1:
                return True

            # 先暂存当前位置字符，
            # 然后把它标记成已访问，避免重复使用。
            temp = board[i][j]
            board[i][j] = '#'

            # 四个方向：上、下、左、右。
            directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

            for dx, dy in directions:
                ni, nj = i + dx, j + dy

                # 只有在不越界、并且这个格子还没被使用时，
                # 才继续递归搜索下一个字符。
                if 0 <= ni < m and 0 <= nj < n and board[ni][nj] != '#':
                    if dfs(ni, nj, index + 1):
                        # 找到答案后，先恢复现场，再返回 True。
                        board[i][j] = temp
                        return True

            # 四个方向都试过了，还是不行，
            # 说明从当前位置出发匹配失败。
            # 递归返回前要把当前格子恢复。
            board[i][j] = temp
            return False

        # 枚举每一个格子作为起点。
        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True

        return False
```

## 这段代码最值得记住的地方

这题最核心的不是四个方向怎么写，
而是下面这个“回溯模板”：

```python
temp = board[i][j]
board[i][j] = '#'

for dx, dy in directions:
    ...

board[i][j] = temp
```

它表达的是：

- 先把当前格子占用掉
- 去试下一步
- 试完以后恢复现场

这正是“同一个格子不能重复使用”这个限制的核心处理方式。

## 常见错误

### 1. 忘记恢复现场

如果你把当前格子改成了 `'#'`，
却没有在递归结束后恢复，
后面的搜索就会受到影响。

所以一定要记住：

- 递归前标记
- 递归后恢复

### 2. 没有限制同一个格子不能重复使用

如果没有 `visited` 或原地标记，
同一个格子就可能被反复走到，
这会让结果错误。

### 3. 把“找到最后一个字符”写错位置

推荐顺序是：

- 先确认当前格子字符匹配
- 再判断它是不是最后一个字符

这样逻辑最清楚。

### 4. 忘记枚举所有起点

很多人只从左上角开始搜，
但题目并没有保证起点固定。

必须遍历整个网格，
把每个位置都当成可能的起点。

### 5. 把对角线也算成相邻

这题里相邻只包括：

- 上下
- 左右

不包括左上、右上、左下、右下。

## 适合你自己再写一遍的版本

```python
from typing import List


class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])

        def dfs(i, j, index):
            if board[i][j] != word[index]:
                return False

            if index == len(word) - 1:
                return True

            temp = board[i][j]
            board[i][j] = '#'

            for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                ni, nj = i + dx, j + dy
                if 0 <= ni < m and 0 <= nj < n and board[ni][nj] != '#':
                    if dfs(ni, nj, index + 1):
                        board[i][j] = temp
                        return True

            board[i][j] = temp
            return False

        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True

        return False
```

## 一句话总结

这道题的关键是：

**从每个格子出发做 DFS，匹配单词的下一个字符，同时用“标记并恢复”的回溯方式避免重复使用同一个格子。**
