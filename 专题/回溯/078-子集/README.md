# 078. 子集

## 所属专题

- 回溯

## 题目描述

给你一个整数数组 `nums`，数组中的元素 **互不相同**。
返回该数组所有可能的子集（幂集）。

解集 **不能包含重复的子集**，你可以按 **任意顺序** 返回答案。

## 示例

### 示例 1

```text
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

### 示例 2

```text
输入：nums = [0]
输出：[[],[0]]
```

## 题意理解

这道题让我们做的事情是：

- 从数组里挑一些数出来
- 也可以一个都不挑
- 也可以全部都挑
- 把所有可能的挑法都找出来

比如：

```text
nums = [1,2]
```

所有子集就是：

- `[]`：一个都不选
- `[1]`：只选 `1`
- `[2]`：只选 `2`
- `[1,2]`：两个都选

所以这题本质上是在问：

**对于每个元素，选还是不选？**

只要把每个位置的这两种情况都考虑到，
就能得到所有子集。

## 为什么适合用回溯

这类题有几个非常明显的特征：

- 要求返回 **所有可能结果**
- 每一步都在做“选哪个”的决策
- 做完当前选择后，要继续往后枚举

这正是回溯最擅长处理的场景。

你可以把它理解成：

- 先确定第一个数要不要进子集
- 再确定第二个数要不要进子集
- 再确定第三个数要不要进子集
- ……

一路往下走，
每走到一个位置，都形成一种当前子集状态。

## 两种常见思路

这题常见有两种回溯理解方式：

### 思路一：每个元素“选 / 不选”

例如对 `1`：

- 选 `1`
- 不选 `1`

再递归处理下一个元素。

### 思路二：枚举“下一个选谁”

也就是你给出的这版代码：

- 先把当前 `path` 作为一个子集加入答案
- 然后从 `start` 开始，依次尝试把某个元素加入 `path`
- 加入后继续向后递归

这两种写法本质上是等价的。

你现在这版代码更常见、也更好写。

## 核心思路：`start` 控制下一步从哪里选

代码里的递归函数是：

```python
def backtrack(start, path):
```

它表示：

- `path`：当前已经选出来的子集
- `start`：下一次只能从 `nums[start]` 及其后面继续选

为什么一定要有 `start`？

因为子集不关心顺序。

例如：

- `[1,2]` 和 `[2,1]`

在子集问题里其实是同一个结果，
不能重复加入答案。

所以一旦我们已经选了前面的元素，
后面就只能继续往后选，
不能再回头选前面的数。

这就是 `start` 的作用。

## 为什么一开始就要加入答案

代码里最关键的一句是：

```python
result.append(path[:])
```

而且它出现在递归函数一开始。

这是因为：

- 当前的 `path` 本身，就是一个合法子集
- 不需要等递归结束才加入

例如：

- 刚进入 `backtrack(0, [])` 时，`[]` 就是一个合法子集
- 当进入 `backtrack(1, [1])` 时，`[1]` 也是一个合法子集
- 当进入 `backtrack(2, [1,2])` 时，`[1,2]` 也是一个合法子集

所以每到一个节点，
都应该先把当前路径收集起来。

## 用示例手推一遍

以：

```text
nums = [1,2,3]
```

为例。

### 第 1 步：从空集开始

调用：

```python
backtrack(0, [])
```

此时：

- `path = []`
- 这是一个合法子集，先加入答案

当前答案：

```text
[[]]
```

然后从下标 `0` 开始枚举可以加入的元素。

---

### 第 2 步：先选 `1`

执行：

```python
path.append(1)
backtrack(1, [1])
```

进入下一层后：

- `[1]` 是一个合法子集，加入答案

当前答案：

```text
[[], [1]]
```

然后从下标 `1` 开始继续选。

---

### 第 3 步：在 `[1]` 的基础上选 `2`

进入：

```python

```

先加入 `[1,2]`。

然后从下标 `2` 开始继续选，
还能加入 `3`。

得到：

```text

```

这条路走完后，回退到 `[1]`。

---

### 第 4 步：在 `[1]` 的基础上改选 `3`

回到 `[1]` 后，
前面已经试过 `2` 了，继续试 `3`。

得到：

```text
[1,3]
```

---

### 第 5 步：回到空集，改从 `2` 开始

这时得到：

- `[2]`
- `[2,3]`

---

### 第 6 步：回到空集，再选 `3`

- `[3]`

## 回溯树怎么理解

对于 `nums = [1,2,3]`，
递归过程可以大致看成这样：

```text
[]
├── [1]
│   ├── [1,2]
│   │   └── [1,2,3]
│   └── [1,3]
├── [2]
│   └── [2,3]
└── [3]
```

注意：

- 树上的每一个节点，都是一个子集
- 所以每到一个节点，都要加入答案

这就是为什么 `result.append(path[:])` 写在递归开头。

## 代码中的每一部分在干什么

```python
def subsets(nums):
    result = []
    
    def backtrack(start, path):
        result.append(path[:])
        
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
    
    backtrack(0, [])
    return result
```

### 1. `result = []`

用来保存所有子集。

### 2. `backtrack(start, path)`

表示：

- 当前已经选出的子集是 `path`
- 接下来只能从 `start` 开始往后选

### 3. `result.append(path[:])`

把当前子集加入答案。

这里一定要写成：

```python
path[:]
```

因为 `path` 是可变列表。
如果直接写：

```python
result.append(path)
```

后面 `path` 继续变化时，
`result` 里的内容也会跟着变，答案就错了。

### 4. `for i in range(start, len(nums))`

枚举当前层可以选择的元素。

为什么从 `start` 开始？

因为前面的元素已经处理过了，
不能回头再选，
否则会产生重复子集。

### 5. `path.append(nums[i])`

做选择：
把当前元素加入子集。

### 6. `backtrack(i + 1, path)`

递归处理后面的元素。

这里传 `i + 1`，意思是：

- 当前选了 `nums[i]`
- 下一层只能从它后面继续选

### 7. `path.pop()`

撤销选择。

也就是回到进入这一层之前的状态，
方便继续尝试下一个元素。

这就是回溯里的经典三步：

- 做选择
- 递归
- 撤销选择

## 算法步骤

1. 创建结果数组 `result`
2. 定义递归函数 `backtrack(start, path)`
3. 每次进入递归，先把当前 `path` 加入结果
4. 从 `start` 开始枚举每个可选元素
5. 将该元素加入 `path`
6. 递归处理后续元素
7. 递归返回后，将刚加入的元素弹出
8. 所有分支遍历完成后，返回 `result`

## 复杂度分析

### 时间复杂度

`O(n × 2^n)`

原因是：

- 一个长度为 `n` 的数组，一共有 `2^n` 个子集
- 每次加入答案时，复制当前 `path` 需要 `O(n)` 时间

所以总时间复杂度是：

`O(n × 2^n)`

### 空间复杂度

`O(n)`

这里通常指递归调用栈和当前路径 `path` 的额外空间。

- 递归深度最多为 `n`
- `path` 最长也为 `n`

如果把最终结果也算上，
那结果集合本身会占用 `O(n × 2^n)` 空间，
这是题目要求输出所有子集所无法避免的。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        # 用来保存所有子集。
        result = []

        def backtrack(start: int, path: List[int]) -> None:
            # 当前 path 本身就是一个合法子集，
            # 所以每次进入递归都先收集答案。
            result.append(path[:])

            # 从 start 开始，依次尝试把后面的数字加入当前子集。
            for i in range(start, len(nums)):
                # 做选择：把 nums[i] 放进当前子集。
                path.append(nums[i])

                # 递归处理下一个位置。
                # 因为子集不关心顺序，所以只能继续往后选。
                backtrack(i + 1, path)

                # 撤销选择：恢复现场，尝试下一个数字。
                path.pop()

        # 从空子集开始回溯。
        backtrack(0, [])
        return result
```

## 常见错误

### 1. 忘记拷贝 `path`

错误写法：

```python
result.append(path)
```

正确写法：

```python
result.append(path[:])
```

因为 `path` 会在后续递归中不断变化，
直接加入原列表会导致结果出错。

### 2. 递归之后忘记 `pop()`

如果你写了：

```python
path.append(nums[i])
backtrack(i + 1, path)
```

却忘了：

```python
path.pop()
```

那前一个分支加入的元素会残留到后一个分支里，
结果就乱了。

### 3. 把这题写成排列问题

子集和排列最大的区别是：

- 子集不关心顺序
- 排列关心顺序

所以这题不需要 `used` 数组，
只需要用 `start` 保证后续选择始终往后走。

### 4. 不理解为什么空集也要加入答案

题目要求的是“所有子集”，
而空集本身就是任何集合的子集，
所以必须包含：

```python
[]
```

## 一句话总结

这道题的关键是：

**把“生成所有子集”看成一个不断向后选数的过程，用 `path` 记录当前子集，用 `start` 保证不重复选择前面的元素，并在每次进入递归时把当前 `path` 收集到答案中。**
