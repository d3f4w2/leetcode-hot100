# 090. 子集 II

## 所属专题

- 回溯

## 题目描述

给你一个整数数组 `nums`，其中可能包含重复元素，
请你返回该数组所有可能的子集（幂集）。

注意：

- 解集 **不能包含重复的子集**
- 返回的解集可以按 **任意顺序** 排列

这里的“子集”指的是：

- 从原数组里选出若干个元素
- 也可以一个都不选
- 元素之间的相对顺序不重要，重点是“选了哪些数”

## 示例

### 示例 1

```text
输入：nums = [1,2,2]
输出：[[],[1],[1,2],[1,2,2],[2],[2,2]]
```

### 示例 2

```text
输入：nums = [0]
输出：[[],[0]]
```

## 题意理解

这道题和普通的“子集”问题很像，
核心仍然是：

- 每个元素都有两种状态：选，或者不选

所以我们最终要找的是：

- 所有可能的选法

比如：

```text
nums = [1,2,2]
```

如果暂时不考虑重复，
你可能会枚举出很多子集：

- `[]`
- `[1]`
- `[2]`
- `[1,2]`
- `[2,2]`
- `[1,2,2]`

但问题在于：

- 这里有两个 `2`
- 如果处理不好，就会生成重复子集

例如：

- 选第一个 `2` 得到 `[2]`
- 选第二个 `2` 也可能得到 `[2]`

这两个结果虽然来自不同下标，
但作为“子集”来说，它们是同一个答案，不能重复加入结果。

所以这道题的真正难点不是“怎么生成所有子集”，
而是：

- **怎么在生成子集的同时去重**

## 最直接的想法：先暴力枚举，再去重

最容易想到的办法是：

1. 先像普通子集题一样，把所有可能的子集都枚举出来
2. 然后再想办法去重

这个方法理论上可行，
但会有两个问题。

### 问题 1：会生成很多重复结果

如果数组里重复元素比较多，
那么暴力枚举时会产生不少重复子集。

例如：

```text
nums = [2,2,2]
```

很多不同路径最后都会落到相同的子集上。

### 问题 2：后处理去重不够自然

你可能会想到：

- 把每个子集转成元组放进集合里去重

虽然也能做，
但这相当于：

- 先制造重复
- 再清理重复

不是最顺手的思路。

更好的做法是：

- **在搜索过程中就尽量避免重复分支**

## 优化思路：排序 + 回溯 + 同层去重

这道题最经典的做法是：

- 先排序
- 再回溯枚举所有子集
- 在同一层里跳过重复元素

### 第一步：先排序

例如：

```text
nums = [1,2,2]
```

排序后还是：

```text
[1,2,2]
```

如果原来是乱序的重复值，
排序就能把相同元素放到一起。

这样我们就能方便判断：

- 当前元素是否和前一个元素相同

这正是后面去重的基础。

### 第二步：回溯生成所有子集

子集问题的一个非常典型写法是：

- 每到一个递归层，先把当前路径加入答案
- 然后从当前位置开始，尝试把后面的元素一个个加入路径

我们定义：

```text
backtrack(start, path)
```

它表示：

- 当前已经选出的子集是 `path`
- 接下来只能从下标 `start` 及其后面继续选元素

为什么要从 `start` 往后选？

因为子集不关心顺序，
所以我们不需要回头再选前面的元素。

### 第三步：同层去重

这道题最关键的一句就是：

```python
if i > start and nums[i] == nums[i - 1]:
    continue
```

它的意思是：

- 如果当前数字和前一个数字一样
- 并且它们处在同一层选择里
- 那么当前这个数字就跳过

为什么是“同一层去重”？

因为：

- 同一层里，如果前一个相同数字已经试过了
- 再试当前这个相同数字，只会得到重复结果

但是：

- 不同层不能随便跳过

例如子集 `[2,2]` 是合法的，
说明第二个 `2` 在更深一层时仍然可能要被选到。

所以一定要注意：

- 只跳过同层重复
- 不跳过跨层重复

## 用示例手推一遍

以：

```text
nums = [1,2,2]
```

为例。

排序后：

```text
[1,2,2]
```

初始调用：

```text
backtrack(0, [])
```

### 第 1 层：从下标 0 开始选

先把当前子集加入答案：

```text
[]
```

然后依次尝试：

- 选 `1`
- 选第一个 `2`
- 选第二个 `2`

#### 分支 1：先选 `1`

进入：

```text
backtrack(1, [1])
```

先加入答案：

```text
[1]
```

接下来可以继续从下标 1 往后选。

##### 在 `[1]` 后面选第一个 `2`

进入：

```text
backtrack(2, [1,2])
```

加入答案：

```text
[1,2]
```

再往后还能选第二个 `2`，得到：

```text
[1,2,2]
```

##### 在 `[1]` 这一层直接选第二个 `2`

这时会发现：

- 当前 `nums[i] == nums[i - 1]`
- 并且 `i > start`

说明它和前一个 `2` 属于同一层重复选择，
所以跳过。

这样就避免再次生成重复的 `[1,2]`。

#### 分支 2：在第一层直接选第一个 `2`

进入：

```text
backtrack(2, [2])
```

加入答案：

```text
[2]
```

然后再往后选第二个 `2`，得到：

```text
[2,2]
```

#### 分支 3：在第一层直接选第二个 `2`

这一层里，
它和前一个数相同，
而且前一个 `2` 已经作为同层选择处理过了，
所以直接跳过。

最终结果就是：

```text
[[],[1],[1,2],[1,2,2],[2],[2,2]]
```

## 为什么这样写

### 1. 子集问题天然适合回溯

因为每个元素本质上都面临：

- 选
- 不选

或者换个角度说：

- 当前层从剩余元素里尝试选下一个加入子集

所以回溯是这类题最自然的写法。

### 2. 排序是去重的前提

如果不排序，
相同元素可能分散在不同位置。

那你就很难用：

```python
nums[i] == nums[i - 1]
```

去判断当前是不是重复选择。

所以排序不是附属步骤，
而是去重策略的基础。

### 3. 去重发生在“同一层”而不是“所有层”

这是这道题最关键的理解点。

例如：

- 第一层里，两个 `2` 作为起点是重复的，要跳过一个
- 但如果我们已经选了一个 `2`，下一层再选另一个 `2`，这是合法的，因为 `[2,2]` 本来就应该存在

所以判断条件必须写成：

```python
i > start and nums[i] == nums[i - 1]
```

而不能简单写成：

```python
if nums[i] == nums[i - 1]:
    continue
```

否则会错误地把跨层合法情况也跳掉。

## 算法步骤

1. 先对数组 `nums` 排序
2. 创建结果列表 `result`
3. 定义回溯函数 `backtrack(start, path)`
4. 每次进入回溯时，先把当前 `path` 的拷贝加入 `result`
5. 从下标 `start` 开始，依次枚举可以选择的元素
6. 如果当前元素和前一个元素相同，并且它们处在同一层，就跳过当前元素
7. 否则把当前元素加入 `path`
8. 递归调用 `backtrack(i + 1, path)`，去处理后面的元素
9. 递归返回后，弹出刚加入的元素，恢复现场
10. 所有分支处理完后，返回 `result`

## 复杂度分析

### 时间复杂度

`O(n × 2^n)`

原因是：

- 一个长度为 `n` 的数组，总共有大约 `2^n` 个子集
- 每次把当前路径加入答案时，需要复制一份路径
- 复制路径的代价在最坏情况下是 `O(n)`

因此整体时间复杂度可以写成：

`O(n × 2^n)`

### 空间复杂度

`O(n)`

如果只计算辅助空间：

- 递归深度最多为 `n`
- 路径 `path` 的长度最多也为 `n`

所以辅助空间复杂度是 `O(n)`。

如果把最终答案也算上，
结果集本身会占用更多空间，
这是无法避免的。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        # 先排序，把相同元素放到一起，方便后面去重。
        nums.sort()

        # 保存最终结果。
        result = []

        def backtrack(start: int, path: List[int]) -> None:
            # 每到一个状态，当前 path 都是一个合法子集。
            # 所以先把它加入结果。
            result.append(path[:])

            # 从 start 开始，尝试把后面的元素一个个加入当前子集。
            for i in range(start, len(nums)):
                # 同层去重：
                # 如果当前元素和前一个相同，
                # 并且当前元素不是这一层的第一个可选元素，
                # 那么跳过，避免生成重复子集。
                if i > start and nums[i] == nums[i - 1]:
                    continue

                # 做选择：把当前元素加入路径。
                path.append(nums[i])

                # 递归处理后面的元素。
                backtrack(i + 1, path)

                # 撤销选择，恢复现场。
                path.pop()

        # 从空子集开始搜索。
        backtrack(0, [])

        return result
```

## 这段代码最值得记住的地方

这题最值得记住的主干其实只有两部分。

### 1. 子集题的通用骨架

```python
result.append(path[:])

for i in range(start, len(nums)):
    path.append(nums[i])
    backtrack(i + 1, path)
    path.pop()
```

这表示：

- 每到一个状态，先收集当前子集
- 然后尝试把后面的元素继续加入

### 2. 这道题额外多出来的“同层去重”

```python
if i > start and nums[i] == nums[i - 1]:
    continue
```

这句就是整道题的灵魂。

你只要记住它的含义：

- 同一层里，相同元素只让第一个进入分支

这题就基本掌握了。

## 常见错误

### 1. 忘记先排序

如果不排序，
相同元素不挨在一起，
就很难判断“当前是不是重复分支”。

所以排序必须放在最前面。

### 2. 去重条件写错

很多人会写成：

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue
```

这样会把一些本来合法的跨层情况也错误跳过。

正确写法必须是：

```python
if i > start and nums[i] == nums[i - 1]:
    continue
```

这里的 `start` 非常关键，
它表示“同一层”的边界。

### 3. 忘记在每次递归开始时加入当前子集

子集问题和排列问题不一样。

排列通常是在“路径长度满足条件时”才加入答案；
但子集问题里：

- 每一个状态本身就是一个合法子集

所以应该在每次进入递归时就先做：

```python
result.append(path[:])
```

### 4. 回溯后忘记弹出元素

如果少了：

```python
path.pop()
```

那么路径会残留上一条分支的元素，
导致后续结果全乱掉。

## 适合你自己再写一遍的版本

如果你准备先默写一个最稳定的版本，
可以直接记下面这版：

```python
from typing import List


class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        result = []

        def backtrack(start: int, path: List[int]) -> None:
            result.append(path[:])

            for i in range(start, len(nums)):
                if i > start and nums[i] == nums[i - 1]:
                    continue

                path.append(nums[i])
                backtrack(i + 1, path)
                path.pop()

        backtrack(0, [])
        return result
```

## 一句话总结

这道题的关键是：

**先排序把重复元素放到一起，再用回溯枚举所有子集，并通过“同层去重”跳过重复分支，这样既能找全答案，又不会生成重复子集。**
