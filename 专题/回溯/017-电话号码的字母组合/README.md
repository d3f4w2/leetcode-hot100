# 017. 电话号码的字母组合

## 所属专题

- 回溯

## 题目描述

给定一个仅包含数字 `2-9` 的字符串 `digits`，
返回所有它能表示的字母组合。

答案可以按 **任意顺序** 返回。

数字到字母的映射与电话按键一致：

- `2 -> abc`
- `3 -> def`
- `4 -> ghi`
- `5 -> jkl`
- `6 -> mno`
- `7 -> pqrs`
- `8 -> tuv`
- `9 -> wxyz`

注意：

- `1` 不对应任何字母
- 题目输入只会包含 `2-9`

## 示例

### 示例 1

```text
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

### 示例 2

```text
输入：digits = ""
输出：[]
```

### 示例 3

```text
输入：digits = "2"
输出：["a","b","c"]
```

## 题意理解

这道题本质上是在做一件事：

- 第 1 个数字，从它对应的字母里选 1 个
- 第 2 个数字，从它对应的字母里选 1 个
- 第 3 个数字，再从它对应的字母里选 1 个

一直选到最后一个数字，
就得到一个完整的字符串组合。

例如：

```text
digits = "23"
```

表示：

- 第一个位置只能从 `abc` 里选
- 第二个位置只能从 `def` 里选

所以所有结果就是：

- 先固定第一个字母为 `a`，得到：`ad`、`ae`、`af`
- 再固定第一个字母为 `b`，得到：`bd`、`be`、`bf`
- 再固定第一个字母为 `c`，得到：`cd`、`ce`、`cf`

这不是排序题，
也不是随便从所有字母里乱挑。

而是：

- **按数字顺序**
- **每一位都选一个字母**
- **把所有可能都找出来**

## 最直接的想法：一位一位往后拼

如果只有两位数字，
我们可以写两层循环。

如果只有三位数字，
我们可以写三层循环。

但题目里的 `digits` 长度是不固定的，
所以没法用固定层数的循环来写。

这时候更自然的想法就是：

- 先处理第 0 位
- 再处理第 1 位
- 再处理第 2 位
- ……

每处理一位，
就把当前选中的字母拼到已有结果后面。

当所有位都处理完时，
就得到一个完整答案。

你会发现这个过程非常像：

- 做选择
- 进入下一层
- 再继续做选择

这正是回溯的典型结构。

## 优化思路：回溯搜索所有组合

### 核心想法

我们定义一个递归函数：

```text
backtrack(index, path)
```

它表示：

- 当前正在处理下标为 `index` 的数字
- `path` 表示已经拼好的字母组合

例如：

```text
digits = "23"
```

如果现在是：

```text
backtrack(1, "a")
```

意思就是：

- 第 0 位已经选好了，是 `a`
- 现在轮到第 1 位继续选字母

### 什么时候加入答案

当：

```text
index == len(digits)
```

说明所有数字都处理完了，
此时 `path` 就是一个完整组合，
应该加入结果列表。

### 当前层做什么

如果还没处理完，
就先取出当前数字对应的所有字母：

```python
mapping[digits[index]]
```

然后逐个尝试：

- 选这个字母
- 拼到 `path` 后面
- 递归处理下一位

例如当前数字是 `2`，
它对应 `abc`，
那么这一层就要依次尝试：

- 选 `a`
- 选 `b`
- 选 `c`

### 为什么这就是回溯

因为每一层都在做“枚举当前位的所有选择”。

走进下一层后，
如果后面还能继续组成结果，
就继续往下。

等这条路走完后，
再回来试当前层的下一个字母。

如果你使用的是字符串写法：

```python
path + letter
```

那么其实不需要手动撤销，
因为字符串是新生成的，
每次递归拿到的都是新的 `path`。

## 用示例手推一遍

以：

```text
digits = "23"
```

为例。

映射关系：

- `2 -> abc`
- `3 -> def`

### 第 1 步：从第 0 位开始

调用：

```text
backtrack(0, "")
```

说明：

- 现在处理第 0 位
- 当前还没有拼任何字母

第 0 位数字是 `2`，可选字母有：

- `a`
- `b`
- `c`

### 第 2 步：先选 `a`

进入：

```text
backtrack(1, "a")
```

现在处理第 1 位，
它是数字 `3`，对应字母：

- `d`
- `e`
- `f`

于是得到：

- `backtrack(2, "ad")`
- `backtrack(2, "ae")`
- `backtrack(2, "af")`

此时 `index == len(digits)`，
所以把下面这些加入答案：

- `ad`
- `ae`
- `af`

### 第 3 步：回到上一层，选 `b`

同理得到：

- `bd`
- `be`
- `bf`

### 第 4 步：回到上一层，选 `c`

同理得到：

- `cd`
- `ce`
- `cf`

### 最终结果

```text
["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

## 为什么这样写

### 1. 数字位数不固定，不能写死循环层数

如果题目永远只有两位，
那两层循环就够了。

但这里 `digits` 长度不固定，
所以需要一种能够自动处理任意层数的方法。

递归正好适合这种“按位向下处理”的结构。

### 2. 每一层递归正好表示“处理一位数字”

你可以把递归树理解成：

- 第 0 层决定第 1 个字母
- 第 1 层决定第 2 个字母
- 第 2 层决定第 3 个字母

这样思路非常清晰。

### 3. 这道题要求的是“所有组合”

只要题目里出现：

- 所有可能
- 全部组合
- 枚举每一种方案

往往就要想到：

- 回溯

因为回溯最擅长系统地枚举全部答案。

### 4. 空字符串要单独处理

如果 `digits` 是空，
说明根本没有可以选择的数字。

这时返回的应该是：

```python
[]
```

而不是：

```python
[""]
```

因为题目要的是“字母组合”，
空输入就没有任何组合。

## 算法步骤

1. 如果 `digits` 为空，直接返回 `[]`
2. 建立数字到字母的映射表 `mapping`
3. 创建结果列表 `result`
4. 定义递归函数 `backtrack(index, path)`
5. 如果 `index == len(digits)`，说明已经拼出一个完整组合，将 `path` 加入 `result`
6. 否则取出当前数字 `digits[index]` 对应的字母集合
7. 枚举这些字母中的每一个
8. 对每个字母递归调用 `backtrack(index + 1, path + letter)`
9. 递归结束后返回 `result`

## 复杂度分析

设字符串长度为 `m`。

### 时间复杂度

`O(4^m × m)`

原因：

- 每一位最多有 4 个字母可选（比如 `7` 和 `9`）
- 一共可能生成大约 `4^m` 条路径
- 每次形成结果字符串时，整体代价可以看作和字符串长度 `m` 有关

更精确地说，
不同数字对应的字母数可能是 3 或 4，
但用 `O(4^m × m)` 表示最坏情况已经足够。

### 空间复杂度

如果只计算递归调用栈，
空间复杂度是：

`O(m)`

因为递归深度最多就是数字个数 `m`。

如果把最终返回结果也算上，
那结果集本身会占用更多空间。

## Python 参考实现（详细注释）

```python
from typing import List


class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        # 如果输入为空，说明没有任何数字，
        # 那么也就不存在任何字母组合。
        if not digits:
            return []

        # 电话按键的映射关系。
        mapping = {
            '2': 'abc',
            '3': 'def',
            '4': 'ghi',
            '5': 'jkl',
            '6': 'mno',
            '7': 'pqrs',
            '8': 'tuv',
            '9': 'wxyz'
        }

        # 用来保存所有最终答案。
        result = []

        def backtrack(index: int, path: str) -> None:
            # 如果 index 已经走到 digits 的末尾，
            # 说明前面的每一位都选好了字母，
            # 当前 path 就是一个完整组合。
            if index == len(digits):
                result.append(path)
                return

            # 取出当前数字对应的所有候选字母。
            letters = mapping[digits[index]]

            # 当前位可以尝试每一个字母。
            for letter in letters:
                # path + letter 会生成一个新的字符串，
                # 表示“在当前组合后面再拼上这个字母”。
                # 然后递归去处理下一位数字。
                backtrack(index + 1, path + letter)

        # 从第 0 位开始回溯，
        # 一开始 path 还是空字符串。
        backtrack(0, '')

        return result
```

## 这段代码最值得记住的地方

如果你自己手写，
最关键的是记住下面这个递归框架：

```python
if index == len(digits):
    result.append(path)
    return

for letter in mapping[digits[index]]:
    backtrack(index + 1, path + letter)
```

它表达的意思就是：

- 当前位的所有字母都试一遍
- 每试一个，就继续处理下一位
- 当所有位都处理完时，把当前组合收进答案

## 常见错误

### 1. 忘记处理空字符串

如果 `digits == ""`，
应该直接返回：

```python
[]
```

### 2. 结束条件写错

很多人会把结束条件写成：

```python
index == len(digits) - 1
```

这样通常会让逻辑变得别扭，
也容易漏掉最后一位。

推荐固定写法：

```python
if index == len(digits):
    result.append(path)
    return
```

### 3. 没有按当前位去取字母

一定要记住：

```python
mapping[digits[index]]
```

这里表示的是：

- 当前正在处理哪一位
- 这一位对应哪些候选字母

### 4. 把这题误写成排列问题

这题不是把所有字母拿出来做全排列，
而是：

- 第 1 位只能从第 1 个数字对应的字母里选
- 第 2 位只能从第 2 个数字对应的字母里选

顺序是由 `digits` 固定下来的。

### 5. 使用列表路径时忘记撤销选择

如果你不是用字符串，
而是用列表 `path.append(letter)` 的写法，
那么递归回来后一定要记得：

```python
path.pop()
```

否则路径内容会串掉。

## 适合你自己再写一遍的版本

```python
from typing import List


class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []

        mapping = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz'
        }

        result = []

        def backtrack(index, path):
            if index == len(digits):
                result.append(path)
                return

            for letter in mapping[digits[index]]:
                backtrack(index + 1, path + letter)

        backtrack(0, '')
        return result
```

## 一句话总结

这道题的关键是：

**把每一位数字都看成一次选择，用回溯按顺序枚举当前位的所有字母，并在走到末尾时收集完整组合。**
